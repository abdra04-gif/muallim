## Как работаем
1. Идея записывается в `ideas.md` со статусом 💡. Статус меняет **автор** (решение о публикации — его и руководителя).
2. Выбрана → создаётся папка `docs/publications/<id>-<короткое-имя>/` с `outline.md` (тезисы), `claims.md` (каждое утверждение → SRC/ADR/отчёт/таблица) и `figures.md`.
   Черновик текста — LaTeX; папку для статей (в `thesis/` её пока нет, `make papers` собирает только документы диссертации) создаём, когда выбрана первая идея.
3. Любое число в статье берётся из отчёта `make report` или из ADR, а не из головы (правило `thesis-writer`).
4. Перед отправкой — `checklist.md` и агент `thesis-opponent` (читает как рецензент). Библиография — `citation-verifier`.
5. После отправки — запись в таблицу ниже и в `docs/thesis/materials-log.md`; в заключение диссертации — раздел «Публикации и доклады»
   (`sec:concl-dissemination`, `thesis/university-requirements.md`).

## Правила, которые уже действуют
- Нельзя придумывать библиографию и результаты (CLAUDE.md, «Нельзя»). Все ссылки — только из `docs/research/sources.md`.
- Данные учеников (голоса, ПД) в статью и в репозиторий открытых данных попадают **только** при отдельном согласии на публикацию (TD-SEC-02) и после решения этического вопроса (OQ-01, TD-SEC-09).
- Публикуемые цифры на тесте считаются **один раз**, на замороженном тесте (`research/preregistration.md`).
- Роль ИИ-агентов в работе раскрывается так, как требует площадка (см. `checklist.md`).

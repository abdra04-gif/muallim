# Муаллим: первая версия бота для чтения

Telegram-бот-тренажёр: русскоязычный взрослый учит арабское чтение **с нуля** по учебнику «Аль-Муаллим ас-Сани». Ученик получает урок, шлёт голосовое, бот находит ошибки чтения и объясняет их. Это описание — для автора, профессоров и для проверки в ChatGPT. Править можно любой раздел (файлы `docs/site/content/*.md`), потом `make site`.

## Коротко: что меняется по замечаниям профессоров

- Показываем **первую версию**, а не длинный план: один законченный путь на уроках 1–3.
- Фокус только на **буквах и огласовках** (28 пунктов программы).
- Урок = **видео ≤ 5 мин** (1–3 буквы) → **картинка со словами + аудио** → **попытка ученика** → **разбор** текстом или картинкой.
- **Без кириллической транслитерации**: только арабское письмо и звук.
- **Без AI-голоса и AI-картинок**: только живая речь (арабский с субтитрами).
- Путь **лёгкий**: достаточно один раз прочитать все слова, ошибки показываем, идеала не требуем.
- Прогресс **внутри урока и общий**, поздравление, **серия** дней.
- Все буквы с огласовками — **одна большая веха** с визуализацией; после неё — Этап II.
- Артикуляция: **статичная картинка + текст**; живой человек — дополнительный ресурс; для самых старательных — онлайн-учитель.

## Новое обновление Telegram: виджеты

9 ноября 2026 Telegram (Bot API 10.4) позволил сообщению стать маленьким приложением. Подробные заметки: `docs/research/telegram-widgets.md`. Рабочие прототипы: `docs/design/widgets/*.html`.

{{fig:widgets|Ученик нажимает в виджете, запрос (до 64 байт) идёт нашему боту, бот отвечает и меняет состояние, Telegram перерисовывает виджет.}}

Что такое виджет:

- Один HTML ≤ 32 КБ (≤ 4 КБ после сжатия zlib-9), в песочнице QuickJS, **без сети и без ввода текста**.
- Код после отправки не меняется, меняется только состояние (≤ 1024 байт), его пишет бот.
- Запрос виджета к боту ≤ 64 байт, ответ ≤ 1024 байт за 15 секунд, 5 запросов за 5 секунд на человека.
- **В продакшне только личный чат с ботом**; группы, пересылка, inline — пока тестовый сервер.
- Шрифты только системные; нет аудио, видео, микрофона. Вертикальный жест всегда принадлежит чату.

Как мы используем виджеты (всё управление внутри виджета, кнопок под сообщением нет):

| Виджет | Что внутри | Запросы к боту |
|---|---|---|
| Урок | вкладки «Слушай / Читай / Итог», карусель букв, слоги, кольцо прогресса, серия | `p:N` послушать слог, `next` дальше |
| Серия | ежедневная карточка: пламя, неделя кружками | `go` начать занятие |
| Карта | 28 букв, пройденные закрашены, текущая выделена | `l:N` открыть урок буквы |
| Веха | конфетти на canvas, «Этап II», «Поделиться» | `st2`, `share` |

Размеры прототипов после сжатия: урок 2423, серия 1016, карта 1320, веха 1181 байт из 4096.

Что остаётся обычными сообщениями: видео-урок, голосовые эталоны, голосовое ученика, подпись-запасной вариант под виджетом для старых приложений.

Что не доказано: прототипы запускались в браузере с имитацией, а не в песочнице Telegram; проверка на тестовом сервере и на iOS, Android, Desktop впереди. Библиотека бота (aiogram 3.31) пока не умеет `sendWidget`.

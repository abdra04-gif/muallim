## Путь ученика

Один урок — пять шагов. Ученик получает видео, картинку со словами и аудио, а отправляет одно голосовое. Всё остальное — кнопки «дальше».

{{fig:journey|Видео → картинка со словами и аудио → голосовое ученика → разбор → прогресс; после урока поздравление, после всех 28 букв — веха.}}

| Шаг | Что получает ученик | Что делает ученик |
|---|---|---|
| 1. Видео | видео-урок ≤ 5 мин на 1–3 буквы, арабская речь, русские субтитры | смотрит |
| 2. Слова | картинка со словами урока и голосовое «как правильно» | слушает, можно повторить |
| 3. Попытка | просьба прочитать слова | отправляет голосовое |
| 4. Разбор | что услышано, 1–3 пункта, что поправить (текст или картинка) | читает, по желанию пробует ещё раз |
| 5. Прогресс | «шаг n из 4», общая карта, серия 🔥, поздравление | жмёт «Следующий урок» |

Правила пути:

- Один экран — одно действие, минимум кнопок.
- Результат не блокирует: даже с ошибками ученик идёт дальше; «засчитано», когда слова прочитаны хотя бы раз.
- Нет наказаний: серия — мотивация, а не штраф.
- Видео ≤ 5 минут; если урок охватывает 3 буквы, видео не длиннее.

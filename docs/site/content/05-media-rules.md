## Правила для звука, картинок и транслитерации

| Правило | Что значит на практике |
|---|---|
| Нет кириллической транслитерации | на экранах ученика нет «ба», «Ра», «дж», «х» как записи звука; есть арабское письмо (بَ) и аудио |
| Нет AI-звука | эталон — живая запись человека; синтез речи не используем |
| Нет AI-картинок и AI-видео | картинки слов — оформление (шрифт, схема), видео — съёмка человека |
| Арабский с субтитрами | речь в видео арабская, русские субтитры |
| Артикуляция | статичная картинка (где рождается звук) + текст; живой человек — дополнительно |

Что надо проверить в нынешнем боте: источник каждого файла в `curriculum/audio/SOURCES.md` и `curriculum/video/videos.yaml`; поля `sound`, `translit`, `name` в программе; тексты `CARD_HOW_TO_READ`, `CARD_LETTER_INFO`, шаблоны `feedback.ru.yaml`; уровень квиза «узнаю» (опирается на кириллицу).

Исправления учебного контента (арабский текст, подсказки, имена букв) вносит только человек; агент готовит черновик со ссылкой на источник.

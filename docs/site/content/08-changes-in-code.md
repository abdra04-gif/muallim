## Что меняется в боте

| Область | Изменение |
|---|---|
| Программа | срез «Этап I: уроки 1–3 → 28 букв»; шаги урока: видео, слова+аудио, попытка, разбор |
| Контент (человек) | видео-уроки, живые эталоны слов, картинки артикуляции, тексты без транслитерации |
| Тексты ученику | убрать кириллические звуки; прогресс «шаг n из 4»; поздравление |
| Прогресс | карта 28 букв, веха, открытие Этапа II |
| Оценка | мягкий зачёт: засчитано, если слова прочитаны хотя бы раз |
| Видео | в `videos.yaml` — длительность, буквы урока, источник; кнопка «Углублённо» |
| Виджеты | порт + адаптер, сначала тестовый сервер |
| Проверки | тесты нового пути, bot-driver (`make try`), learner-simulator, ревью безопасности |

Работы — по правилам проекта: сначала падающие тесты, затем код, затем ревью; решения и отклонённые варианты записываются в ADR.

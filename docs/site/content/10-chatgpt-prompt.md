## Для проверки в ChatGPT

Скопируйте весь файл `spec-for-chatgpt.md` и вставьте вместе с запросом:

> Ты методист арабского чтения для взрослых новичков и разработчик Telegram-ботов. Прочитай описание и проверь: (1) соответствует ли путь ученика замечаниям профессоров (видео ≤ 5 мин на 1–3 буквы → картинка со словами + аудио → попытка → разбор; без транслитерации; без AI-медиа; лёгкий путь; большая веха из 28 букв); (2) нет ли противоречий и лишнего усложнения; (3) какие решения рискованны (виджеты Telegram Bot API 10.4, приватность, старые клиенты); (4) чего не хватает для первой версии. Ответь списком замечаний по важности и предложи исправления. Ничего не выдумывай: если данных нет, так и скажи.

Что ChatGPT не увидит: рисунки (в файле они заменены описанием словами) и содержимое роликов YouTube.

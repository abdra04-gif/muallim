# ADR-0030: Разбор ошибок, который хочется читать: «не дочитал», один пункт на слог, похвала, «было → стало»

- **Статус:** Принято; п. 5 частично заменён ADR-0057 — «было → стало» только при изменении балла
- **Дата:** 2026-10-18
- **Кто решил:** автор (варианты предложил агент)
- **Связано:** FR-43, ADR-0024, ADR-0029

## Контекст
Ученик прочитал половину строки (Фатиха 1:2) — бот выдал ~17 мелких ошибок («пропущен звук»,
«пропущена огласовка»…), три подробно и «…и ещё ошибок: N»; на картинке непрочитанный конец не был
подсвечен (подсветка искала букву по номеру согласной, а в фонемах шадда — одна согласная и «ٱ»
внутри фразы не читается — подсветка уезжала к началу). Долгий мадд из двух «ا» давал два
одинаковых пункта. «كَتَبَ» → «كَبَ» объяснялось как «не прозвучал гласный в «ка»» — difflib
выбирал одно из двух равноценных выравниваний. Автор: разбор должен быть точным, не нудным и
мотивировать исправлять.

## Решение
1. **«Не дочитал» — один пункт** (`domain.assessment.unread_from`): после последнего совпавшего куска
   (≥ 3 фонемы) осталось ≥ 2 согласных, а услышано после него — не больше трети. Пункт: на каком
   слоге остановился и что осталось; ошибки до этого места — как обычно; непрочитанное не
   подчёркнуто, не в «скажи 3 раза» и не в счёте «верно».
2. **Один пункт на слог**: ошибки одного слога — один пункт, одна строка «👄 Как сказать»; если
   пропущена буква, о её огласовке и мадде отдельно не говорим; одинаковые пункты — один раз.
   В БД (`detected_errors.message`) — по-прежнему текст к каждой ошибке.
3. **Сначала похвала**: «✅ Прочитано верно — N из M» (слоги).
4. **Картинка в три цвета**: верно — зелёным, ошибка — красным на розовом, не прочитано — серым.
   Буквы сопоставляются с фонемами по самим буквам (difflib по согласным), а не по номеру.
5. **«Было → стало»** со второй попытки той же строки: 📈/➡️/📉 и «✨ Исправлено: «…»» — слоги с
   ошибкой в прошлый раз, верные теперь (дочитанный конец не считается исправлением).
6. **Пропуск — с согласной**: если удалённый кусок можно сдвинуть вправо без изменения остатка,
   он начинается с согласной («пропущено «та»», а не «гласный в «ка» + «т»»).

## Рассмотренные варианты
| Вариант | Плюсы | Минусы | Итог |
|---|---|---|---|
| **🎯 Тренировка одного слога** (кнопка, голосовое только слога) | быстро, ощущение победы | слог вне строки не закрепляется | **отклонено автором**: исправлять — перечитывая всю строку |
| **Перечитать всю строку + «было → стало»** | закрепляется вся строка; прогресс виден | дольше одной попытки | **выбрано** |
| Объяснения от ИИ-чата (свободный текст) | живой язык | может уверенно ошибиться в таджвиде; новичок не заметит | отклонено (только проверенный словарь) |
| «Мои трудные звуки» (повтор слабых мест) | адресно | нужна статистика по ученику, интервалы | отложено |

## Последствия
- Новые тексты ученику — черновики агента, **утвердить автору**: `feedback.ru.yaml` (`unread`,
  `unread_how`), `texts.py` (`RESULT_RIGHT`, `RESULT_PROGRESS`, `RESULT_FIXED`). В kk/en черновиках
  `unread` нет — там непрочитанный конец разбирается по-старому, по ошибкам.
- Порог «не дочитал» (2 согласных, треть) — подобран на примерах, сверить на реальных попытках.
- Сдвиг пропуска меняет классификацию части ошибок у новых попыток (старые в БД не пересчитаны).

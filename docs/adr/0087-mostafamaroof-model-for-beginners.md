# ADR-0087: MostafaMaroof — модель бота для новичков; Muaalem рассмотрена и отложена до режима таджвида

- **Статус:** Принято автором 2026-11-19; в коде бота ещё не сделано (переводчик сделан, п. 8; следующий шаг — `/feature`, уровень L). Пороги утверждены (п. 4)
- **Дата:** 2026-11-19
- **Кто решил:** автор; измерения, варианты, плюсы и минусы — агент (протокол ADR-0021)
- **Связано:** ADR-0086 (уточняет п. 7), ADR-0051, ADR-0064, SRC-169 (MostafaMaroof), `docs/research/PHASE_3_EXPERIMENTAL_RESULTS.md` §11.8c, §11.8c-bis, §11.8e–11.8h, `docs/research/ERROR_RULES_DRAFT.md`

## Контекст
С начала проекта бот слушает ученика моделью Quran Muaalem (обучена на чтении Корана, даёт фонемы и
10 признаков звука). Фаза 3 показала, что для новичков она подходит хуже, чем MostafaMaroof
(`wav2vec2-arabic-phoneme-asr`, XLSR-53, 0,3 млрд параметров, Apache-2.0), при одном и том же способе
проверки «варианты карточки» (ADR-0086):

| Где измерено | MostafaMaroof | Muaalem |
|---|---|---|
| 840 слогов учеников: верное засчитано (допуск 0) | 76 из 100 | 62 из 100 |
| 840 слогов: «не та огласовка» проскочила | 3 из 100 | 8 из 100 |
| 200 верных аятов: верное выбрано — огласовка / похожая буква / сукун | 99 / 99,8 / 99,2 | 94 / 93,5 / 99,7 |
| 200 верных аятов: шадда / мадд | 94,8 / 93,6 | 33,6 / 43,3 |
| 200 верных аятов поругано зря (допуск 4) | 5 из 100 | 82 из 100 |

Muaalem проигрывает не из-за ошибки перевода в её запись (проверено, §11.8e): она строго ждёт длины
звуков по правилам чтения Корана (мадд 2–4 счёта, шадда с удержанием). Для чтеца это правильно, для
новичка, который читает медленно и неровно, — постоянные «ошибки» там, где их нет.

## Решение
1. **Бот для новичков слушает моделью MostafaMaroof** на всю книгу, способом «варианты карточки»
   (ADR-0086). Ученик видит один ответ; учитель — все способы.
2. **Muaalem не удаляется.** Её адаптер остаётся в коде за тем же портом `PronunciationRecognizer`,
   выключенным для новичков. Включить, когда появится: (а) режим для продвинутых с таджвидом
   (гунна, ихфа, идгам, икляб, калькаля — у MostafaMaroof для них нет знаков), (б) суры и заучивание,
   (в) если MostafaMaroof после дообучения всё равно не хватит.
3. **Уроки 54–69 (нун и мим с сукуном):** MostafaMaroof засчитывает оба чтения — с таджвидом и без;
   новичка таджвид не штрафует (ADR-0086 п. 5).
4. **Пороги (утверждены автором 2026-11-19, строгие):** разница «верное − лучшая ошибка» ≥ 0 — «засчитано»;
   от −4 до 0 — «прочитай ещё раз»; ниже −4 — «ошибка» (§11.8f, вариант А из трёх: строгие 0/−4, средние −1/−4,
   мягкие −2/−5). Явная ошибка в огласовке проскакивает 3 из 100; верный слог зря назван ошибкой 8 из 100.
   «Прочитай ещё раз» — не больше одного раза подряд: во второй раз «засчитано» с мягкой подсказкой, попытка
   уходит учителю (иначе: только «да/нет» ругает зря каждого четвёртого или пропускает половину ошибок).
   **Соперник «другой слог»:** кроме типичных ошибок карточки, верное чтение сравнивается со всеми слогами
   с другой, не похожей буквой (§11.8g): без него чужой слог («зу» вместо «ба») засчитывается 18 из 100,
   с ним — 1 из 100 (цена: верных сразу засчитано 69 вместо 76). Ниже −6 — «ошибка: прочитан другой слог»,
   от −6 до −3 — «прочитай ещё раз». Для фраз соперник — свободное распознавание; измерить до фраз.
   Пересмотреть на 200 записях учеников, размеченных преподавателем.
5. **Дообучение — позже, на наших данных:** записи учеников с согласием, разметка преподавателя
   выбором из вариантов карточки; 200 записей оценки в обучение не попадают никогда, учим на других
   учениках. Сравнение «до/после» — с `results/baseline_840.csv` строка в строку и с 200 аятами (§11.8e),
   чтобы модель не разучилась верному чтению.
6. **Где учить:** MacBook Air M1 8 ГБ хватает на подбор порогов и проверку, но не на полное дообучение
   (модель 0,3 млрд параметров, нужно ~5–6 ГБ только на веса и оптимизатор). Порядок: сервер
   университета → почасовая аренда видеокарты (несколько долларов на эксперимент). Голоса учеников —
   персональные данные: в чужое облако только записи с согласием, решает автор.
7. **Порядок встраивания (вариант А, автор 2026-11-19):** сначала уроки 1–41 (буквы, огласовки, мадд,
   шадда — всё измерено); уроки 42+ — после переводчика «текст карточки → звуки модели» и измерения
   правил слияния, артикля, танвина, нечитаемых букв (§11.8h, `ERROR_RULES_DRAFT.md`). Отклонено:
   сразу вся книга (непроверенные правила задержат всё); сначала 200 записей на старом боте (ученики
   дольше получают проверку 14 из 100).
8. **Переводчик «текст карточки → звуки модели» (автор 2026-11-19, PHASE_3 §11.8i):** свой фонетизатор бота
   (чтение по Хафсу, как в книге) + таблица знаков в алфавит MostafaMaroof (`docs/research/phase3/to_maroof.py`).
   Не фонетизатор, на котором училась модель (Навар Халаби, IqraEval): он пишет по написанию, а не по
   правилам чтения (танвин, слияние, сокращение долгой перед сукуном, ٱللَّهِ) — расходится с книгой.
   Твёрдые гласные (A I U) не угадываются: при подсчёте складываются с простыми. Карточка из отдельных
   слогов читается со всеми гласными. Все 288 карточек уроков 1–41 переводятся.
9. **Последний слог карточки из нескольких слогов — правило «ясная гласная» (автор 2026-11-19, §11.8i):**
   слышна верная гласная — «засчитано»; ясно слышна другая — «ошибка»; гласная почти не слышна —
   «прочитай ещё раз, протяни последнюю гласную», не «ошибка». На 28 записях учителя ни одна подменённая
   последняя гласная не засчитана (строгое правило зря ругало 17 из 28 верных, мягкое — пропускало 28 из 56
   ошибок). Текст просьбы ученику — черновик агента, утверждает автор.
10. **Алфавит (урок 2) голосом не проверяется — как в книге** (автор 2026-11-19): подсказка урока L002-01 (по SRC-040, с. 10):
    «только посмотри на буквы и их названия. Учить будем не названия, а звуки»; в боте — `ItemKind.ALPHABET`.

## Отклонено
| Вариант | Почему нет |
|---|---|
| Взять фонетизатор, на котором училась модель (Халаби) | пишет по написанию, не по правилам чтения книги |
| Последний слог строго, как все | зря ругает быстрое верное чтение (17 из 28 у учителя) |
| Последний слог мягко: остановка без гласной засчитывается | пропускает половину ошибок в последней гласной (28 из 56) |
| Проверять названия букв в алфавите | книга учит звуки, не названия (метод Максуди); меняло бы методику |
| Оставить Muaalem основной моделью | на новичках хуже по огласовке и буквам; ругает 82 из 100 верных аятов |
| Две модели для новичков (голосование) | вдвое дольше ответ и сложнее объяснить ученику; MostafaMaroof не хуже на всём, что проверяем строго |
| Удалить Muaalem из бота | нужна для таджвида и сур в будущем; её адаптер и тесты уже есть |
| Обучить свой классификатор 84 слогов | 91 из 100, но только для 84 слогов и пропускает похожие буквы (§11.8c); не покрывает слова и фразы |
| Дообучать сразу, до сбора данных | нет записей новичков с ошибками и разметкой; учить на верном чтении чтецов — не научит слышать ошибки |
| Полное дообучение на M1 Air | 8 ГБ памяти мало для 0,3 млрд параметров с оптимизатором |

## Оговорки
- MostafaMaroof обучалась на обучающей части IqraEval — её цифры на dev этого же набора могут быть завышены.
- По описанию модели, значительная часть её обучения — синтетическая речь; на детских и женских голосах не проверена (`PHASE_1_ASR_RESEARCH.md` §3.8).
- Похожие буквы (с/ص, д/ض и т. п.) она различает слабо: в опыте на слогах «не та буква» проскакивает 18 из 100 при допуске 0 — главная цель дообучения.

# ADR-0045: Проверка бота в терминале — `muallim --test`, `make try`, агент bot-driver

- **Статус:** Принято
- **Дата:** 2026-10-18
- **Кто решил:** Исмаилов — «сделай проверку бота, чтоб можно было». Устройство предложил агент.
- **Связано:** ADR-0008, ADR-0034, ADR-0035, TD-FN-41, TD-FN-61, TD-FN-69, SRC-072, SRC-090

## Контекст
Проверить путь ученика можно было только в Telegram с телефона (`make run-stub`) или тестами.
Агенты не могли пройти бота сами: `telegram-mcp` требует личного аккаунта (TD-FN-41). В лабе 7
научрука обязательное требование — режим `--test "/command"` с ответом в терминал (SRC-072).

## Решение
`uv run muallim --test "шаг" "шаг" …` (`src/muallim/bootstrap/console.py`): настоящие обработчики,
DI и экраны; Telegram заменён сессией в памяти, которая печатает ответы бота и кнопки; шаг — текст,
нажатие кнопки по надписи или голосовое `🎤`. **Изоляция:** настройки собираются в коде, `.env` не
читается; база — временная SQLite, удаляется после запуска; распознавание — всегда заглушка, о
чём печатается первой строкой. `make try a='…'`; агент `bot-driver` (только читает и запускает
режим проверки).

## Рассмотренные варианты
| Вариант | Плюсы | Минусы | Итог |
|---|---|---|---|
| telegram-mcp с тестовым аккаунтом (TD-FN-41) | настоящий клиент | отдельный аккаунт, сеть, сессия Telethon — доступ к аккаунту | Отложено |
| Взять сессию из `tests/` | уже есть | код приложения не должен зависеть от тестов | Отклонено; своя сессия в bootstrap |
| Сохранять базу между запусками | путь можно продолжать | риск перепутать с базой учеников; каждый запуск — не воспроизводим | Отклонено: путь целиком в одном запуске |
| Настоящая модель в режиме проверки | проверка распознавания | 2 ГБ и минуты загрузки; для пути по кнопкам не нужна | Отклонено |

## Последствия
- Первый же прогон нашёл два расхождения текста с действием (TD-FN-69).
- Обновление aiogram может потребовать правки сессии (`BaseSession`) — её проверяют тесты.

## Как проверить
`tests/integration/test_console.py` (в том числе: подмена `DATABASE_URL` и `BOT_TOKEN` в окружении
не используется); `make try a='"/start" "✅ Да, разрешаю"'`.

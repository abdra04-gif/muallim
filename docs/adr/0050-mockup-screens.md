# ADR-0050: Пять экранов из макетов: формы буквы, разбор по словам, открытка, прогресс по книге, начало занятия

- **Статус:** Принято; п. 2 (плашки слов, «нужна X вместо прозвучала Y» — `_swap`) частично заменён ADR-0070 — красная буква с номером и легенда групп
- **Дата:** 2026-10-18
- **Кто решил:** автор («внедряй все 5 макетов»; ответы на вопросы — ниже); устройство выбрал агент. Начало занятия автор принял до сверки источника, сверка — до пилота (TD-FN-71); состав открытки (неделя и серия) автор утвердил
- **Связано:** FR-45, FR-46, FR-47, ADR-0024 (дизайн), ADR-0025, ADR-0049, SRC-059, SRC-110; макеты — <https://claude.ai/artifact/Q1kQGvyfoVHMAxfgENbCoW>

## Контекст
Анализ экранов (2026-10-18) показал, где новичку трудно:
- карточка буквы не показывает, как буква выглядит в слове;
- разбор ошибки требует читать транскрипцию с точками под буквами;
- конец урока — одна строка текста;
- картинка прогресса повторяла карту алфавита с главной;
- истиаза и басмала звучали только в уроке 1.

Автор утвердил все пять предложений.

## Решение
1. **Карточка буквы** (`render.letter_forms`): формы в слове справа налево (отдельно, в начале, в середине, в конце).
   У несоединяемых букв форм две, у хамзы одна. Ниже — огласовки, внизу — зона звука «горло / язык / губы».
   Это упрощение махāридж аль-Джазарийи (SRC-059) до трёх зон; утвердил автор: горло — ء ه ع ح غ خ,
   губы — ب م و ف, язык — остальные (`domain/phonetics.articulation_zone`).
2. **Разбор по словам** (`render.word_states`, `result_words`): верные слова — зелёные плашки, неверное — красная
   с рамкой, непрочитанные — серые; сверху «верно N из M». Первая замена буквы показывается как
   «нужна ص вместо прозвучала س». Данные те же, что раньше (кластеры ошибок), меняется только картинка.
3. **Открытка** (`render.postcard`): медаль с буквой урока (или номером), «Урок пройден», страница книги,
   неделя и серия. Кнопка «📤 Поделиться» присылает открытку отдельным сообщением с приглашением в бот,
   ученик пересылает её сам. Имени и псевдонима на открытке нет (FR-47, `privacy.md`).
4. **Прогресс** (`render.book_progress`): полоса на каждую из 9 частей книги и неделя занятий.
   `Progress.week` — 7 дней с попытками, `Progress.today`. Карта алфавита осталась на главной.
5. **Начало занятия** (FR-45). Автор спросил, как правильно читать — сразу или по отдельности.
   Допустимы все четыре способа соединить истиазу, басмалу и начало чтения; лучший — остановка после каждой
   (SRC-110, надёжность C — сверка с преподавателем или книгой по таджвиду: TD-FN-71). Поэтому ученик читает две готовые карточки урока 1 (L001-02, L001-03) двумя
   голосовыми, а после басмалы получает «▶️ Продолжить занятие» туда, где остановился.
   Экран предлагается раз в день: урок 1 пройден, сегодня попыток нет, сегодня не пропускал.
   Пропуск и «куда вернуться» хранятся в FSM (ADR-0049).
6. **Русские подписи на картинках** — шрифт **PT Sans** (ParaType, OFL; файл из репозитория Google Fonts —
   не пакет Python): в Scheherazade New нет кириллицы. Все подписи приходят из `texts.py`.

## Рассмотренные варианты
| Вопрос | Выбрано | Отклонено и почему |
|---|---|---|
| Истиаза и басмала | два голосовых, остановка после каждой (лучший из 4 способов по SRC-110; проще новичку) | одно голосовое на обе — нужна новая карточка в программе (правка расшифровки книги) |
| Зоны звука | 3 упрощённые зоны, утвердил автор | 17 махāридж — перегрузка для новичка; без зон — меньше пользы |
| Кириллица на картинках | PT Sans (OFL) | без русского на картинках — подписи форм и частей книги ушли бы в текст, макеты не совпали бы |
| «Поделиться» | открытка отдельным сообщением | inline-режим Telegram — сложнее, нужен режим бота; без кнопки — ученик не догадается |

## Последствия
- `make design` рисует 18 экранов, добавлены `17_opening.png` и `18_postcard.png`. Скрипт `render_screens.py`
  был сломан с ADR-0030 (строки вместо `Explanation`) — исправлен.
- Попытки начала занятия сохраняются как обычные попытки L001-02 и L001-03. В исследовании их можно
  отделить по времени: первая попытка дня, урок 1 уже пройден.
- Если урок закрыт попыткой с ошибками, вместо открытки показывается разбор по словам; «📤 Поделиться» всё равно есть.
- После перезапуска бота отметка «пропустил сегодня» теряется (FSM в памяти, TD-FN-70): экран
  предложится ещё раз. Если ученик сегодня уже читал, экран не предлагается — это видно по БД.

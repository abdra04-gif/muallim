# ADR-0038: Анкета при входе — родной язык, опыт чтения, 18+

- **Статус:** Предложено — ждёт решения человека (схема БД и тексты ученику — его зона)
- **Дата:** 2026-10-18
- **Кто решил:** Исмаилов выбрал «спроектировать анкету при входе»; варианты и черновик — агент.
- **Связано:** H2.1, H2.2 и раздел 2 `docs/research/preregistration.md`, roadmap 1.6, TD-SEC-05,
  FR-09, FR-41, US-U-01, `docs/requirements/audience.md`; черновик FR-44

## Контекст
Гипотеза H2.1 и шаг 1.6 сравнивают русско- и казахоязычных учеников, но бот не знает родного
языка: `learners.language` — язык интерфейса Telegram, у казахоязычного он обычно русский.
Не известен и уровень: «с нуля» (`audience.md`) или уже знает буквы — без этого ошибки новичка
смешиваются с ошибками продолжающего. Участие в исследовании — только 18+ (TD-SEC-05), а возраст
бот не спрашивает. **Задним числом не восстановить**: решить до пилота (roadmap 1.3).

## Предлагаемое требование (черновик FR-44)
После согласия на исследование и до первого урока бот задаёт три вопроса кнопками; ответ можно
изменить в «Мои данные»; без ответа на 18+ голос не сохраняется (как без согласия).

## Черновик вопросов — **тексты утверждает человек**
1. «Ваш родной язык?» — Русский · Казахский · Татарский · Другой
2. «Читаете ли вы по-арабски?» — Совсем нет · Знаю некоторые буквы · Читаю медленно, по слогам
3. «Вам есть 18 лет?» — Да · Нет (тогда: занятия доступны, запись голоса для исследования — нет)

Без свободного текста: только кнопки — меньше персональных данных, удобнее на телефоне.

## Рассмотренные варианты
| Вариант | Плюсы | Минусы | Итог |
|---|---|---|---|
| А. Три вопроса кнопками после согласия, до урока | данные у всех с первой попытки; 15 секунд | ещё один экран до первого успеха (QAS-07) | **Рекомендую** |
| Б. Спросить после первой засчитанной строки | первый успех не задерживается | первые попытки без ковариат; часть уйдёт раньше | запасной |
| В. Внешняя форма (Google Forms / Яндекс Формы) | без изменения кода | связь с псевдонимом вручную, данные за пределами системы и, возможно, за рубежом (TD-SEC-04) | Отклонено |
| Г. Выводить язык по `language` Telegram | ничего не спрашивать | неверно для казахоязычных с русским интерфейсом — ровно та группа, что нужна H2.1 | Отклонено |

## Данные (черновик — схема БД решает человек)
Таблица `learner_profile` (1 : 1 к `learners`, каскадное удаление): `native_language`
(`ru`/`kk`/`tt`/`other`), `arabic_reading` (`none`/`some_letters`/`slow_syllables`),
`adult_confirmed` (bool), `answered_at`, `questionnaire_version`. Поля — в `v_attempts` для
отчётов (без Telegram ID). Это персональные данные: обновить `docs/security/privacy.md`, словарь
данных и текст согласия (что спрашиваем и зачем).

## Последствия
- H2.1 и матрица путаниц по L1 становятся проверяемыми; в анализе — ковариата «опыт чтения».
- В `preregistration.md` — переменные `native_language`, `arabic_reading` (раздел 2) **[утвердить]**.
- Ещё один экран в первом запуске; `learner-simulator` должен пройти его глазами новичка.

## Как проверить
Тест сценария первого запуска: согласие → три вопроса → первый урок; без «18+ = да» аудио не
сохраняется; удаление ученика удаляет профиль; отчёт по L1 не содержит Telegram ID.

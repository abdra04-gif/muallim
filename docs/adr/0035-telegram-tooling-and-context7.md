# ADR-0035: Обзор инструментов для бота — Context7, скилл telegram-bot, находки в выходе модели

- **Статус:** Принято
- **Дата:** 2026-10-18
- **Кто решил:** Исмаилов (требование: найти, что пригодится для Telegram-бота и проекта, скачать
  или сделать). Обзор, выбор и состав скилла предложил агент.
- **Связано:** ADR-0005, ADR-0008, ADR-0024, ADR-0034, TD-FN-02, TD-FN-17, TD-FN-35…41,
  TD-SEC-04, TD-SEC-12, SRC-060, SRC-061, SRC-062

## Контекст
Обзор `docs/research/bot-tooling.md`. Агенты писали код aiogram 3 по памяти — версия в проекте
3.31, API меняется. Лимиты Bot API и тестовая среда Telegram нигде не были записаны. При чтении
исходников `quran-muaalem` выяснилось, что модель отдаёт уверенность и признаки сифат, а проект
их теряет.

## Решение
1. **Context7 MCP** в `.mcp.json` проекта, версия зафиксирована (`@upstash/context7-mcp@4.1.1`,
   выпущена за месяц до решения), — документация библиотек нужной версии для агентов. Запросы
   уходят в Context7 только с названиями библиотек и вопросами, без кода и данных.
2. **Проектный скилл** `.claude/skills/telegram-bot/` — лимиты Bot API (SRC-060), тестовая среда
   (SRC-061), что отдаёт Muaalem (SRC-062), правила проекта для кода бота.
3. Скачаны для справки в `../external/` (вне проекта; с 2026-10-22 — `external/` внутри проекта, вне git, ADR-0063): `chigwell/telegram-mcp`,
   `snakers4/silero-vad`, `MahmoudAshraf97/ctc-forced-aligner`.
4. Изменения кода и зависимости не делаются: находки записаны в техдолг TD-FN-35…41 для `/feature`.

## Рассмотренные варианты
| Вариант | Плюсы | Минусы | Итог |
|---|---|---|---|
| Context7 без фиксации версии (`@latest`) | всегда свежий | каждый запуск тянет новый код из npm — риск цепочки поставок | Отклонено |
| Подключить telegram-mcp сразу | агент тестирует бота настоящим клиентом | сессия Telethon = полный доступ к личному аккаунту; нужен отдельный тестовый аккаунт | Отложено (TD-FN-41) |
| Сразу поставить silero-vad и torchaudio | быстрее TD-FN-37, TD-FN-40 | новые зависимости — решение человека; torchaudio тяжёлый | Отложено |
| Sentry, локальный Bot API, telegram-test-api, aiogram-dialog | — | причины — `bot-tooling.md`, «Рассмотрено и отклонено» | Отклонено |

## Последствия
- Агент сверяет API aiogram/SQLAlchemy по документации, а не по памяти.
- Перед пилотом прибавилось: TD-FN-35 (T1 — сохранять уверенность модели), TD-FN-38, TD-FN-39 (T2).
- При первом запуске Claude Code спросит разрешение на сервер `context7` из `.mcp.json`.

## Как проверить
`.mcp.json` содержит версию без `latest`; скилл `telegram-bot` виден в списке скиллов сессии;
TD-FN-35…41 есть в `docs/tech-debt.md`.

# ADR-0040: Разметка по фонемам с ответом бота, учёт согласия и сохранность данных

- **Статус:** Принято
- **Дата:** 2026-10-18
- **Кто решил:** предложил агент (аудит БД), решения по разметке и согласию — автор
- **Связано:** RQ-1, RQ-2, QAS-01, NFR-ACC-01, NFR-TR-03, FR-09, FR-10, FR-14, ADR-0004, ADR-0020, ADR-0023, SRC-043, SRC-063, SRC-064, SRC-065, SRC-066

## Контекст
Аудит БД 2026-10-18 нашёл, что главная метрика диссертации не считается и что данные могут теряться:
1. precision/recall/F1 брали метки «на ошибку» (`annotations.detected_error_id`), а импорт разметки
   их никогда не ставил — на реальных данных TP = FP = 0. Тест заполнял поле вручную и был зелёным.
2. Очередь разметки исключала уже размеченное кем угодно — второй разметчик не получал попытку,
   κ «учитель — учитель» не посчитать.
3. Повторная загрузка CSV дублировала метки; CSV без BOM — «кракозябры» в Excel; Excel с русской
   локалью сохраняет с «;» — загрузка молча принимала 0 меток; пути к аудио — абсолютные.
4. `make backup` печатал «Копия: …» при упавшем pg_dump; копия не проверялась.
5. Отзыв согласия не удалял записи, хотя `privacy.md` обещает хранить их «до отзыва согласия».
6. «Удалить мои данные» стирало файлы до commit (при сбое БД ссылается на пустоту) и могло стереть
   ту же запись у другого ученика (пересланное голосовое — тот же SHA-256).

## Решение
- **Разметка** (`docs/data/annotation-guide.md` 2.0): разметчик записывает, что прозвучало на самом
  деле (`corrected_phonemes`). Видит ответ бота — поле заполнено тем, что услышал бот: `agree` — бот
  прав, `fix` — исправить; `audio_unusable`, `off_task`. Загрузка ловит `agree` с правками и `fix` без
  правок. В пакете все попытки (и засчитанные ботом), где бот нашёл ошибки — в начале.
- **Пакет** — папка `tasks.csv` (UTF-8 с BOM) + `audio/` с относительными путями; своя очередь у
  каждого разметчика; **всё размечают оба**. Загрузка: разделитель «,»/«;»/таб, проверка колонок,
  алфавита фонем (SRC-002) с подсказками, кода разметчика; всё или ничего; повтор — без дублей;
  исправление — новая строка, в метриках последняя; удалённые/без согласия — пропуск со счётом.
- **Метрики** по каждой фонеме эталона: TA/FR/FA/TR, precision, recall, F1, FAR, FRR, верный диагноз
  (SRC-064, как Iqra'Eval и L2-ARCTIC); вердикт учителя — та же политика оценки по его транскрипции;
  κ (вердикт), α Криппендорфа по фонемам (SRC-065); **учёт согласия с ботом** по разметчику и вердикту.
- **Датасет**: строка на попытку, разметка каждого, `consensus_phonemes`; `truth.csv`/`predictions.csv`
  в формате `mdd_eval` Iqra'Eval (SRC-066) — только согласованная разметка.
- **Сохранность**: отзыв согласия удаляет записи и разметку по ним (попытки остаются); файлы удаляются
  только после commit и только если запись больше никому не нужна; `muallim-research verify`
  (потерянные, лишние, повреждённые файлы, записи без согласия); `scripts/db/backup.sh` и
  `restore.sh` (проверка архива, SHA256SUMS, `-FAILED` при сбое, подтверждение «да», копия перед
  восстановлением, одна транзакция); `make migrate` сначала делает копию; хук `guard.py` запрещает
  агенту удаление тома БД, откат миграций, восстановление и DROP/TRUNCATE/DELETE через консоль БД.

## Рассмотренные варианты
| Вариант | Плюсы | Минусы | Итог |
|---|---|---|---|
| Фонемы «что прозвучало» + метка попытки | P/R/F1 по фонемам, сравнимо с Iqra'Eval/L2-ARCTIC; готовые данные для дообучения | разметчику нужен фонетический алфавит | **принято** |
| Метка на каждую найденную ошибку | проще | пропуски не локализуются; для обучения почти бесполезно | отклонено |
| Только метка на попытку (как было) | проще всего | P/R/F1 не посчитать вообще | отклонено |
| Слепая разметка (поле — эталон, ответа бота не видно; L2-ARCTIC) | честнее precision и κ «бот — учитель» | дольше для преподавателя | отклонено автором; риск — угроза валидности (`preregistration.md` §5) |
| Смешанная: 20 % слепо для оценки, остальное с ответом бота | честная оценка при быстрой разметке | больше кода, сложнее объяснить | отложено — предложить, если оппонент спросит о подсказке |
| Двойная разметка 10 % / 20 % | меньше работы | меньше данных о согласии | отклонено автором: размечают оба всё |
| Label Studio | готовый интерфейс, несколько разметчиков | сервер, голоса на сервере, новая зависимость | отложено до > 2000 записей или > 3 разметчиков |
| При отзыве согласия — удалять файлы, метки оставить; или хранить и изменить текст | меньше потерь данных | разметка производна от голоса; юридически слабее | отклонено автором |

## Последствия
- Метки руководства 1.0 в метрики не входят; `annotations.detected_error_id` больше не заполняется
  (кандидат на удаление миграцией, TD-DB-04).
- Пакеты разметки содержат копии голосов — передавать на зашифрованной флешке и удалять после
  загрузки.
- Не сделано (решение человека, `docs/tech-debt.md`): роли PostgreSQL вместо суперпользователя,
  CHECK/UNIQUE в БД, копия по расписанию вне ноутбука, миграции при старте контейнера без копии.

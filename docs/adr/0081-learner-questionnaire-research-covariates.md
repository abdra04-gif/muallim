# ADR-0081: Анкета 2.0 — данные об ученике для исследования и личной помощи

- **Статус:** Принято (решения автора 2026-11-07)
- **Дата:** 2026-11-07
- **Кто решил:** автор. Его решения в этой сессии: собирать данные обо всех учениках — имя, возраст,
  уровень арабского, пол, намаз; анкету сократить до самого важного и сделать быстрой (кнопки);
  согласие — одно нажатие после приветствия; «до 18» запись голоса не отключает; имя хранить,
  а ученика находить по индивидуальному номеру; экран «Мои ошибки» ученику не делать — разборы только
  для исследователя. Тексты вопросов — **черновик агента, утверждает автор**.
- **Меняет:** ADR-0038 (анкета при входе: три вопроса, без свободного текста, «нет 18» снимает
  согласие); закрывает TD-SEC-05 решением автора (см. «Последствия»).
- **Связано:** FR-44, FR-65 (новое), FR-09, FR-10; ADR-0010, ADR-0040, ADR-0054, ADR-0051;
  `docs/security/privacy.md`, `docs/research/preregistration.md` (раздел 2, ковариаты)

## Контекст
Для публикаций нужно сравнивать ошибки по группам (пол, возраст, опыт, намаз) и видеть ученика по
отдельности. ADR-0038 собирал три признака: 18+, родной язык, опыт чтения. Задним числом анкету не
восстановить, а у пилота небольшое число учеников — каждый ответ важен.

Автор ограничил размер: слишком много вопросов отпугивает новичка до первого урока (QAS-07).

## Решение
1. **Шесть экранов**, на каждом «Пропустить»: имя («как обращаться»), возраст (группа), пол, родной
   язык, как читает по-арабски (с нуля / буквы / по слогам / уверенно), намаз (нет / иногда /
   регулярно). Все — одно нажатие; имя — кнопка «как в Telegram» или текст.
2. **Ответ сохраняется сразу**, поэтому брошенная анкета продолжается с того же вопроса.
   Уже зарегистрированным задаются только новые вопросы.
3. **Порядок:** приветствие → согласие (одно нажатие, журнал согласий как раньше) → анкета → урок.
   Отказ от исследования — анкета не задаётся (минимизация).
4. **Возраст — группа** (до 18, 18–24, 25–34, 35–44, 45–54, 55+). «До 18» **не отключает** запись
   голоса и не снимает согласие. Это решение автора, ответственность за согласие родителей и закон
   — на авторе (OQ-01, OQ-08 остаются открытыми).
5. **Имя — отдельная таблица `learner_names`**, не в `learner_profiles`: в `v_*`, отчёты, выгрузки
   не попадает, роль просмотра `muallim_reader` её не читает (`scripts/db/roles.sql`). Номер ученика
   для личной помощи — псевдоним `L-xxxxxxxx`, он есть везде; по нему
   `muallim-research learner L-…` показывает имя и анкету (Telegram ID не показывает).
6. **Исследование:** представление `v_learner_cohorts` (ковариаты + итоги попыток под псевдонимом),
   отчёт `analytics/sql/12_errors_by_cohort.sql` (пол, возраст, намаз, опыт, язык × ошибки; группы
   меньше 5 учеников скрыты), ковариаты в `manifest.jsonl` выгрузки датасета.

## Рассмотренные варианты
| Вариант | Плюсы | Минусы | Итог |
|---|---|---|---|
| А. 6 экранов с кнопками, пропуск везде | быстро, данные для гипотез, имя для помощи | 6 нажатий до урока | **Принято** |
| Б. 12 вопросов (стаж, учитель, суры, цель, время, страна) | больше ковариат | отпугивает новичка, часть слабо влияет | Отклонено: можно добавить «Дополнить анкету» позже |
| В. Возраст числом | точнее | ввод текстом дольше; для публикаций хватает групп; точный возраст — лишнее ПДн | Отклонено автором в пользу быстроты |
| Г. Имя в `learner_profiles` | проще | попадает в представления и роль просмотра | Отклонено: прямое ПДн отдельно |
| Д. Согласие убрать совсем | быстрее | нет журнала согласий (FR-09) — нечем подтвердить в публикации | Отклонено: одно нажатие остаётся |
| Е. Экран «Мои ошибки» ученику | польза ученику | не нужен сейчас, у ученика есть «Прогресс» | Отложено автором |

## Последствия
- **TD-SEC-05** (несовершеннолетние): правило «исследование только 18+» снято решением автора;
  записывается голос и у «до 18». Согласие родителей и этическое заключение (TD-SEC-09) остаются на
  авторе и нужны до публикации данных несовершеннолетних.
- **FR-63** (разметка 3.0) говорит «пол ученика не делаем»: это про разметку, не про анкету; пол в
  анкете — по этому решению. Разметчик (учитель) пол ученика по-прежнему не видит.
- Малые группы в публикации: порог 5 в отчёте — защита от узнавания; в статье тот же порог.
- Пока учеников в пилоте мало, отчёт по когортам будет пустым — это ожидаемо, а не ошибка.
- После `make migrate` нужен `make db-roles` (иначе просмотр читает `learner_names`).
- **Предрегистрация** (`preregistration.md`, раздел 2): ковариаты — возрастная группа, пол, намаз,
  опыт чтения, родной язык **[утвердить]**.
- Откат миграции 0013 теряет имена и пропуски (подробнее — в самой миграции).

## Как проверить

`tests/integration/test_bot_flow.py` (путь экран за экраном, имя текстом, устаревшая кнопка),
`tests/integration/test_cohorts.py` (в датасете, представлении и отчёте нет имени; группы < 5 скрыты;
поиск по номеру), `tests/integration/test_sql_repositories.py` (имя в отдельной таблице, каскад).

# ADR-0029: «Как читается» под спойлером и разбор ошибок для новичка

- **Статус:** Принято
- **Дата:** 2026-10-17
- **Кто решил:** автор (варианты предложил агент)
- **Связано:** FR-21, FR-43, M-09, M-10, M-16, ADR-0024, SRC-021, SRC-022, SRC-051

## Контекст
Ученики учат чтение с нуля (`audience.md`). Объяснение говорило, *что* не так, но не *что делать*:
подсказка «как сказать» была только у перепутанных букв, место ошибки — «во 2-м слоге», в
транскрипции — значки МФА (ħ ʿ θ ð), мадд на 4–6 счётов выглядел как «ииииии», семь символов
фонетизатора не были описаны. До отправки транскрипции не было, после — только «Услышано», без
«Как надо». Подпись к фото в Telegram — до 1024 символов. Методика M-09: преподаватели советуют не
учиться по транскрипции (SRC-021, SRC-022).

## Решение
1. **Карточка:** «🔤 Как читается» — **под спойлером**: ученик сначала пробует прочитать буквы сам и
   подсматривает, только если не знает. Чтение — полное, со всеми огласовками (васл), от
   фонетизатора quran-transcript с теми же параметрами, что у проверки.
2. **Результат:** «Нужно» и «У тебя» по слогам, слог с ошибкой подчёркнут; **каждая** ошибка —
   что не так, в каком слоге (транскрипцией) и «👄 Как сказать»; в конце один план: послушай 🔊
   (если есть эталон) → скажи слоги медленно 3 раза → прочитай строку. С ошибками — два сообщения:
   фото с вердиктом и сравнением, потом текст с разбором и кнопками.
3. **Транскрипция** — по научной русской системе Крачковского (SRC-051), упрощённой: точка снизу —
   твёрдые и горловые (с̣ д̣ т̣ з̣ х̣ к̣ г̣), черта снизу — межзубные (с̱ з̱), ‘ — айн, ’ — хамза,
   һ, ў, н̃ м̃ (ихфа); долгий гласный — двумя буквами; пояснения — только к значкам этой строки.
4. **Слоги:** согласная + её гласные; согласная без гласной закрывает предыдущий слог («баб», «раб-ба»).

## Рассмотренные варианты
| Вариант | Плюсы | Минусы | Итог |
|---|---|---|---|
| Транскрипция открыто везде | проще всего | ученик читает транскрипцию, а не буквы (M-09) | отклонено |
| Только после отправки | строже всего по методике | новичку не с чем свериться до попытки | отклонено |
| **Спойлер на карточке + сравнение после** | сначала попытка сама, подсказка по касанию | одна лишняя строка на карточке | **выбрано** |
| Подробно только главная ошибка | короче экран | автор хочет разбор каждой | отклонено автором |
| **Все ошибки подробно + один план** | ничего не скрыто; план не повторяется | длинно → второе сообщение | **выбрано** |
| Практическая транскрипция (как в дуа) | привычно | ص и س обе «с» — ошибку в сравнении не видно | отклонено |
| МФА (было) | точно | новичку непонятно | отклонено |
| **Крачковский, упрощённый** | научная русская традиция; различия видны | значки нужно пояснять | **выбрано** |
| Деление по словам / только после сукуна | короче | место ошибки неточное; «катаба» без деления | отклонено автором |
| Обрезать подпись по символам | просто | обрыв внутри HTML-тега — Telegram отвергает сообщение | отклонено: укорачиваем по слогам |

## Последствия
- Формулировки, подсказки и таблицу нужно сверить с преподавателем таджвида (TD-FN-30).
- В длинных строках нет границ слов — фонемы приходят без пробелов (TD-FN-31).
- Черновики kk/en работают по-старому (новые поля YAML необязательны).

# ADR-0014: Ошибки хранятся структурой, текст строится отдельно

- **Статус:** Принято; заменяет подход прототипа (ошибки только как текст)
- **Дата:** 2026-10-17
- **Кто решил:** предложил агент, утвердил Исмаилов
- **Связано:** FR-05, FR-11

## Контекст
В прототипе `explain()` сразу возвращала русские фразы. Посчитать «как часто путают ص и س» можно было
только разбором текста.

## Решение
`domain.assessment.assess()` возвращает `PronunciationError(kind, position, syllable, expected, heard)`;
`application.feedback.FeedbackRenderer` превращает их в те же фразы, что в прототипе (проверено тестами).
В БД сохраняются и структура, и показанный текст.

## Последствия
Отчёт «матрица путаниц» — один SQL-запрос. Текст можно менять, не теряя сопоставимости данных.

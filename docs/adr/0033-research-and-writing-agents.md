# ADR-0033: Агенты для исследования и текста диссертации

- **Статус:** Принято
- **Дата:** 2026-10-18
- **Кто решил:** Исмаилов (выбрал все четыре агента из предложенных). Состав и правила агентов
  предложил агент.
- **Связано:** ADR-0012 (обвязка агента), ADR-0021 (протокол решений), ADR-0026 (GQM),
  SRC-004, SRC-030, SRC-031, SRC-043

## Контекст
Семь субагентов (ADR-0012) закрывают цикл разработки: тесты, код, ревью архитектуры и
безопасности, методика, данные, летопись. Впереди этап 1 roadmap: пилот, разметка, RQ-1…RQ-3,
текст глав и статья. Для них агентов не было: цифры качества модели считались без протокола
сопоставимости с IqraEval, текст глав никто не писал, источники не сверялись с первоисточниками,
текст никто не читал глазами оппонента.

## Решение
Добавить четыре проектных субагента в `.claude/agents/`:

| Агент | Задача | Может менять |
|---|---|---|
| `asr-evaluator` | протокол оценки модели, метрики RQ-1/RQ-2 с ДИ, сопоставимость с IqraEval | `analytics/`, `docs/research/`; код — только спецификацией для `/feature` |
| `thesis-writer` | черновики глав из материалов репозитория, каждое утверждение со ссылкой | `docs/thesis/chapters/` |
| `citation-verifier` | сверка `sources.md`/`sources.bib` и ссылок с первоисточниками, ГОСТ Р 7.0.5 | ничего (отчёт) |
| `thesis-opponent` | чтение главы как оппонент: угрозы валидности, выводы без данных, вопросы | ничего (отчёт) |

## Рассмотренные варианты
| Вариант | Плюсы | Минусы | Итог |
|---|---|---|---|
| Готовые наборы с GitHub (VoltAgent/awesome-claude-code-subagents, wshobson/agents) | сотни агентов, бесплатно | общие шаблоны под бизнес-разработку («business insights», «p<0.05»), ссылки на несуществующие инструменты (context manager, платный BGPT MCP), не знают проекта и его запретов | Отклонено |
| Расширить `data-analyst` и `thesis-scribe` | меньше агентов | смешивает SQL-отчёты с оценкой модели и сбор материалов с написанием прозы; у ревьюера и автора текста разные права | Отклонено |
| Четыре отдельных проектных агента | роли и права разделены, правила проекта внутри (`data/` не читать, не выдумывать источники, человек утверждает пороги) | ещё четыре файла поддерживать | **Принято** |

## Последствия
- Каждая цифра для главы 4 проходит через один протокол (`asr-evaluator`), с ДИ и n.
- Черновики глав появляются в `docs/thesis/chapters/`; голос и структуру утверждает человек.
- Два ревьюера только читают и не могут «исправить» текст под себя.
- Глава 3: новые агенты — данные для Q6.2 (сколько вмешательств человека нужно на текст).
- Наборы скиллов (academic-research-skills, K-Dense, humanizer) установлены у автора глобально,
  вне репозитория; агенты от них не зависят.

## Как проверить
Файлы `.claude/agents/{asr-evaluator,thesis-writer,citation-verifier,thesis-opponent}.md` есть и
перечислены в `docs/process/agent-harness.md`; у ревьюеров в `tools` нет `Edit`/`Write`.

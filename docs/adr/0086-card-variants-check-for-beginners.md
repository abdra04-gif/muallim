# ADR-0086: Проверка «варианты карточки» — что ученик видит и что бот проверяет

- **Статус:** Принято автором 2026-11-19; в коде бота ещё не сделано (опыт на Muaalem проведён, п. 7; следующий шаг — переводчик текста в звуки, затем `/feature`)
- **Дата:** 2026-11-19
- **Кто решил:** автор; варианты, плюсы и минусы — агент (протокол ADR-0021)
- **Связано:** ADR-0051, ADR-0064, `docs/research/PHASE_3_EXPERIMENTAL_RESULTS.md` §11.8b–11.8d, `docs/research/ERROR_RULES_DRAFT.md`, SRC-164 (HAFSS)

## Контекст
Сейчас бот записывает звуки моделью Muaalem и сравнивает строку с эталоном. На 840 записях отдельных
слогов он засчитал бы 14 из 100, чаще всего ругая за протянутую гласную (§11.8a). Опыты фазы 3
сравнили четыре способа; «варианты карточки» — верное чтение против короткого списка типичных ошибок,
модель выбирает, на что запись похожа больше, — засчитывает 76 из 100 слогов без обучения и
работает для всей книги, а не только для 84 слогов (§11.8c, §11.8d).

## Решение
1. **Ученик видит только ответ «вариантов карточки».** Остальные способы считаются молча; учитель видит
   все рядом и отмечает, кто прав (данные для оценки и будущего обучения).
2. **Что проверяется строго:** огласовка, похожая буква, пропуск гласной, лишняя гласная на сукуне.
3. **Шадда и мадд — мягко:** бот подсказывает («похоже, не удвоил — послушай образец»), но не говорит
   «ошибка»: модель хуже различает их (89–91 из 100) и не меряет длину звука (§11.8b).
4. **Протяжная гласная на отдельной букве — никогда не ошибка.**
5. **Таджвид автоматически не проверяется** (гунна, идгам, ихфа, икляб, калькаля, виды мадда): это
   уровень продвинутых, новичка частые «ошибка» отбивают от занятий. Остаётся учителю.
6. **Три ответа:** верное чтение явно победило — «засчитано»; ошибка явно победила — «ошибка» с местом
   (слог) и что исправить; спорно — «скажи ещё раз». Границы — **[утвердить]** на 200 записях с учителем;
   до этого — допуск из опыта на фразах. **Уточнено ADR-0087 п. 4:** строгие 0 / −4, повтор не больше
   одного раза, соперник «другой слог».
7. **Модель:** сначала тот же опыт на Muaalem. Если не хуже MostafaMaroof — одна модель; иначе
   MostafaMaroof добавляется вторым адаптером за тем же портом.
   **Итог опыта (2026-11-19, PHASE_3 §11.8c-bis):** на 840 слогах Muaalem засчитывает 62 из 100 верных,
   MostafaMaroof — 76; «не та огласовка» проскакивает 8 и 3 из 100. Muaalem хуже → для «вариантов
   карточки» берётся MostafaMaroof вторым адаптером; Muaalem остаётся для остального.
   **Уточнено ADR-0087 (2026-11-19):** после сравнения на 200 аятах (§11.8e) MostafaMaroof — единственная
   модель для новичков на всю книгу; Muaalem будет выключена для новичков и ждёт режима таджвида.
8. **Тексты ученику:** готовые объяснения из `curriculum/feedback.ru.yaml` по видам ошибок (место и
   «как сказать» там уже есть) + 2–3 новые фразы (мягкая подсказка про шадду и мадд, «скажи ещё раз»)
   — черновик агента, утверждает автор.

## Отклонено
| Вариант | Почему нет |
|---|---|
| Ученик видит два ответа (два способа) | новичок запутается, если ответы спорят |
| Строго проверять шадду и мадд | модель хуже их различает и не меряет длину — будет ругать зря |
| Проверять таджвид автоматически | для новичка слишком строго; модель не меряет длину и носовость |
| Только строгий порог (всегда «верно» или «ошибка») | на фразах поругал бы зря каждого третьего |
| Написать все тексты ученику заново | почти не лучше готовых: место ошибки и «как сказать» уже есть |
| Сразу заменить Muaalem | Muaalem лучше знает Коран и даёт признаки звуков; сначала проверить |

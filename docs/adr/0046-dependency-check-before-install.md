# ADR-0046: Каждая новая библиотека проверяется на PyPI до установки (хук dep_check)

- **Статус:** Принято
- **Дата:** 2026-10-18
- **Кто решил:** автор поручил («библиотеки проверить, чтоб были настоящие, и всегда проверял перед добавлением»); реализацию выбрал агент
- **Связано:** ADR-0034 (хуки), ADR-0042 (deptry, zizmor), NFR-SEC-06, TD-SEC-23, R-15

## Контекст
Код пишет в основном агент (R-15). Языковые модели иногда называют пакеты, которых нет, а злоумышленники
регистрируют такие имена и имена-опечатки популярных пакетов (slopsquatting, тайпсквоттинг).
До решения новую зависимость останавливал `human_zones` («подтвердите установку»), но человек видел
только команду — без сведений, настоящий ли это пакет.

Аудит 2026-10-18: все 27 объявленных пакетов существуют на PyPI и ведут в официальные репозитории.
Найдено другое: `transformers 4.57.6` (extra `ml`) с известными уязвимостями, а `pip-audit` в CI их не видит —
CI ставит пакеты без `ml` (TD-SEC-23).

## Решение
Хук `PreToolUse` `.claude/hooks/dep_check.py` на `uv add`, `pip install`, `poetry add` и новые строки
зависимостей в `pyproject.toml`:
1. Пакета нет на PyPI → **блок**: имя, скорее всего, выдумано.
2. Пакет есть → человеку в запросе подтверждения показывается карточка: версия, год первого выпуска,
   репозиторий, число уязвимостей последней версии (OSV) и тревожные признаки — моложе 90 дней,
   нет репозитория, нет описания, имя похоже на уже подключённую зависимость.
3. PyPI недоступен → не блок, а просьба проверить вручную.
Решение о зависимости по-прежнему за человеком (CLAUDE.md); хук только даёт ему факты.

## Рассмотренные варианты
| Вариант | Плюсы | Минусы | Итог |
|---|---|---|---|
| **Хук с проверкой PyPI + OSV** | ловит выдуманные имена до установки; человек видит факты; без зависимостей | нужна сеть; признаки эвристические | **выбран** |
| Только правило в CLAUDE.md | ничего не писать | агент забывает правила (R-15) | отклонён |
| Белый список пакетов | строго | каждую новую библиотеку вносить руками; не говорит, *почему* пакет плох | отклонён |
| Сторонний сканер (Socket, Phylum) | глубже анализ кода пакета | внешний сервис и учётная запись; для одного автора избыточно | отклонён (вернуться при команде) |

## Последствия
- `uv add <выдуманное>` не выполнится; настоящий пакет — с карточкой в запросе подтверждения.
- Журнал хуков (`docs/journal/hooks/`) фиксирует каждую проверку — данные для главы о методике агентов.
- Уже установленные пакеты хук не проверяет: для них — `make audit` (pip-audit) и TD-SEC-23.

## Как проверить
- `tests/architecture/test_dep_check.py`: разбор команд, новые строки pyproject, похожие имена, признаки риска (без сети).
- Вручную: `echo '{"tool_name":"Bash","tool_input":{"command":"uv add nesushchestvuyushchiy-paket"}}' | python3 .claude/hooks/dep_check.py` → код 2.

# ADR-0037: Текст диссертации в LaTeX, приватный GitHub как резервная копия

- **Статус:** Принято
- **Дата:** 2026-10-18
- **Кто решил:** Исмаилов (выбор: приватный GitHub, LaTeX → PDF; вуз — Университет Иннополис,
  магистратура «Программная инженерия», сдача ≈ июнь 2027). Каркас и проверки предложил агент.
- **Связано:** ADR-0036 (отпечаток версии), TD-FN-27, TD-FN-14, TD-SEC-04, SRC-040

## Контекст
Проект существовал в единственной копии на ноутбуке: Time Machine не настроен, коммитов не было
(TD-FN-27). Глав диссертации ещё нет; оформление по требованиям Иннополиса, которые в открытом
доступе не найдены (свободный двуязычный титул встречается в публичных работах выпускников).

## Решение
1. **Приватный репозиторий** `abdra04-gif/muallim` на GitHub, ветка `main`. В git не попадают
   `data/`, `.env`, скан книги (`.gitignore`); перед коммитом — pre-commit с gitleaks и
   проверкой ключей (`uv run pre-commit install`). Коммит и push — по-прежнему решение человека.
2. **LaTeX** в `thesis/`: xelatex + biber, библиография — тот же `docs/research/sources.bib`,
   рисунки — прямо из `docs/architecture/diagrams/`, арабский — шрифт карточек бота.
   `make thesis`, `make thesis-check`. Язык основного текста — один переключатель (`\mainlang`).
   Черновики глав — сразу в `thesis/chapters/*.tex` (не в `docs/thesis/chapters/`).
3. **poppler** (системно, brew) — без него агенты не открывают страницы PDF: нужен
   `book-proofreader` (скан книги) и чтение статей.

## Рассмотренные варианты
| Вариант | Плюсы | Минусы | Итог |
|---|---|---|---|
| Снимок в iCloud по расписанию | без git | нет истории; iCloud вне РФ — только без `data/` | Отклонено автором |
| Time Machine на внешний диск | полная копия, вместе с `data/` | нужен диск; копия рядом с ноутбуком | Рекомендуется дополнительно для `data/` (TD-FN-14) |
| Markdown → Word (pandoc) | Word удобен руководителю | автор выбрал LaTeX | Отклонено автором |
| Взять сторонний шаблон диссертации | готовая вёрстка | официальный шаблон вуза не найден; чужой шаблон потом всё равно переделывать | Отклонено: свой минимальный каркас, заменяется официальным одной правкой преамбулы |

## Последствия
- TD-FN-27 закрыт: у кода есть история; `make trace` может добавить хеш коммита к отпечатку.
- Голоса и БД (`data/`) по-прежнему только на ноутбуке — нужна отдельная зашифрованная копия
  (TD-FN-14, T1 перед пилотом).
- Первый push требует права `workflow` у токена `gh` (`gh auth refresh -s workflow`).
- В CI на GitHub пока красный тест про нарезки Хусари (`curriculum/audio/husary/` ещё не создан).
- Требования вуза к оформлению и языку не подтверждены — `thesis/README.md`.

## Как проверить
`git ls-files` не содержит `data/`, `.env`, `book/*.pdf`; `make thesis-check` собирает PDF без
ошибок, арабские огласовки видны; `make thesis` собирает каркас.

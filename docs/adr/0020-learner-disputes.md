# ADR-0020: Кнопка «Бот ошибся» — ученик сам помечает спорные проверки

- **Статус:** Принято; номер попытки под каждым результатом заменён ADR-0057 — ученик видит номер в «🚩 Бот ошибся», под результатом — только учитель и разметчик
- **Дата:** 2026-10-17
- **Кто решил:** предложил агент, утвердил Исмаилов
- **Связано:** FR-23, FR-13, `docs/data/annotation-guide.md`

## Контекст
Разметчик не может прослушать всё. Ложные срабатывания — главный риск автоматической обратной связи
(точность детекторов ошибок ~60 %, SRC-025, SRC-026). Ученик лучше всех знает, где бот был несправедлив.

## Решение
- Под каждым результатом — номер попытки и кнопка «🚩 Бот ошибся» с выбором причины:
  «я прочитал правильно», «ошибка указана не та», «другое».
- Жалоба сохраняется в `learner_reports`; попытки с жалобами идут **первыми** в очередь разметки.
- Отчёт `07_learner_disputes.sql` — какие карточки и типы ошибок оспаривают чаще.
- Ученик видит свой ID (/me) — по нему можно найти его данные по запросу.

## Ограничения
Жалоба — не истина: её проверяет разметчик. Доля жалоб — сигнал, а не метрика точности.

# ADR-0017: Объяснения ошибок на выбранном языке

- **Статус:** Принято; частично заменяет ADR-0009
- **Дата:** 2026-10-17
- **Кто решил:** Исмаилов (требование), реализацию предложил агент
- **Связано:** FR-22, ADR-0009, TD-FN-01, TD-FN-08

## Контекст
Ученики — из России и Казахстана. Объяснение ошибки полезно на родном языке ученика.

## Решение
- Шаблоны сообщений об ошибках — `curriculum/feedback.<язык>.yaml`, словарь звуков и подсказок —
  `curriculum/lexicon.<язык>.yaml`. Язык включается флагом `enabled: true` (ставит человек).
- *(2026-10-17, ADR-0022: пока только русский — команда /language скрыта, черновики в `curriculum/drafts/`.)*
- Ученик выбирает язык командой /language; по умолчанию — язык Telegram, если он включён, иначе `ru`.
- В каждую попытку пишется `feedback_language` — для анализа «помогает ли родной язык» (RQ-3).
- Русский — эталон (формулировки прототипа). Казахский и английский — **черновики агента,
  выключены** до проверки носителем и преподавателем.
- Интерфейс (кнопки) пока на русском — TD-FN-01.

## Рассмотренные варианты
| Вариант | Итог | Причина |
|---|---|---|
| Fluent / aiogram-i18n для всего | Отложено | интерфейс — потом; объяснения — это учебный контент, им место в `curriculum/` |
| Машинный перевод на лету | Отклонено | ошибки в описании звуков дойдут до учеников, нельзя проверить заранее |
| YAML-шаблоны на язык, включает человек | **Принято** | контент под контролем человека, версии в git |

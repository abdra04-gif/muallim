# ADR-0058: Шаги урока, «Продолжить» и начало занятия — ответы бота не противоречат карточке

- **Статус:** Принято; частично заменяет ADR-0024 (точки и подпись «строка k из n» → «шаг N из M»;
  «▶️ Продолжить» — по правилу ниже)
- **Дата:** 2026-10-20
- **Кто решил:** автор (UX-обход новичком, пакет А; формулировки и выбор вариантов — в сессии 2026-10-20);
  добавления агента утверждены автором («Оставить всё»)
- **Связано:** FR-49, FR-50, FR-39, FR-45, M-12, ADR-0024, ADR-0050, SRC-136, US-U-07, US-U-08, US-U-10

## Контекст
Обход бота глазами новичка нашёл, где бот противоречит сам себе: голосовое на карточке-правиле
проверялось как чтение; «Продолжить» после пройденного урока возвращал на его последний шаг; первая кнопка
«Начать с алфавита» открывала урок с истиазой; замок «Закрепления» говорил «урок 3 и дальше», даже если
ученик уже там; голосовое на главной проверялось по карточке, которой нет на экране; начало занятия
(истиаза, басмала) сдвигало «Продолжить» на урок 1; «строка 3 из 5» на карточке-правиле, где строки нет;
у истиазы обещан 🔊, а записи не было. Ученик, у которого строка не получается, застревал.

## Решение
1. **Шаги.** Карточки урока — «шаг N из M» (правило, таблица, чтение); в прогрессе — «повторить шаги: …».
2. **«Продолжить»** (`GetProgress._continue`): курсор ученика; если это последний шаг урока и урок
   засчитан, **или** по шагу есть попытка (даже незасчитанная), **или** читать на нём нечего — первый шаг
   следующего урока (автор: «Да, в следующий»). На последнем уроке книги — остаёмся.
3. **Не получается — можно дальше.** После незасчитанной попытки — та же кнопка «▶️ Дальше»; строка
   остаётся в «повторить» (FR-07). Урок пройден, как и раньше, когда засчитаны все строки (M-12).
4. **Голосовое не по месту.** На карточке-правиле — «это правило, нажми ▶️ Дальше»; когда открыта главная или
   другое меню — не проверяется: подсказка «открой урок» и кнопка «Продолжить» (автор). Что на экране —
   в FSM (`presentation/telegram/on_screen.py`, ADR-0049); нет записи (старая сессия) — как раньше.
   Текст вместо голосового не присылает главную заново.
5. **Начало занятия** не сдвигает «Продолжить»: истиаза и басмала проверяются по своей карточке
   (`AssessRecitation.execute(..., item_id=)`), курсор ученика на месте (добавлено агентом, утверждено).
6. **Кнопки.** Первая — «▶️ Начать первый урок»; листание — «▶️ Дальше»; назад — одна кнопка: на первом шаге
   «⬅️ Предыдущий урок», на остальных — «Назад» на шаг; на последнем шаге — «➡️ Следующий урок: …».
7. **Замок «Закрепления»** называет урок, на котором откроется (`domain.quiz.first_quiz_lesson`): «когда
   начнёшь урок N»; если ученик уже на нём или дальше — «прочитай хотя бы по строке в двух уроках с
   буквами». Отвлекающие варианты вопроса — сначала та же буква с другими огласовками, затем начатые буквы,
   ближайшие по книге (без случайности, вопрос восстанавливается по кнопке; решение автора 2026-10-20).
8. **🔊 истиазы** (L001-02) — Хусари, муратталь, EveryAyah (SRC-136): строка `manual` в
   curriculum/audio/husary/cuts.yaml, `status: unchecked` (автор: «пусть играет как есть»; что это
   муратталь, а не муаллим, — известно, «подходит»). `scripts/audio/cuts_manifest.py` при пересборке не
   теряет и не перезаписывает ручные строки.
9. Счётчики уроков на всех экранах считаются одинаково. Тексты — `texts.py`, утверждены автором 2026-10-20.

## Рассмотренные варианты
| Вопрос | Вариант | Плюсы | Минусы | Итог |
|---|---|---|---|---|
| Кнопка после неудачи | «▶️ Дальше» (как везде) | одна кнопка, не стыдит | ученик может не заметить, что строка не засчитана | **принято** (автор) |
| | «⏭ Дальше — вернусь позже» | явно говорит, что строка отложена | длинно; новичок читает как «провал» | отклонено автором |
| | не пускать дальше, пока не засчитано | строже к качеству чтения | новичок застревает и бросает | отклонено (ограничение для буквы урока — пакет В, FR-52) |
| «Продолжить» на последнем шаге | в следующий урок, если шаг пробовали (даже неверно) или он без чтения | ученик не ходит по кругу | урок может остаться не пройден | **принято** (автор: «Да, в следующий») |
| | только если урок засчитан | честнее к M-12 | застревание на трудной строке | отклонено |
| | всегда остаётся на последнем шаге (как было) | просто | после пройденного урока «Продолжить» ведёт назад | отклонено |
| Голосовое на главной | подсказка + кнопка «Продолжить» | нет проверки «вслепую» по невидимой карточке | одно лишнее нажатие | **принято** (автор) |
| | проверять по карточке курсора (как было) | меньше нажатий | ученик не знает, что именно проверено | отклонено |
| 🔊 истиазы | Хусари с EveryAyah, муратталь (SRC-136) | есть сейчас; тот же чтец, что и остальные эталоны | муратталь, а не муаллим (медленное чтение) | **принято** (автор) |
| | запись учителя | эталон «как на уроке» | записи сейчас нет | отклонено автором на сейчас; пересмотреть, когда учитель запишет (FR-30 заменит файл) |
| | убрать обещание 🔊 | честно, без работы | у новичка нет образца первой же строки | отклонено автором |
| Замок закрепления | «когда начнёшь урок N» | понятно, куда идти | N считается из программы (функция + тест) | **принято** (автор) |
| | «урок 3 и дальше» (как было) | просто | неправда, если ученик уже там | отклонено |

## Последствия
- M-12 (`docs/pedagogy/methodology.md`) дополнен: «дальше» можно и без зачёта; «урок пройден» не изменился.
- Строки с ошибкой копятся в «повторить»: возвращать к ним — пакет В (FR-52, «🔁 Повторение»).
- Состояние «что на экране» хранится в FSM: после перезапуска бота без хранилища FSM — поведение как раньше.
- Звук истиазы не проверен человеком (`unchecked`) — проверить вместе с другими нарезками Хусари.

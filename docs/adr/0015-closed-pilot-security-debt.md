# ADR-0015: Закрытый пилот на себе и знакомых; часть требований безопасности — в техдолг

- **Статус:** Принято
- **Дата:** 2026-10-17
- **Кто решил:** Исмаилов
- **Связано:** `docs/tech-debt.md` (TD-SEC-*), ADR-0010, SRC-033, SRC-036, SRC-037

## Контекст
Исследование правовых требований (сводный отчёт, SRC-038) показало большой объём работы: уведомление
Роскомнадзора, согласие отдельным документом, локализация в РФ и РК, правила Telegram для ML-данных,
шифрование. Для первых проверок бота это блокирует разработку.

## Решение
Первая фаза — **закрытый пилот**: автор и знакомые, которые лично уведомлены о целях и о записи
голоса. Требования безопасности и права, не нужные для такой фазы, вынесены в `docs/tech-debt.md`
с триггером **T1 «до первого ученика вне круга знакомых»**. Технические меры, которые уже есть
(псевдонимы, согласие кнопкой, удаление данных, права 0600, хуки), остаются.

## Рассмотренные варианты
| Вариант | Итог | Причина |
|---|---|---|
| Закрыть все требования до первого запуска | Отклонено | недели работы до первой проверки идеи |
| Не записывать долг, «потом разберёмся» | Отклонено | через год никто не вспомнит, что именно отложено |
| Закрытый пилот + явный реестр долга с триггерами | **Принято** | |

## Последствия
- Данные закрытого пилота **не используются** в публикациях без закрытия TD-SEC-01, -02, -09.
- Перед расширением круга — пройти таблицу T1 целиком.

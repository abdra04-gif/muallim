# ADR-0018: Эталонное аудио «как правильно» — записи человека, не синтез

- **Статус:** Принято
- **Дата:** 2026-10-17
- **Кто решил:** Исмаилов (требование), выбор источника звука предложил агент
- **Связано:** FR-20, TD-FN-05, `docs/pedagogy/teaching-practice.md` §3–4

## Контекст
Во всех курсах по книге урок начинается с образца: «услышать → повторить» (SRC-021, SRC-022);
принцип наглядности Максуди (SRC-015). Без образца ученик учится по транскрипции, от чего преподаватели
прямо предостерегают.

## Решение
- Порт `ReferenceAudioLibrary`; реализация читает `curriculum/audio/<id карточки>.ogg` (OGG/Opus —
  формат голосовых Telegram).
- Кнопка «🔊 Как правильно» на карточке и после попытки — только если файл есть.
- Каждое прослушивание пишется в журнал событий (`reference_played`) — данные для RQ-3
  («слушал ли образец перед удачной попыткой»).
- Кто, когда и с какой лицензией записал — `curriculum/audio/SOURCES.md`.

## Рассмотренные варианты
| Вариант | Итог | Причина |
|---|---|---|
| Синтез речи (TTS) для арабского | Отклонено | качество огласовок и махраджей не гарантировано; ошибка образца хуже его отсутствия |
| Нарезка из записей чтецов (EveryAyah и др.) | Отложено | отдельные буквы и слоги книги в Коране не встречаются; лицензии записей не проверены |
| Записи преподавателя/чтеца по карточкам | **Принято** | контролируемо, соответствует таляккы |

# ADR-0024: Интерфейс ученика — «одно окно», строка книги картинкой, подсветка ошибок, прогресс уроков, эталон от учителя

**Статус:** Принято (пробная версия — будет меняться по отзывам); частично заменено ADR-0057 (текст строки и «Для исследования» — только учителю и разметчику), ADR-0058 («шаг N из M», «Продолжить»), ADR-0059 (холст 900 px)
**Дата:** 2026-10-17
**Кто решил:** автор (замечания после первой проверки бота), варианты — агент

## Контекст (что не понравилось автору)
1. «▶️ Дальше» на последней карточке не вёл в следующий урок (листал по кругу внутри урока).
2. Плохо видно, что читать: арабский текст в Telegram мелкий, огласовки теряются.
3. Каждая кнопка присылала новое сообщение — чат уезжал вниз, начало приходилось искать.
4. Нет кнопки «на главный экран», нет отметки пройденных уроков, нельзя услышать, как правильно.
5. Книга начинается со всего алфавита (с. 10), а бот — с хамзы.

## Решение
- **Урок 1 — таблица алфавита** (4 строки с. 10 с названиями букв из книги), без проверки голосом
  (тип карточки `alphabet`); дальше хамза и буквы по одной — 29 уроков, 131 карточка.
- **Переход дальше — сквозной** по программе: последняя строка урока → первая строка следующего
  (`Curriculum.next_item`), на результате — «➡️ Следующий урок: …».
- **Одно окно:** кнопки редактируют то же сообщение (`edit_media` / `edit_text`); новое сообщение — только
  для /команд и результата голосового; у прошлого экрана кнопки снимаются.
- **Строка книги — картинка** (Pillow + libraqm, шрифт Scheherazade New): крупно, буква урока красным,
  как в книге; точки «строка k из n». На результате неверные буквы — красные на розовом, полоса сверху — оценка.
- **Прогресс:** статус урока (новый / начат / пройден — все строки засчитаны), карта букв на главной,
  ✅/🟡/⚪ в списке уроков (по 10 на страницу), «🎉 Урок пройден», серия дней подряд, «▶️ Продолжить».
- **🏠 Главная** на каждом экране; /help «Как заниматься» — цикл урока по `teaching-practice.md` §4.
- **Эталон «как правильно» записывает учитель прямо в боте:** `TEACHER_IDS` в `.env` → кнопка
  «🎙 Записать эталон» → голосовое сохраняется как `curriculum/audio/<id>.ogg` (`RecordReference`).

| | текст жирным | просто | мелко, без цвета | запасной режим без libraqm |

| Подсветка буквы | **перекраска полосы по границам буквы** (ширина префикса + ZWJ) | соединения букв верные | на стыке краснеет кусочек соседней связки | ✅ |
| | рисовать буквы по отдельности | точный цвет | ломает соединения и огласовки | ❌ |

| | новое сообщение на каждый шаг | просто | чат уезжает вниз (жалоба автора) | ❌ |

## Взято у других
- **Tarteel:** ошибки подсвечены прямо в тексте (красный); история частых ошибок — уже есть в отчётах 08–10.
- **Duolingo:** карта уроков с отметками, «продолжить», серия дней, празднование пройденного урока.

## Последствия
- Новая зависимость Pillow; в Docker и CI — `libfribidi0`; на macOS — `brew install fribidi` (Makefile сам подставляет путь).
- Новая версия программы `2026.10.17-book-2` (id карточек сдвинулись: L01 — алфавит).
- Состояние «ждём эталон от учителя» и кэш картинок — в памяти процесса (TD-FN-15).
- Длинная строка «разбавляет» ошибки: 2 ошибки в строке из 6 слов → 94% → засчитано. Порог для строк — OQ-12.
- Макеты: `docs/design/README.md`.

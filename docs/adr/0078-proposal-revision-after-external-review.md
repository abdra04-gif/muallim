# ADR-0078: Предложение темы по внешней рецензии — RQ-3 убран, RQ-1 (а/б), RQ-2 при фиксированном бюджете, рамка до таджвида

- **Статус:** Предложено 2026-11-02; **[утвердить]** автором и руководителем
- **Дата:** 2026-11-02
- **Кто решил:** научный руководитель (замечания к рецензии: язык введения ближе к его формулировке, RQ-3
  убрать, «Муаллим ас-Сани» — до таджвида, проверяем махраджи); формулировки — агент по рецензии
- **Связано:** уточняет ADR-0064 (гипотеза, RQ); источники SRC-149…SRC-151

## Контекст
Внешняя рецензия предложения темы (глубокое исследование литературы 2025–2026) предложила: рассматривать
задачу как обнаружение и диагностику ошибок произношения (MDD: эталон → фонемы → выравнивание), а не как
«речь в текст»; сузить новизну («насколько нам известно, нет набора для взрослых начинающих на этапе
букваря с разметкой, где ошибки чтения отделены от ошибок произношения»), признав QVoice (SRC-150);
разделить RQ-1 на ошибки чтения и произношения; сравнивать агента с базовыми подходами при фиксированном
бюджете; делить учеников на обучение / валидацию / тест без пересечений; отчитываться по F1 и по уровням
(буква, слог, слово, текст Корана — SRC-151); RQ-3 сделать разведочным или убрать. Руководитель принял
рецензию с тремя замечаниями (см. «Кто решил»).

## Решение
1. **Введение** — первый абзац по тексту руководителя с исправленной грамматикой; второй — рамка MDD и
   существующие инструменты (Tarteel, QVoice, Quran Muaalem).
2. **RQ-3 убран** вместе с отслеживанием знаний (SRC-124, SRC-125) и тестом учителя в трёх точках.
   Причина: без контрольной группы RQ-3 не отвечает на причинный вопрос (ADR-0064, «Последствия»).
3. **RQ-1:** «…обнаруживают и находят место ошибок взрослых начинающих: (а) ошибок чтения и (б) ошибок
   произношения?»
4. **RQ-2:** «…при фиксированном бюджете экспериментов… по сравнению с заранее заданными базовыми
   конфигурациями». Термин *agentic loop-engineering* заменён на *agentic pipeline optimization*
   («агентная оптимизация конвейера») по рецензии — **[утвердить]**: термин в ADR-0064 выбран руководителем.
5. **Ошибка произношения = ошибка махраджа** (SRC-059). Правила таджвида (гунна, калькала и т. п.) вне
   работы: учебник идёт до таджвида. Примеры (ح → ه, ع → гортанная смычка, ق/ك — неоднозначно) —
   предложены агентом, **[утвердить]** автором.
6. **Базовые подходы B0–B3:** распознавание в текст + сравнение с эталоном; базовая модель IQRA 2026
   (SRC-031, SRC-066); конвейер по образцу Harf-Speech (SRC-149); Quran Muaalem как есть (SRC-002).
   Источник модели B0 (Whisper, дообученный на Коране) ещё не выбран — **проверить** через `/source`.
7. **Вклад:** датасет → бенчмарк → конвейер → инструмент.

## Изменение 2026-11-03: охват проверки — по классификации ошибок, а не «до таджвида»
Руководитель: часть правил таджвида учитывать нужно (калькаля — часть махраджа); перечислить всё, что можно
проверить, указать, что проверяем, и изучить существующие классификации. Вторая рецензия предложила уровни
A–F (чтение → знаки → махрадж → сифаты → контекстный таджвид → уровень чтеца).

Исправлено: п. 5 выше («учебник идёт до таджвида») **неверен** — программа (`curriculum/course.ru.yaml`)
учит мим и нун с сукуном (L054–L069), калькалю (L070), остановку (L086–L088), виды мадда (L090–L093).

Решение (предложено агентом, **[утвердить]**):
1. Обзор классификаций и полный перечень проверяемого — `docs/research/error-taxonomy.md`: классическое
   джали/хафи (SRC-153), Hassan & Zailaini (SRC-152; калькаля — 22 % ошибок «махраджа и сифатов»),
   S/D/I L2-ARCTIC (SRC-154), QuranMB/Iqra'Eval (без таджвида), Quran Muaalem (10 сифатов), QDAT/qdat_bench
   (SRC-155), Tarteel, наш `ErrorKind`.
2. Две оси вместо одной: причина (чтение / произношение — метка преподавателя) и последствие (джали / хафи —
   из наблюдаемого). Разметка: что услышано (замена, пропуск, вставка, неверный признак) + обе метки.
3. Охват: **ядро** — буквы, огласовки, сукун, шадда, танвин, естественный мадд, правила написания, махрадж,
   калькаля, тафхим/тарқиқ; **отдельный отчёт** — гунна, правила мима и нуна с сукуном, формы при остановке,
   прочие сифаты; **вне** — длина производных маддов, сакт, имала, выбор места остановки.
4. В предложении темы абзац «Два типа ошибок» заменён на «Что мы проверяем» с таблицей охвата.

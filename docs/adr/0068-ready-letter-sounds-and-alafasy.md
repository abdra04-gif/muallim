# ADR-0068: Звук «как правильно» — готовые записи букв и слогов, аяты аль-Афаси без тишины

- **Статус:** Принято
- **Дата:** 2026-10-23
- **Кто решил:** автор («мне не нравятся звуки чтеца… давай Мишари Рашид аль-Афаси, его чтение везде»;
  буквы — «ниоткуда не вырезай, выбери одного, кто произносит алфавит целиком»; прослушал образцы:
  «мне нравится новое, берём всё»). Поиск источника, сверку голоса и устройство библиотеки предложил агент.
- **Связано:** ADR-0018 (эталон — человек, не синтез), ADR-0025 (чтец аятов), ADR-0032 (нарезка Хусари —
  звук заменён этим решением), ADR-0066 (ступень ② «Слышу»), SRC-144, SRC-145, TD-FN-98, TD-FN-102

## Контекст
1. Аяты звучали «обучающим» чтением Хусари (SRC-042): после каждого куска пауза ~4 с, чтобы ученик
   повторил. В Telegram это длинное голосовое, где больше тишины, чем звука.
2. Буквы и слоги были нарезаны моделью из аятов (ADR-0032): звук вырван из беглого чтения, на стыке
   слышно соседние звуки. Автору это не понравилось.
3. Готовых записей букв и слогов у аль-Афаси нет (поиск 2026-10-23). У приложений по «Нурании» общий
   источник — чтение Мухаммада Фарука ар-Раи: каждую букву и каждый слог он произносит отдельно, с паузой.

## Варианты
| Вариант | Плюсы | Минусы |
|---|---|---|
| **A. «Нурания» ар-Раи, по файлу на букву/слог** (выбран) | один диктор на весь алфавит; каждый звук сказан отдельно, не вырезан из чтения; есть все 28 букв × 3 огласовки и тройки | лицензия не указана (TD-FN-102); одиночный слог только с проговариванием «ра — фатха — ра» |
| B. Нарезка из чтения аль-Афаси | один голос везде, автоматически | снова звук из беглого чтения — то, что не понравилось (отклонён) |
| C. Записать самим (учитель) | права и методика наши | время автора на ~150 записей; остаётся возможным — запись учителя всегда главнее |
| D. Lingua Libre (Wikimedia Commons, CC BY-SA) | открытая лицензия | ~23 буквы по названию, слогов нет (отклонён) |

## Решение
- **Аяты** — EveryAyah `Alafasy_128kbps` (SRC-145). При скачивании `trim_silence` (ffmpeg, порог −45 дБ,
  0,1 с запаса) срезает тишину в начале и в конце; в кэше лежит уже обрезанный файл.
- **Буквы и слоги** — `curriculum/audio/library/` + `sounds.yaml` (текст карточки → файл, `source`, `origin`,
  `status`), собирает `scripts/audio/library_sounds.py` (`make library-sounds`). Карточка буквы — название
  буквы (урок 1), карточка слога — слог с проговариванием (урок 4), строка из трёх слогов — тройка подряд.
  Файл выбирается **по устройству урока** (5 файлов на букву), а не по подписи: в копии ibr7h подписи
  местами сдвинуты (f4-131 подписан «بَ», а звучит «وَ وِ وُ»). Все файлы уроков 1 и 4 расшифрованы моделью
  Muaalem (буква/огласовка совпадают со структурой); прослушивание человеком — TD-FN-98.
- **Истиаза** — `audhubillah.mp3` аль-Афаси, строка `manual: true`.
- Порядок не изменился: запись учителя → аят целиком → готовая запись. Нарезки Хусари и скрипт
  `husary_cuts.py` удалены (история — в git).

## Последствия
- Ученику имя чтеца не показывается (автор: «не указывать автора, где не обязательно»): аудио — «Как
  правильно», подсказка к сурам — «послушай 🔊». Источники названы в документации и диссертации.
- Голосовые короткие: буква 0,6–1,5 с, слог с проговариванием ~1,7 с, тройка ~1,1 с.
- Строки книги из слов («أَوْ رَوْ نَوْ لَوْ», «مِنْهُ مِنْهُمْ …») звука больше не имеют — до записи учителя.
- Перед пилотом с незнакомыми — разрешение на записи ар-Раи (TD-FN-102).

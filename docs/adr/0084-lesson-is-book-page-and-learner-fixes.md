# ADR-0084: Урок = страница книги, слоги на всех карточках, честная проверка чтения

- **Статус:** принят автором 2026-11-08, реализован (ветка `worktree-book-fixes`)
- **Дата:** 2026-11-08
- **Кто решил:** автор (замечания после прохода бота 2026-11-08); варианты и реализация — агент
- **Связано:** FR-36, FR-49, FR-50, FR-51, FR-53, FR-54, FR-56, FR-57, FR-61, FR-65, FR-66, FR-67, FR-68;
  ADR-0022, ADR-0024, ADR-0057, ADR-0058, ADR-0061, ADR-0074, ADR-0076, ADR-0077, ADR-0081, ADR-0082;
  TD-FN-151, TD-FN-153, TD-FN-166…169

## Контекст
Автор прошёл бота и записал замечания: уроки не совпадают со страницами книги, правило нельзя
проверить голосом, кнопки на разных шагах стоят по-разному, «Верно 4 слова из 5» за чужую строку,
список ошибок суры пропадает, лишние тексты и настройки. Сверка программы со сканом (book-proofreader,
с. 10–85) нашла расхождения в арабском тексте и пропуски.

## Решение
1. **Урок для ученика — страница книги** (с. 10–85, 76 уроков). `Curriculum.pages()` собирает карточки
   по `source.page`; разделы-уроки внутри (прогресс, закрепление, id карточек) не меняются — старые
   попытки и прогресс сохраняются. Начало урока — скан страницы всегда (`PageOpen`, картинки
   `curriculum/book_pages/` (NNN.jpg) вне git, `scripts/book/pages.py`), «▶️ Начать»; «▶️ Дальше» с последнего
   шага — начало следующей страницы. Страницы только с правилом (46, 50, 69, 71) — скан и «▶️ Дальше».
2. **Кнопки:** `[◀️ Назад][🏠][▶️ Дальше]` одним рядом на любом шаге и на результате; 🔊 и 🎬 — обе;
   «📖 Углублённо» → «📖 Подробнее» (с «📄 Страница книги» и 🏠); «📖 Вся сура» → «📜 Вся сура».
3. **Правило:** на карточке — первый абзац; огласованный текст правила проверяется голосом
   (`LessonItem.is_checkable`, в прогресс не входит). Образцы без огласовок (с. 35–37) —
   `ItemKind.SAMPLE`, только посмотреть.
4. **Слоги с подписью на всех карточках** чтения (`curriculum/syllables/ayat.yaml`, 817 строк), буква
   урока красная, номер аята — только в сурах. Разметка (FR-62) — по-прежнему слоги только сур
   (`SuraSyllables`). Подпись видна при «Закрыта» и «Видна сразу»; «Не показывать» — строка целиком.
5. **Проверка чтения:** неверны все слова, которые накрывает ошибка; если совпало согласных < 20 %
   (`GradingPolicy.other_line_threshold`) — «🤔 Похоже, прочитана другая строка…» над разбором (разбор —
   всегда, решение автора).
6. **Суры:** список аятов с ошибками хранится (FSM), на карточке аята — «📋 К ошибкам суры»,
   исправленные — ✅.
7. **Анкета** без «Пропустить» и «Как в Telegram» (`QUESTIONNAIRE_VERSION` 2026-11-08). Убраны
   «Автозвук» (колонка осталась, всегда выкл.) и блок «🔬 Для исследования» (и у учителя).
   Закрепление: ✅ на верном ответе и через 1 с следующий вопрос.
8. **Программа по скану:** исправления, одобренные автором (с. 32, 39, 40, 45, 47, 51, 54, 55, 57, 63,
   65, 67), знаки остановки и сакта на с. 64–66 и в 2:2, 2:5 (`scripts/book/build.py`, `MARKS`).

## Отклонённые варианты
- **Перестроить внутренние уроки по страницам** (новые id уроков) — ломает прогресс, закрепление и
  карту букв (они держатся на «урок = буква»); страница — слой поверх разделов.
- **Скрывать разбор при «другой строке»** — автор: «пусть всегда будет разбор».
- **Порог по всем фонемам** — чужая строка набирает 20–30 % на одних гласных; по согласным — около 0.
- **Знак остановки отдельной клеткой** — рисуется пунктирным кружком; знак слитно с концом слова, как в
  мусхафе.
- **Убрать шаг «три слога вместе»** — автор: разбирать всю страницу, ничего не пропускать.

## Последствия
- Заменяет: ADR-0058 и ADR-0024 (кнопки «Предыдущий/Следующий урок»), ADR-0061 В5 (автозвук),
  ADR-0057 (блок для учителя), ADR-0074 (ролик вместо 🔊 и авто-ролик), ADR-0076 («📖 Вся сура»),
  ADR-0081 («Пропустить» и имя из Telegram), ADR-0082 срез 2 (страница книги — реализован, путь другой).
- Порог `other_line_threshold` не пишется в снимок `policy` попытки — пока только для экрана.
- Чего из книги нет — TD-FN-166; перевод Кулиева — TD-FN-167; звук строк книги — TD-FN-168; проверка
  слогов — TD-FN-169.

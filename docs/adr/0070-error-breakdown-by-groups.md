# ADR-0070: Разбор попытки группами для русскоязычного новичка (FR-54, этап 1)

- **Статус:** Принято; тексты экрана и подписи звуков — черновики (утвердить автору, TD-FN-108).
  Частично заменяет ADR-0030 (один пункт на слог, три счётчика), ADR-0031 (до трёх мест, «👄 Подробнее»,
  вариант C пересмотрен и снова отклонён), ADR-0050 п. 2 (плашки слов, «нужна X вместо прозвучала Y»),
  ADR-0062 В3 (форма строки буквы урока)
- **Дата:** 2026-10-24
- **Кто решил:** автор 2026-10-23/24 (обсуждение, макет, решения Р1–Р7, подписи «ха» горлом / «ха» легко);
  устройство (вариант Б), раскладка кода и черновики текстов — агент
- **Связано:** FR-54, FR-43, FR-48, NFR-USE-01, ADR-0017, ADR-0024, ADR-0029, ADR-0030, ADR-0031, ADR-0050,
  ADR-0057, ADR-0062, ADR-0068; SRC-044, SRC-045, SRC-046, SRC-052…SRC-058, SRC-146, SRC-147

## Контекст
Автор 2026-10-23: «на картинке из 3 ошибок показывает одну; объяснение непонятное и длинное; для
русскоязычного новичка; видеть все ошибки». Что нашлось в коде:
- `feedback.explain` убирал повторы через `dict.fromkeys` и терял одинаковые ошибки в разных местах строки;
- картинка (`render._swap`, ADR-0050 п. 2) показывала только первую замену буквы;
- подписи звуков шли значками транскрипции (х̣ һ ħ) — новичку, который учит буквы с нуля, они ничего не говорят;
- на экране было три счётчика сразу: «Точность», «✅ верно N из M слогов», «слов верно N из M»;
- «👄 Подробнее — как сказать» повторяло то же самое для каждой ошибки.

Источники из обсуждения:
- Uchihara, Karas, Thomson — мета-анализы HVPT (SRC-044, SSLA 2025; SRC-045, Applied Psycholinguistics 2024):
  тренировка слуха даёт сильный эффект, перенос на произношение слабее. Поэтому «послушай» стоит первым
  шагом, а пара звуков отложена на этап 2.
- Aljaafreh & Lantolf 1994 (SRC-146): подсказка растёт по шагам — сначала место, объяснение потом.
  Поэтому на экране только место и «нужно / у тебя», «как сказать» — после двух неудач (этап 2).
- Butler 1988 (SRC-147): оценка числом без комментария мотивирует хуже, чем комментарий. Поэтому вместо
  трёх счётчиков один — «Верно N слов из M», а главное на экране — пункты разбора.
- Tarteel (SRC-046): ошибки окрашены прямо в тексте, по касанию — подробности. ELSA Speak: звук окрашен
  цветом. Оттуда взята красная буква на картинке. Для ELSA источник не оформлен (ссылка — проверить, `/source`).
- Korzekwa et al. 2021, <https://arxiv.org/abs/2101.06396> (без SRC — оформить через `/source`): ложные
  тревоги детектора сбивают ученика. Поэтому в тексте не больше двух пунктов, остальное — на картинке.
- SRC-052…SRC-058 (ADR-0031): сначала явные ошибки, потом мадд; мало пунктов; эталон важнее объяснения.

## Решение
**Устройство — вариант Б.**
- `src/muallim/domain/arabic.py` разбирает арабскую строку: кластеры букв, какая буква текста отвечает
  какой согласной эталона, номера слов. Модуль нужен и сценарию, и картинке. `render` реэкспортирует эти объекты.
- `src/muallim/application/breakdown.py` содержит `build_breakdown` → `Breakdown` (`ErrorGroup`, `Place`,
  `words_ok`, `words_total`, `unread`).
- `RecitationResult.breakdown` заполняет `AssessRecitation`.
- Букву урока даёт `domain.curriculum.lesson_letter`, одна функция и для сценария, и для экрана.
- Подписи звуков лежат в `curriculum/lexicon.ru.yaml`, раздел `sounds:` (`say`, `note`, `syllables`) и
  ключ `missing`; читает их `infrastructure/curriculum/yaml_loader.py`.
- Простое чтение слова кириллицей даёт `application/transcription.plain`.

**Группы.** Ключ группы: вид ошибки, нужный звук, прозвучавший. Если один и тот же знак перепутан на разных
буквах, это одна группа. Слоги «фа→фи» и «фа→фу» — разные группы. «N раз» считает места; буква с шаддой —
одно место. Порядок: буква урока, потом явные ошибки, потом мадд; внутри — по строке. Ошибки после места,
где ученик перестал читать, в группы не входят. Огласовка и мадд пропущенной буквы уходят вместе с ней.

**Картинка** (`render.result_marks`, холст 900 px). Красной становится только сама буква, над ней — номер
группы. Внизу легенда: одна строка на группу, «Нужно / У тебя» с крупной буквой и подписью. Строк не больше
`LEGEND_MAX_ROWS` (6), дальше — «…и ещё K» (`texts.LEGEND_MORE`). Ширина + высота ≤ 10000 (предел фото Telegram).

**Текст** (`screens.result`, `texts.py`).
- Пунктов не больше `views.MAX_ERRORS_SHOWN` (2), остальные — «➕ Ещё N — на картинке». Без картинки
  показываются все пункты.
- Каждая строка пункта начинается по-русски:
  - «1️⃣ Буква урока ح (Хэ): нужно «ха» горлом, у тебя «ха» легко (2 раза)»;
  - «Знак над ف — фатха: нужно «фа», у тебя «фи»»; для кясры — «Знак под»;
  - мадд — «… — тяни дольше» / «… — коротко, без растяжки»;
  - «у тебя пропущено», «Лишний звук …», «… — удвой звук (шадда)».
- Вторая строка: «В слове: / В словах:» — слово и его простое чтение кириллицей, не больше трёх слов.
- На экране один счётчик «Верно N слов из M». При 0 и для строки из одного слова его нет.
- «Было → стало» показывается в процентах (решение автора) и только при изменении балла (ADR-0057).
  «✨ Исправлено» показывает подписи групп.
- Остановка: «⏹ Запись закончилась на слове … — дочитай до конца, можно медленно».
- Экран — одно сообщение, если подпись влезает в 1024 знака. Иначе хвост уходит вторым сообщением целиком.

**Подписи звуков** (`sounds:`) написаны простой кириллицей, отличие звука — словом. Автор принял:
ح — «ха» горлом, ه — «ха» легко. Значков х̣ һ ħ θ ʿ нет.

## Рассмотренные варианты
| Вариант | Плюсы | Минусы | Итог |
|---|---|---|---|
| **Б. Разбор строки в domain (`arabic.py`), группы в application (`breakdown.py`), вид в presentation** | группы проверяются без Telegram; сценарий считает «✨ Исправлено» по тем же группам; картинка и текст берут одни данные | новый модуль в domain | **принято** |
| A. Всё в presentation | меньше файлов | сценарий не видит групп («исправлено» пришлось бы считать отдельно); логику не проверить без экрана | отклонено |
| В. Группировка в domain | правило рядом с оценкой | подписи и порядок показа — не правило оценки; domain начал бы зависеть от словаря подписей | отклонено |
| Подписи звуков в `texts.py` / `feedback.ru.yaml` | всё в одном месте | это учебный контент по буквам, а не тексты экрана; `feedback` — полный текст для БД | отклонено → `lexicon.ru.yaml`, `sounds:` |
| Подписи из `sound` карточек курса | уже есть | там значки θа ħа ʿа ðа | отклонено (свести к одной записи — TD-FN-110) |
| Запись звука: «толстые / тонкие», значки арабистов (х̣ с̣ ‘), казахские қ ғ һ, совсем без транскрипции | — | новичку непонятно; казахские буквы не всем | отклонено; автор выбрал «кириллица + пометка словом» |
| Строка «🪤 Русская привычка» | объясняет причину | автору не понравилась | отклонено |
| ⭐ у буквы урока | заметно | в «🧠 Закреплении» ⭐ значит «знаю уверенно» — путаница | отклонено → «Буква урока …» словами |
| Пункт начинается с арабской буквы | короче | Telegram может развернуть строку справа налево | отклонено |
| Кнопка «📋 Все ошибки» | всё видно | после группировки лишняя: картинка показывает все группы | отклонено |
| «👄 Как сказать» на экране результата | подсказка сразу | длинно, повторяется; по SRC-146 подсказка нужна после неудач | убрано; «как сказать» после двух неудач подряд — этап 2 (TD-FN-105) |
| Проценты вместо счётчика слов | привычно | число без смысла для новичка (SRC-147) | отклонено; проценты остались только в «было → стало» |
| Одна ошибка за раз (ADR-0031, вариант C) | максимум фокуса | ученик не видит всех ошибок, а автор просил видеть все | снова отклонено |

## Последствия
- Колонка `detected_errors.message` хранит прежний полный текст объяснения (`renderer.render`). На экране
  он больше не показывается. Описание колонки обновлено в `docs/data/data-dictionary.md`. Для анализа:
  до FR-54 ученик видел этот текст, после — разбор группами.
- Тексты `HEAD_*`, `POINT_*`, `WORDS_*`, `RESULT_WORDS`, `RESULT_UNREAD`, `MORE_ON_IMAGE`, `LEGEND_MORE` и
  раздел `sounds:` — черновики агента. Их должен утвердить автор (TD-FN-108).
- Старый путь разбора остался в коде мёртвым: `feedback.explain`, `RecitationResult.feedback`,
  `expected_reading` и др., `render.result`, `result_words`, `accent_clusters`, `word_states`. Удалить с
  согласия автора (TD-FN-109).
- Этап 2 отложен (TD-FN-105): «👂 пара звуков», «🎯 одно слово», журнал нажатий, «как сказать» после двух неудач.
- Чтение кириллицей (`plain`) не сверено с преподавателем (TD-FN-106). Слог ل с даммой ещё не решён (TD-FN-107).
- Экран с ошибками нельзя пройти через `make try` (TD-FN-111). Проверка — только тестами.

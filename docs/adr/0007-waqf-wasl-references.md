# ADR-0007: Два допустимых эталона — с остановкой (вакф) и слитно (васл)

- **Статус:** Принято (методическое решение, перенесено из прототипа)
- **Дата:** 2026-10-17 (решение принято в прототипе, коммит 695ce27)
- **Кто решил:** Исмаилов
- **Связано:** `docs/pedagogy/methodology.md`, FR-04

## Контекст
Ученик читает отдельное слово. Его можно прочитать с остановкой на конце (огласовка не произносится)
или так, будто чтение продолжается (огласовка произносится). Оба варианта правильные.

## Решение
Распознаватель строит два эталона: с вакфом (`quran_phonetizer(текст)`) и слитный — фонетизация
`текст + " مَ"` без последнего символа. Оценка берётся по лучшему из двух.

## Ограничения
Приём с добавлением «مَ» — инженерный; его корректность для всех слов книги нужно проверить
с преподавателем (вопрос OQ-03 в `docs/research/open-questions.md`).

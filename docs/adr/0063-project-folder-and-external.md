# ADR-0063: Одна папка проекта `~/Desktop/muallim`, справочные репозитории — внутри, в `external/` (вне git)

- **Статус:** Принято
- **Дата:** 2026-10-22
- **Кто решил:** автор («открыть в VS Code одну папку, чтобы там было всё, на Рабочем столе», имя `muallim`);
  устройство предложил агент
- **Связано:** ADR-0035 (п. 3 — где лежат образцы), ADR-0039, ADR-0042

## Контекст
Проект лежал в `~/thesis/Исмаилов_диплом_магистратуры`, рядом — `external/` (17 чужих репозиториев, 4,5 ГБ).
Чтобы агент видел обе папки, VS Code открывали на родительской папке, а для неё держали обёртку
`.claude/` со ссылками на агентов и копией настроек (`sync_settings.py`). Обёртка ломалась: в сессии
2026-10-18 агенты проекта не загрузились. После переноса проекта на Рабочий стол пути `../external/`
и ссылки обёртки перестали работать, `.venv` указывал на самый первый путь.

## Решение
1. Проект — `~/Desktop/muallim` (как репозиторий на GitHub, проект Docker и пакет). Открывается сама
   эта папка; родительской обёртки нет.
2. `external/` — внутри проекта: в `.gitignore` и `.dockerignore`; правка запрещена в
   `.claude/settings.json` (`Edit`/`Write(./external/**)`); строка в карте CLAUDE.md.
3. Проверки не задевают её: ruff уважает `.gitignore`, mypy и pytest смотрят `src/`, `tests/`,
   deptry — `src`, zizmor — `.github/workflows`.
4. VS Code (локальный `.vscode/settings.json`, вне git): не искать git-репозитории в `external/`,
   не разбирать её Pylance.

## Рассмотренные варианты
| Вариант | Плюсы | Минусы | Итог |
|---|---|---|---|
| `external/` рядом с проектом, файл `.code-workspace` | документы не меняются (ADR-0035) | две-три вещи на Рабочем столе; автор хочет одну папку | Отклонено |
| Проект в `~/Developer` | стандартное место для кода | автору удобнее Рабочий стол | Отклонено |
| Родительская папка с обёрткой `.claude/` (как было) | видно обе папки | обёртка ломается, агенты не загружаются | Отклонено |
| Прежнее имя `Исмаилов_диплом_магистратуры` | привычно | кириллица в пути ломает часть инструментов | Отклонено |

## Последствия
- Пути в документах: `external/…` вместо `../external/…`.
- После переименования папки `.venv` пересобирается (`uv sync --extra ml`); история сессий Claude
  по старым путям остаётся под старыми именами в `~/.claude/projects/`.
- База данных не затронута: том Docker `muallim_postgres-data` не зависит от пути.

# ADR-0011: Разработка через тесты (TDD) с фазами, которые соблюдаются хуками

- **Статус:** Принято
- **Дата:** 2026-10-17 (механизм перенесён из прототипа, коммит 3ef6f74)
- **Кто решил:** Исмаилов
- **Связано:** ADR-0012, `docs/process/development-workflow.md`

## Контекст
Код пишет в том числе ИИ-агент. Известный риск: агент «подгоняет» тесты под свой код, и тесты перестают
что-либо проверять.

## Решение
Цикл red → green → refactor с явными фазами (`scripts/phase tests|impl|off`):
1. `tests` — агент пишет падающие тесты; человек их принимает.
2. `impl` — тесты **заморожены**: PreToolUse-хук запрещает изменять `tests/`.
3. `off` — сводка, проверка руками в Telegram, коммит человеком.

## Рассмотренные варианты
| Вариант | Итог | Причина |
|---|---|---|
| Тесты после кода | Отклонено | тесты подстраиваются под ошибки реализации |
| BDD (Gherkin) | Отложено | лишний слой для одного разработчика; сценарии описаны в требованиях |
| TDD с фазами и хуком | **Принято** | человек контролирует, *что* проверяется; агент — *как* реализовано |

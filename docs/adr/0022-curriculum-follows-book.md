# ADR-0022: Программа бота — строго по книге, в порядке книги; книга хранится в проекте, но не в боте; пока только русский

**Статус:** Принято
**Дата:** 2026-10-17
**Кто решил:** автор (указание: «давай все по книге делать как там написано и порядок такой же… книга
хранилась внутри у меня в проекте но не в тг боте… пока только русский язык») — варианты реализации
выбраны агентом и перечислены ниже

## Контекст
Программа бота досталась от прототипа: урок 1 — 28 букв по алфавиту, урок 2 — 12 слов с переводом.
Ни то, ни другое не взято из книги, и порядок не совпадает с книгой (OQ-09: книга начинает с ر ز م).
Издание для сверки не было выбрано (OQ-02), поэтому у карточек не было страниц.

## Решение
1. **Рабочее издание — SRC-040:** Максуди А. «Муаллим сани — Правила чтения Священного Корана»,
   Альметьевск: Ай Медиа, 2010 (ДУМ РТ, ред. О. Тураби), 88 с. Единственное найденное полное издание
   на русском с открытым сканом; орфография Мединского мусхафа (Хафс) совпадает с тем, на чём обучена
   модель Muaalem; к нему есть видеокурс (SRC-021). Порядок букв проверен по второму, узбекскому
   изданию — совпадает, т. е. это порядок Максуди.
2. **Книга лежит в `book/`** (скан + `README.md` с выходными данными и SHA-256 + `contents.yaml` —
   оглавление и соответствие урокам). PDF не коммитится и не попадает в Docker-образ; код бота на
   `book/` не ссылается (тест `tests/architecture/test_book.py`).
3. **Урок = раздел книги** (одна буква), **карточка = одна печатная строка** арабского текста, в
   порядке страниц и строк. Первая карточка урока — заголовок раздела (буква с фатхой, кясрой,
   даммой), дальше — строки слогов и слов как в книге, включая строки «Обратите внимание» (пары
   похожих слов — готовые минимальные пары для исследования, RQ-2).
4. **У каждой карточки — `source: {SRC-040, page, line}`**; «строка» определена в `book/README.md`.
5. **Строки книги без транскрипции и перевода** — в книге их нет (M-09: главное — эталонное аудио).
6. **Русский текст книги в бот не копируется** (авторское право): подсказки — свои (`lexicon.ru.yaml`).
7. **Арабский текст перенёс агент со скана и пометил `verified: false`**; сверяет человек по
   чек-листу `docs/pedagogy/book-structure.md`.
8. **Только русский:** команда `/language` убрана из бота, черновики kk/en перенесены в
   `curriculum/drafts/` (загрузчик их не видит). Механизм языков (ADR-0017, `SetFeedbackLanguage`,
   колонка `feedback_language`) оставлен — включение языка позже = вернуть файлы и команду.
9. **Тесты сценариев отвязаны от контента:** `tests/unit/test_use_cases.py` работает на своей мини-программе,
   а соответствие книге проверяет `tests/unit/test_curriculum_content.py`.

## Рассмотренные варианты
| Вопрос | Вариант | Плюсы | Минусы | Итог |
|---|---|---|---|---|
| Издание | **2010, Альметьевск (ДУМ РТ)** | полное, русское, Мединская орфография, есть видеокурс | не 1917; «все права защищены» | ✅ |
| | узбекское «Муаллими соний» (цифровая версия) | оцифрован арабский текст | старая орфография, узбекский язык, нет лицензии на репозиторий | ❌ — только для сверки порядка |
| | Аббясов 2005 (SRC-024) | для русскоязычных | это другое пособие, не книга Максуди | ❌ |
| Карточка | **строка книги** | точная ссылка «страница + строка»; так учат («прочитай строку») | длинные записи, оценка на строке грубее | ✅ |
| | каждое слово отдельно | точнее оценка | ~400 карточек, теряется «строка» книги | ❌ (можно добавить позже) |
| Урок | **одна буква = урок (28)** | точно как разделы книги | длинное меню | ✅ (меню в два столбца) |

| | в git (LFS) | история | публикация чужого издания | ❌ |
| Языки | **скрыть, черновики в `drafts/`** | бот только на русском, код не потерян | — | ✅ |
| | удалить kk/en и код | проще | придётся переписывать | ❌ |

## Отклонено
- **Урок «Алфавит» из 28 букв по алфавиту и урок из 12 слов прототипа** — не из книги и не в её порядке.
- **Перевод и кириллица у строк книги** — в книге их нет; преподаватели советуют не учиться по транскрипции (SRC-021, SRC-022).
- **Таблица алфавита (с. 10) как урок** — это справочная таблица названий букв, а Максуди учит звуки, не названия (SRC-015).
- **Копирование русских описаний артикуляции из книги в бот** — авторское право; свои подсказки уже есть.

## Последствия
- Новые `item_id` (L01…L28 по книге): старые попытки ссылаются на прежнюю программу; различаются по
  `curriculum_version` (`2026.10.17-book-1`). Закрытый пилот, данных учеников нет.
- Эталонные записи (`curriculum/audio/<item_id>.ogg`) записываются под новые id.
- Разделы с. 25–85 (мадд, ташдид, танвин, …, суры) — следующие уроки, TD-FN-09.
- Работа модели на нескоранических строках (например «رَرْ رِرْ») не проверена — TD-FN-10.

# ADR-0009: Тексты в одном модуле, без системы локализации (пока)

- **Статус:** Отклонено (Fluent/aiogram-i18n); принято `presentation/telegram/texts.py`. Для объяснений ошибок частично заменено ADR-0017
- **Дата:** 2026-10-17
- **Кто решил:** предложил агент, утвердил Исмаилов

## Контекст
Аудитория первого этапа — русскоязычные ученики. Для локализации aiogram-ботов обычно используют Fluent (.ftl, aiogram-i18n).

## Почему отклонено
Система локализации добавляет зависимость и слой косвенности, а второго языка пока нет.
Все тексты собраны в одном модуле, поэтому перенос в Fluent позже — механическая работа.

## Когда пересмотреть
Когда понадобится второй язык интерфейса (например, узбекский или казахский).

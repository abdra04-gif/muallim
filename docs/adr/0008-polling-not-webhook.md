# ADR-0008: Long polling вместо webhook + FastAPI

- **Статус:** Отклонено (webhook); принято long polling
- **Дата:** 2026-10-17
- **Кто решил:** предложил агент, утвердил Исмаилов

## Контекст
Альтернатива long polling — webhook через FastAPI, nginx и HTTPS-сертификат.

## Почему отклонено
Webhook требует публичный домен, TLS, reverse-proxy и открытый порт — это больше поверхность атаки и
обслуживания. Для одного бота long polling работает так же надёжно и не открывает ни одного порта.

## Когда пересмотреть
Если бот уйдёт на serverless-хостинг или нагрузка вырастет до тысяч сообщений в минуту.

# ADR-0005: Не использовать Redis (пока)

- **Статус:** Отклонено (Redis); принято хранить состояние в PostgreSQL
- **Дата:** 2026-10-17
- **Кто решил:** предложил агент, утвердил Исмаилов
- **Связано:** ADR-0004

## Контекст
Типовая схема Telegram-ботов на aiogram — Redis для состояния диалога (FSM) и кэша. В прототипе состояние
(«какая карточка открыта») лежало в словаре в памяти и терялось при перезапуске.

## Решение
Текущая карточка ученика — колонка `learners.current_item_id` в PostgreSQL. Redis не нужен.

## Почему отклонено
- Один экземпляр бота; нагрузка — десятки-сотни учеников.
- Ещё один сервис = ещё один пароль, бэкап и точка отказа.
- Состояние в БД переживает перезапуск и видно в отчётах.

## Когда пересмотреть
Если бот будет запущен в нескольких экземплярах или понадобится многошаговый диалог (FSM).

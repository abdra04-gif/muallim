# ADR-0074: Ролики «🎬 Как произносить» — mp4 в `curriculum/video/` по тексту карточки, file_id в памяти

- **Статус:** Принято 2026-10-25 (вариант A; черновик — агент-архитектор, выбор — автор)
- **Дата:** 2026-10-25
- **Кто решил:** где показывать — автор (карточка слога/буквы с автопоказом при первом знакомстве,
  разбор ошибки FR-54, шпаргалка FR-52); устройство — предложил агент, утверждает автор
- **Связано:** FR-56, FR-20, FR-40, FR-52, FR-54; ADR-0002, ADR-0018, ADR-0024, ADR-0032,
  ADR-0046, ADR-0055, ADR-0061, ADR-0068; SRC-144 (звук ар-Раи), SRC-148 (рисунок Lynch, CC BY 2.5);
  TD-FN-93, TD-FN-102; QAS-05, QAS-07, QAS-10

**Решения автора 2026-10-25** (главнее пунктов ниже, где они расходятся):
- **Уточнение того же дня (главнее остального):** ролики показываются **только на карточках алфавита**,
  где они сделаны (слоги и тройки أ ر ز) — над карточкой, по 🎬 и после попытки на этой же карточке.
  В разборе ошибок строк и сур и в шпаргалке роликов нет (в шпаргалке у всех букв 🔊): ученик пробует
  ролики и даёт отзыв, в других местах они пока не нужны и путают. Пункты ниже про разбор и
  шпаргалку отменены этим уточнением.
- Хранение — вариант A, ролики в **720p** (1280×720).
- Генератор — в `scripts/video/`, группа зависимостей `video = ["numpy"]`.
- **Где есть ролик — только ролик:** у карточки с роликом нет кнопки 🔊 и нет отдельного голосового;
  везде, где раньше уходил звук «как правильно» (автозвук над карточкой, кнопка, после попытки), уходит
  ролик (в нём тот же звук). Где ролика нет — всё как было. Отдельный признак «первое знакомство» (`seen`)
  не нужен: ролик ведёт себя как автозвук.
- Разбор ошибки — ролик **слога, в котором ошибка**; если такого нет — ролик-тройка буквы. Шпаргалка — тройка.
- Слоги вырезаны из троек ар-Раи по паузам (автор утвердил на слух) — исключение из ADR-0068.
- Автор рисунка (SRC-148) — только в документации; вернуться к подписи в боте перед пилотом с незнакомыми.
- Одна ошибка в нескольких слогах — ролик-тройка буквы; одинаковые 🎬 после попытки и в разборе — одна
  кнопка (в разборе); шпаргалка — у букв с тройкой только 🎬 (без 🔊); сбой отправки — событие не пишется;
  хамза под алифом (إ) — тройка أ, если ролика самого слога с хамзой нет.
- Закрепление (FR-53) оставляет 🔊: на ступени «услышь и выбери» ролик с подписанной буквой подсказал бы
  ответ (предложил агент; автор может изменить).
- Поле `picture` (SRC-148) в `videos.yaml` — источник рисунка; генератор в `scripts/video/` — TD-FN-113.

## Контекст
1. Ученик учит чтение с нуля (`audience.md`); текст «кончик языка у бугорка…» новичку мало что даёт.
   Автор сделал ролики артикуляции: mp4 1920×1080, 5–6 с, 0,3–2 МБ, H.264 + AAC, `+faststart`.
   Готовы буквы أ ر ز: ролик на каждый слог (9) и ролик-тройка для карточки «три слога вместе» (3).
   Позже — все 28 букв: ≈ 28 × 4 = 112 файлов, ≈ 50–200 МБ.
2. Генератор (Python: numpy, Pillow, ffmpeg) лежит вне репозитория; рисунок — Wikimedia Commons,
   Patrick J. Lynch, CC BY 2.5 (SRC-148); звук — записи ар-Раи (SRC-144) из `curriculum/audio/library/`.
   Одиночные слоги **вырезаны из троек по паузам** и утверждены автором на слух — сознательное
   исключение из ADR-0068 («ниоткуда не вырезай»).
3. Как устроен звук сейчас (повторяем, где разумно): `SoundLibrary` (`infrastructure/audio/reference_library.py`)
   читает `curriculum/audio/library/sounds.yaml` (`text, file, status, source, origin`) и ищет запись
   **по тексту карточки**, а не по id («id карточек меняются при пересборке» `scripts/book/build.py`);
   `status: bad` бот не отдаёт; файлы — в git, попадают в образ Docker (`COPY curriculum`).
   Отправка — `send_reference` (`handlers/reference.py`), автозвук над карточкой — `show_card` +
   `Display.keep_sound`; факт прослушивания — событие `reference_played` в `interaction_events`.
   Кэш Telegram `file_id` картинок уже есть — в памяти `Display.file_ids`.
4. Ограничения: слои ADR-0002 (application не знает aiogram); тесты < 10 с без сети и модели; новые
   зависимости и схема БД — решение человека; закрытый пилот (ADR-0015). Telegram: отправка файла
   ≤ 50 МБ, ~1 сообщение/с в чат, `callback_data` ≤ 64 байт; картинка, видео и кнопки не собираются
   в одно сообщение. `send_video_note` («кружок») — только квадрат ≤ 640 px; GIF (`send_animation`) — без звука.
5. Отклонённых ADR с той же идеей нет. ADR-0024 отклонил «аудио из видеокурса» (авторское право) —
   здесь ролики свои, а права на звук те же, что у эталонов (TD-FN-102).

## Решение (рекомендация агента — вариант A)
1. **Файлы:** `curriculum/video/<sha16>.mp4` в git + манифест `curriculum/video/videos.yaml`:
   `- {text, letter, file, seconds, width, height, status, source, origin}`. `text` — точный текст
   карточки (как в `sounds.yaml`), `letter` — у ролика-тройки: буква для разбора и шпаргалки
   (`ر`, `أ`, `ز`). Имя файла — хеш содержимого: тот же ролик после пересборки не меняет историю git.
   `status: unchecked | ok | bad`, `bad` — не показывается. Манифест пишет генератор, `status` — человек.
2. **Порт** `ArticulationVideoLibrary` (`application/ports/storage.py`): `for_text(text) -> str | None`,
   `for_letter(letter) -> str | None` (ключ ролика), `get(key) -> Video | None`, где `Video` — байты +
   `key`, `seconds`, `width`, `height` (без aiogram). **Адаптер** `VideoLibrary.load(root)` —
   `infrastructure/video/library.py`, повторяет `SoundLibrary` (только имя файла — не выйти из `root`).
3. **Сценарий** (`application/use_cases/video.py`): отдаёт ролик; событие
   `video_played` `{video, item_id | letter, from: card | auto | after | breakdown | sheet}` пишется
   **только после успешной отправки** (решение автора). Схема БД **не меняется**: `interaction_events.payload`
   — JSON без CHECK по имени события; в `data-dictionary.md` — новая строка события.
4. **Показ** (presentation): колбэк `Watch(v=<key>)`; `send_video(..., supports_streaming=True, width,
   height, duration)`. Первый раз — `BufferedInputFile`, ответный `video.file_id` — в `Display.file_ids`
   под ключом `video:<key>`; дальше — по `file_id`. После перезапуска ролик загружается заново один раз.
   Устаревший `file_id` (`TelegramBadRequest`) — забыть и загрузить файлом.
   Автопоказ: если для текста карточки есть ролик, он уходит над карточкой **каждый раз**, когда раньше
   уходил автозвук (`show_card`), и **заменяет** автоголосовое; от наличия эталонного ogg не зависит.
   Сбой отправки — предупреждение в лог, карточка показывается, событие не пишется.
5. **Генератор** — `scripts/video/` (+ `make videos`), зависимости — группа `video = ["numpy"]` в
   `[dependency-groups]` (Pillow уже в основных, ffmpeg — в системе и образе); боту numpy не нужен.
   Рисунок SRC-148 — `scripts/video/assets/` с файлом лицензии. Фиксированное зерно случайности, чтобы
   пересборка давала тот же файл.
6. Связь «ролик ↔ карточка» — **по тексту** (как `sounds.yaml`), не полем в `course.ru.yaml`.

## Рассмотренные варианты
| Вариант | Плюсы | Минусы | Итог |
|---|---|---|---|
| **A. mp4 в git (`curriculum/video/`) + `videos.yaml` по тексту, `file_id` в памяти** | повторяет `sounds.yaml`: новый ролик — файл + строка манифеста, без кода; в образ Docker попадает сам; то, что автор утвердил на слух, и есть то, что видит ученик; тесты — временная папка с фальшивым mp4, без сети; без миграции | репозиторий +50–200 МБ (и каждая перегенерация с новыми байтами — ещё столько же в истории); первая отправка после перезапуска — загрузка 0,3–2 МБ (~1 с) | **рекомендован** |
| A′. То же, mp4 через Git LFS | репозиторий лёгкий | новый инструмент; квота GitHub LFS 1 ГБ трафика в месяц — CI и сборка образа её тратят; `make try` и CI без `git lfs pull` видят указатели вместо файлов | отклонён (пока); вернуться, если папка > 300 МБ |
| B. mp4 — артефакт сборки вне git (`make videos` → `curriculum/video/`, в `.gitignore`), в git — генератор, рисунок и манифест | репозиторий не растёт | образу Docker нужен numpy и 2–5 мин генерации, либо ручное копирование папки на сервер; без зерна и одинаковых версий ffmpeg/x264 пересборка ≠ ролик, утверждённый на слух; тест «у каждой строки манифеста есть файл» в CI невозможен; при отсутствии файла кнопки просто нет — сбой незаметен | отклонён |
| C. Только Telegram: загрузить один раз, хранить `file_id` (в `videos.yaml` или новой таблице БД), mp4 — у автора | мгновенная отправка с первого раза; репозиторий не растёт | `file_id` привязан к боту: тестовый бот, рабочий бот, `muallim --test` и смена токена — у каждого свои; таблица — изменение схемы (миграция, ADR-0055); контент живёт в Telegram, для диссертации не воспроизводится; `make try` ролик не отправит | отклонён |
| Связь полем `video:` в `course.ru.yaml` | явно видно в программе | `course.ru.yaml` собирается `scripts/book/build.py` — поле потеряется при пересборке или build.py придётся учить; зона человека; у аудио уже выбран путь «по тексту» | отклонён |
| Кэш `file_id` в БД или файле на диске | переживает перезапуск | ради ~1 с на ролик раз в перезапуск — схема или новый файл состояния; при смене бота кэш ложный | отклонён |
| Отправка «кружком» (`send_video_note`) или GIF (`send_animation`) | кружок крупный, GIF без кнопки «плей» | кружок — только 1:1 ≤ 640 px (ролики 16:9); GIF без звука, а смысл — звук вместе с движением | отклонён |
| Генератор вне репозитория | нет новой группы зависимостей | ролики нельзя пересобрать для 28 букв по одной команде и проверить источник (SRC-148, SRC-144) | отклонён |
| Первое знакомство — по попыткам (нет попытки на карточке) или по памяти процесса | без нового чтения из журнала | по попыткам: ролик приходит при каждом открытии, пока ученик не прочитал; по памяти: после перезапуска — снова | отклонены: автор решил — ролик ведёт себя как автозвук, признак «первое знакомство» не нужен |

## Последствия
- Новый ролик для буквы — файлы + строки `videos.yaml` (`make videos`), без правки кода; кнопка 🎬
  появляется сама на всех карточках с тем же текстом (в том числе на карточках-правилах с текстом
  «أَ إِ أُ» — см. вопросы).
- В `interaction_events` появляется `video_played` — для пилота видно, смотрят ли ролики и помогает ли
  это следующей попытке (как `reference_played`, E-7).
- Права: звук — TD-FN-102 (ар-Раи) распространяется и на ролики; CC BY 2.5 требует указать автора
  «разумным для носителя способом» — решение «только в документации» сверить до пилота с незнакомыми.
- Исключение из ADR-0068: одиночные слоги в роликах вырезаны из троек по паузам и утверждены автором
  на слух; эталон 🔊 по-прежнему не вырезается.
- Если папка `curriculum/video/` перерастёт ~300 МБ — пересмотреть (720p вместо 1080p ≈ в 2–3 раза
  меньше; Git LFS — A′).

## Как проверить
- Тест библиотеки роликов (unit): манифест → поиск по тексту и букве, `bad` и отсутствующий файл не
  отдаются, имя файла с `../` не выходит из папки.
- `tests/unit/test_use_cases.py` (или `test_video.py`): `GetArticulationVideo` пишет `video_played` и
  делает commit только после успешной отправки.
- `tests/integration/test_bot_flow.py`-стиль: кнопка 🎬 есть только при ролике; `send_video` с
  `supports_streaming=True`, второй показ — строкой `file_id`; первое открытие карточки — ролик над
  карточкой при каждом открытии (как автозвук); сбой отправки — карточка показана, события нет.
- `tests/architecture/`: сценарий зарегистрирован в `bootstrap/di.py`; import-linter зелёный.
- Тест данных: каждая строка `videos.yaml` — существующий файл ≤ 20 МБ, `text` есть среди карточек
  `course.ru.yaml`, `source` — ключ из `sources.md`.

# ADR-0019: Полный след решения по каждой попытке

- **Статус:** Принято
- **Дата:** 2026-10-17
- **Кто решил:** Исмаилов (требование «полная отслеживаемость, смотреть ответы, находить ошибки»)
- **Связано:** FR-24, ADR-0004, ADR-0014

## Контекст
Чтобы через годы понять, **почему** бот сказал ученику именно это, и найти ошибки модели, нужно хранить
не только итог, но и весь путь решения.

## Решение
В каждой попытке дополнительно сохраняются:

| Поле | Что | Зачем |
|---|---|---|
| `reference_variant` | какой эталон выбран (`wasl` / `waqf`) | понять, засчитали ли чтение с остановкой |
| `candidates` | все эталоны и балл по каждому | воспроизвести выбор |
| `model_output` | сырые данные модели, которые удалось получить | дообучение, отладка |
| `policy` | пороги, по которым вынесен вердикт | вердикт воспроизводим даже после смены порогов |
| `app_version` | версия кода (git) | какой код принимал решение |
| `feedback_language` | на каком языке объяснено | RQ-3 |

Вместе с уже хранимыми `model_version`, `curriculum_version`, ошибками и показанным текстом это даёт
полную цепочку: **аудио → модель → эталоны → сравнение → пороги → текст ученику**.

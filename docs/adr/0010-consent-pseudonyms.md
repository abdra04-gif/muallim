# ADR-0010: Согласие на хранение записей, псевдонимы, право на удаление

- **Статус:** Принято
- **Дата:** 2026-10-17
- **Кто решил:** предложил агент, утвердил Исмаилов
- **Связано:** FR-09, FR-10, NFR-SEC-01..04, `docs/security/privacy.md`

## Контекст
Голос — персональные (а в ряде юрисдикций биометрические) данные. Исследование с людьми требует
информированного согласия. Прототип хранил данные без согласия, по Telegram ID.

## Решение
- Бот работает и без согласия; **аудио сохраняется только с явного согласия** (кнопка при /start,
  изменяется в /privacy). Каждое изменение пишется в `consents` с версией текста согласия.
- Ученик в исследовательских данных — **псевдоним** `L-xxxxxxxx`; Telegram ID есть только в
  `learners` и в выгрузки не попадает (проверяется тестом).
- **Удаление по запросу** (/privacy → «Удалить мои данные»): каскадно удаляются попытки, ошибки,
  разметка, согласия и файлы записей.
- Записи хранятся по SHA-256 с правами 0600.

## Рассмотренные варианты
| Вариант | Итог | Причина |
|---|---|---|
| Хранить всё без согласия, как в прототипе | Отклонено | неэтично и незаконно для исследования |
| Не хранить аудио вообще | Отклонено | без аудио нельзя найти ошибки модели и дообучить её |
| Согласие по кнопке + псевдонимы + удаление | **Принято** | баланс пользы для исследования и прав ученика |

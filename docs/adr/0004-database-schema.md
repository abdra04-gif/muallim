# ADR-0004: PostgreSQL, переносимая схема, попытка — единица данных

- **Статус:** Принято
- **Дата:** 2026-10-17
- **Кто решил:** предложил агент, утвердил Исмаилов
- **Связано:** FR-06, FR-11, FR-13, NFR-TR-01, `docs/data/data-dictionary.md`

## Контекст
Прототип хранил попытки в SQLite (`progress.db`): одна таблица, без версий модели и контента, без
разметки. Для исследования нужно: находить ошибки модели, размечать, строить отчёты, обучать модель.

## Решение
- **СУБД:** PostgreSQL 16 в работе; схема только из переносимых типов (`Uuid`, `JSON`, `UtcDateTime`),
  поэтому тесты идут на SQLite в памяти.
- **Попытка (`attempts`)** хранит всё, чтобы её можно было воспроизвести: эталон и услышанные фонемы,
  балл, вердикт, `item_id`, **версию учебной программы** и **версию модели с параметрами чтения**.
- **Ошибки (`detected_errors`)** — отдельная таблица со структурой (тип, позиция, слог) и точным
  текстом, который увидел ученик.
- **Разметка (`annotations`)** — отдельно от данных модели, с кодом разметчика и версией руководства.
- **Журнал событий (`interaction_events`)** — история действий учеников без текста сообщений.
- Изменение схемы — только миграцией Alembic; тест сверяет миграции со схемой в коде.

## Рассмотренные варианты
| Вариант | Итог | Причина |
|---|---|---|
| SQLite, как в прототипе | Отклонено для работы | одна запись за раз, нет удалённого доступа для анализа |
| MongoDB / документы | Отклонено | отчёты — это JOIN и GROUP BY, им нужна реляционная модель |
| ClickHouse / хранилище для аналитики | Отложено | объём данных магистратуры этого не требует |
| PostgreSQL + переносимая схема | **Принято** | SQL для отчётов, транзакции, лёгкие тесты |

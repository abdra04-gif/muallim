# ADR-0013: Учебная программа в YAML-файлах с версией и ссылками на источник

- **Статус:** Принято
- **Дата:** 2026-10-17
- **Кто решил:** предложил агент, утвердил Исмаилов
- **Связано:** NFR-TR-01, FR-01, `curriculum/`

## Контекст
В прототипе уроки были Python-кодом (`lessons.py`). Менять их мог только программист, а происхождение
строк (страница книги) нигде не фиксировалось.

## Решение
- `curriculum/course.ru.yaml` — уроки и карточки; `curriculum/lexicon.ru.yaml` — названия звуков и
  подсказки. Перенесены из прототипа **скриптом**, без ручного набора, чтобы не исказить огласовки.
- У каждого урока и карточки есть `source` (`source_id`, `page`, `line`, `verified`).
- Поле `version` пишется в каждую попытку: всегда известно, какой текст видел ученик.
- Файлы меняет только человек (хук запрещает агенту правку без подтверждения).

## Рассмотренные варианты
| Вариант | Итог | Причина |
|---|---|---|
| Python-код, как в прототипе | Отклонено | правит только программист, нет ссылок на источник |
| Таблицы в БД + админка | Отложено | нужна админка; YAML в git даёт историю правок бесплатно |
| YAML в git | **Принято** | история, ревью, ссылки на источник, читаемо преподавателем |

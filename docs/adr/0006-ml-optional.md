# ADR-0006: Модель распознавания — заменяемый адаптер и необязательная зависимость

- **Статус:** Принято
- **Дата:** 2026-10-17
- **Кто решил:** предложил агент, утвердил Исмаилов
- **Связано:** NFR-MNT-04, FR-04, SRC-002

## Контекст
Quran Muaalem (SRC-002) весит 1–2 ГБ вместе с torch. В прототипе модель грузилась при импорте
модуля, поэтому даже тесты требовали её скачивания.

## Решение
- Порт `PronunciationRecognizer` в `application`; реализация `MuaalemRecognizer` в `infrastructure`.
- Зависимости модели — extra `ml` (`uv sync --extra ml`); CI и тесты обходятся без них.
- `ASR_BACKEND=stub` запускает бота с заглушкой (`model_version="stub"`, в отчёты не попадает).
- В каждой попытке хранится `model_version` (пакет, версия и параметры чтения), чтобы сравнивать
  модели и воспроизводить результаты.

## Последствия
Новую модель (своя дообученная, Whisper, сервис по API) можно подключить отдельным адаптером
и сравнить на тех же данных, не меняя остальной код.

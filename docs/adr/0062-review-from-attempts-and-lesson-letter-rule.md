# ADR-0062: «Чтобы не забывать» — повторение 1·3·7 дней вычисляется из попыток (без новой таблицы), ошибка в букве урока не засчитывает строку (правило в `GradingPolicy`, след — в `attempts.policy`), шпаргалка букв по книге

- **Статус:** Принято с изменениями автора 2026-10-21 (вариант A для повторения; строгость к букве урока отложена — OQ-14)
- **Дата:** 2026-10-21
- **Кто решил:** решения по сути — автор (2026-10-20/21): (а) шпаргалка «буква → звук → 🔊» с карточки урока и
  с экрана «🔤 Знаки»; (б) «🔁 Повторение» строк с ошибками через 1, 3, 7 дней, засчитанная при повторении —
  на следующий интервал, незасчитанная — сначала; (в) в начале урока «новая буква: X · уже знаешь: …»;
  (г) ошибка в букве урока не засчитывает строку при любом балле («Нет, пусть повторит»), текст «Буква урока X
  прозвучала как Y — послушай и повтори». Архитектура (где хранить, как считать) — предложил агент, принимает
  автор (ADR-0021). Открытые вопросы В1–В4 — ниже
- **Связано:** FR-52, FR-15, US-U-13, TD-FN-92, OQ-12, R-08, R-13, M-12, QAS-01, QAS-02, QAS-05, QAS-07, QAS-08,
  QAS-09, ADR-0002, ADR-0005, ADR-0008, ADR-0019, ADR-0023, ADR-0024, ADR-0025, ADR-0052, ADR-0054, ADR-0058,
  ADR-0061, SRC-107, SRC-129, SRC-098

## Контекст
1. **FR-52 (пакет В UX-обхода, TD-FN-92).** Четыре части: (а) шпаргалка, (б) интервальное повторение,
   (в) связка уроков, (г) строгость к букве урока. Итерация ADD 10 «Интервальное повторение»
   (`design-iterations.md`) стояла «после пилота»; автор перенёс её в пакет В 2026-10-20, потому что после
   ADR-0058 («можно дальше без зачёта») незасчитанные строки копятся в «повторить» и к ним ничто не возвращает.
2. **Что уже есть.** `attempts` хранит по каждой попытке `item_id`, `created_at`, `verdict`, `score`, `policy`
   (JSON порогов) — этого достаточно, чтобы восстановить историю «когда строка не получилась и когда получилась».
   `AttemptRepository.activity` уже читает все `created_at` ученика и считает местный день по
   `learner_settings.utc_offset_min` (ADR-0061). «Пройдено» сейчас — `best_scores` ≥ `pass_threshold`
   (`GradingPolicy.is_mastered`), а не вердикт.
3. **«Буква урока».** `Lesson.accent` — буквы, выделенные в книге красным (`scripts/book/build.py`,
   `letters_accent`): в уроках букв (`section == "letter"`) это сама буква (у хамзы — её формы ءأإؤئآ); в других
   разделах — знаки вроде ى, ة, ٱ или набор «قطبجد» (калькаля), которые не совпадают со звуком один к одному.
   Согласные фонемы Muaalem записаны теми же буквами (`domain/phonetics.CONSONANTS`), поэтому в уроках букв
   «ошибка в букве урока» определяется по `PronunciationError.expected` без нового контента.
4. **Исследование.** Вердикт пишется в `attempts.verdict`; `research/metrics.py` пересчитывает «вердикт учителя»
   той же политикой (`_policy(attempts.policy)` → `GradingPolicy(...).verdict(...)`). Если строгость к букве
   урока не попадёт в `policy`, бот будет строже, чем пересчитанный «учитель», и κ «бот — учитель» (QAS-01, RQ-1)
   исказится. В снимке программы (`curriculum_items`, ADR-0023) `accent` нет — значит, буквы урока для
   пересчёта надо сохранить в самой попытке. Попытки на повторении — естественный отложенный замер (забывание,
   RQ-4, SRC-129); их нужно отличать в данных.
5. **Ограничения:** слои ADR-0002; один процесс, long polling (ADR-0008); без Redis (ADR-0005); тесты без модели
   и сети (ADR-0006); закрытый пилот 5–10 учеников (ADR-0015); схема БД, методика и тексты — решение человека.
6. **Отклонённые раньше похожие идеи.** ADR-0058 отклонил «не пускать дальше, пока не засчитано» — здесь
   «▶️ Дальше» остаётся, строгость меняет только зачёт, поэтому то решение не пересматривается. ADR-0061 отметил,
   что повторение «может переиспользовать тик напоминаний», — отдельный тик не нужен (п. 6 решения).
   Других отклонённых ADR про повторение нет.

## Решение (предлагается)
1. **Строгость к букве урока — в домене (`domain/policy.py`).** `GradingPolicy.verdict(assessment, focus=…)`:
   если среди ошибок прочитанной части строки (до `unread_from`) есть замена или пропуск согласной из `focus`
   (`LETTER_SUBSTITUTION`, `SOUND_SUBSTITUTION`, `FRAGMENT_SUBSTITUTION`, `SOUND_MISSING`, `SHADDA_MISSING`, где
   в `expected` есть буква урока), вердикт — `failed` при любом балле. Пустой `focus` — поведение как сейчас.
   `focus` строки — функция домена от урока: в уроке буквы — её фонема (у хамзы — ء); в остальных разделах —
   пусто (вопрос В3). Флаг правила — поле `GradingPolicy` (по умолчанию включено, значение — методика, M-17).
2. **След решения (QAS-09).** `attempts.policy` (JSON, без миграции) пополняется ключами `"focus"` (буквы урока
   этой попытки) и `"focus_rule"` (версия правила, `"v1"`); `research/metrics._policy` восстанавливает их, и
   «вердикт учителя» считается тем же правилом. Старые попытки без ключей — без строгости (как и оценивались).
   Событие `attempt_assessed` получает `"focus_failed": true|false`; отчёт `make report` показывает, сколько
   строк не засчитано только из-за буквы урока (контроль ложных отказов, QAS-02).
3. **«Пройдено» — по вердикту, а не по лучшему баллу.** Строка засчитана, если есть попытка с вердиктом не
   `failed`. Для старых попыток это то же самое (тогда `failed` ⇔ балл < 80). Порт `AttemptRepository` получает
   метод истории исходов (`item_id`, местный день, засчитано ли) — одним запросом, как `activity`; `GetProgress`,
   `AssessRecitation._lesson_done` и прогресс переходят на него; `best_scores` остаётся для «пробовал ли».
4. **Повторение вычисляется из попыток, без таблицы.** Чистая функция домена (`domain/review.py`) проигрывает
   историю исходов строки по порядку: незасчитанная попытка → ступень 1, срок — следующий местный день;
   засчитанная попытка в срок или позже → следующая ступень (+3, затем +7 дней), после третьей — строка выходит
   из повторения; засчитанная раньше срока — ничего не меняет. Пропущенный срок не наказывается — строка
   просто ждёт. Интервалы `(1, 3, 7)` — константа методики (M-18). Порядок на экране — по сроку, затем по книге;
   лимит на день — вопрос В2. Никакого второго источника правды: поменяли правило — пересчитали из тех же
   попыток; удаление ученика (QAS-08) и восстановление копии ничего нового не требуют.
5. **Экран «🔁 Повторение» — одно окно (ADR-0024).** Кнопка на главной появляется, только когда сегодня есть
   строки (`🔁 Повторение · N`). Карточка повторения — обычная картинка строки с подписью «🔁 Повторение: k из N»,
   🔊, «⏭ Следующая», 🏠 (callback `ReviewItem(item_id)`); экран пишется в `learner_settings.screen_item_id`, как
   любая карточка, поэтому голосовое после перезапуска оценивается по ней (QAS-05). Признак «это повторение» не
   хранится: попытка — повторение, если строка была к сроку до этой попытки (считается в `AssessRecitation`,
   поле `RecitationResult.review_left`). Результат — обычный разбор плюс кнопка «🔁 Дальше по повторению (осталось
   N)» или «✅ На сегодня всё». В `attempt_assessed` пишется ступень повторения (`"review_stage"`).
6. **Напоминание (ADR-0061)** не меняет ритм: одно в день, не после занятия. `Progress` получает число строк
   к сроку, экран напоминания добавляет строку «На повторение: N» (вопрос В4).
7. **Шпаргалка и «новая буква».** Домен: «буквы до этого урока по книге» (буквы строго до урока: уроки `letter` раньше данного, без буквы самого урока — `domain.curriculum.letters_before`,
   их головные карточки `LETTER` с `name` и `sound`). Шпаргалка — экран «буква → звук → 🔊» (кнопки 🔊 —
   существующий `Listen(item_id)` головной карточки, отдельным голосовым, как сейчас на карточке); открывается
   кнопкой с карточки урока (буквы до этого урока) и с «🔤 Знаки» (буквы до урока «Продолжить»). На первой
   карточке урока буквы — строка «Новая буква: X · уже знаешь: …» (у первой буквы — без «уже знаешь»). Всё —
   presentation и домен, без схемы. Буквы «по книге», а не «что ученик пробовал»: так строится книга (каждая
   строка урока — из этой и прошлых букв) — предложение агента, автор может поправить.
8. **Тексты** («Буква урока X прозвучала как Y — послушай и повтори», вариант для пропуска, экран повторения,
   строка напоминания, шпаргалка) — `texts.py`, утверждает автор.

## Последствия
- Схема БД не меняется. Меняются смысл и содержимое JSON: `attempts.policy` (+`focus`, `focus_rule`), payload
  `attempt_assessed` (+`focus_failed`, `review_stage`) — `docs/data/data-dictionary.md`.
- Методика: M-17 (строгость к букве урока), M-18 (повторение 1·3·7, правило «сначала»), M-12 уточняется («урок
  пройден» — все строки засчитаны с учётом M-17) — `docs/pedagogy/methodology.md`; OQ-12 частично закрыт для
  уроков букв (длинная строка больше не «разбавляет» ошибку в букве урока); R-13 снижается там же.
- Риск QAS-02: модель, путающая похожие звуки, теперь валит строку целиком. Смягчение: «▶️ Дальше» и
  «🚩 Бот ошибся» остаются; отчёт «не засчитано только из-за буквы урока»; прогон нарезок Хусари (ADR-0032) —
  тест с маркером «нужна модель».
- RQ-3/RQ-4: повторение — вмешательство для всех учеников (без контрольной группы) — угроза валидности в гл. 4;
  зато попытки через 1/3/7 дней — отложенные замеры удержания, отличимые по `review_stage`.
- `analytics/sql/02_item_difficulty.sql`, `08_book_lines.sql` считают зачёт как `score >= 80` — перевести на
  `verdict <> 'failed'` (или показать обе колонки).
- FR-15 и US-U-13 выполняются частью (б) FR-52; итерация 10 — в «Выполненные» после последнего круга.
- Не делается: лимит и порядок по модели усвоения, повторение «Закрепления», ручное «отложить строку».

## Открытые вопросы автору
- **В1.** Когда строка попадает в повторение: (а) если хоть раз не получилась, даже если сразу исправил
  (рекомендация); (б) только если так и не получилась.
- **В2.** Сколько строк в день: (а) все, что к сроку; (б) не больше 10, остальные — завтра (рекомендация).
- **В3.** Что значит «ошибка в букве урока»: (а) только в уроках 28 букв: вместо буквы прозвучала другая или её
  нет; не та огласовка — как сейчас, по баллу (рекомендация); (б) плюс не та огласовка у буквы урока; (в) плюс
  уроки других разделов с красной буквой (нун, мим, калькаля). Для пропуска — текст «Буква урока X пропущена —
  послушай и повтори»?
- **В4.** Напоминание: (а) то же одно, со строкой «на повторение: N» (рекомендация); (б) отдельное про
  повторение, даже если сегодня уже занимался; (в) не связывать.

# ADR-0012: Цикл ИИ-агентов (agent harness loop) с проверками, которые нельзя пропустить

- **Статус:** Принято
- **Дата:** 2026-10-17
- **Кто решил:** идея — научный руководитель (autonomous agent loops / harness loop); реализация —
  предложил агент, утвердил Исмаилов
- **Связано:** ADR-0011, `docs/process/agent-harness.md`, SRC-011

## Контекст
Агент, которому правила только *написаны* (в CLAUDE.md), иногда их нарушает. В «harness engineering»
правила, которые нельзя нарушать, выносят в хуки — скрипты, которые выполняет среда, а не модель
(SRC-011).

## Решение
- **Контекст** (что агент должен знать): `CLAUDE.md`, ADR, требования.
- **Принуждение** (что агент не может обойти): хуки в `.claude/hooks/` — защита тестов, запрет
  читать секреты и данные учеников, автоформат, Stop-хук с проверкой архитектуры и тестов.
- **Роли** (изоляция контекста): субагенты в `.claude/agents/` — test-writer, implementer,
  architecture-guardian, security-auditor, thesis-scribe, data-analyst, pedagogy-reviewer.
- **Журнал**: каждый запрос человека к агенту сохраняется в `docs/journal/prompts/` (хук
  UserPromptSubmit) — это история работы и материал для главы о методике.
- **Человек в цикле**: принимает тесты, утверждает контент и методику, делает коммиты.

## Рассмотренные варианты
| Вариант | Итог | Причина |
|---|---|---|
| Полностью автономный агент без участия человека | Отклонено | ошибки в огласовках и методике сразу дойдут до учеников |
| Только инструкции в CLAUDE.md | Отклонено | инструкции нарушаются; проверки должны выполняться всегда |
| Хуки + субагенты + человек на ключевых шагах | **Принято** | |

# ADR-0025: Вся книга в боте; настоящая модель вместо заглушки; правила, знаки, закрепление, эталон Хусари

**Статус:** Принято (правила своими словами и порядок частей — утвердить, M-13, M-14); эталон аятов заменён ADR-0068
**Дата:** 2026-10-17
**Кто решил:** автор (отзыв после проверки бота), варианты — агент

## Контекст (замечания автора)
- Бот «засчитывает любое слово». Причина: в `.env` стояла заглушка `ASR_BACKEND=stub` (она всегда «слышит»
  эталон), пакеты модели не были установлены (`uv sync --extra ml`).
- Нет объяснения ошибок — с заглушкой ошибок не бывает.
- Мало материала для новичка: нет правил, нет закрепления; в боте только с. 10–24.
- Не объяснено, что значат значки над и под буквами.
- Начинать, как принято — с басмалы. Бот — для тех, кто учит арабский С НУЛЯ (`docs/requirements/audience.md`).
- Макеты на холсте не открывались.

## Решение
1. **Настоящая модель Quran Muaalem** (SRC-002): пакеты `ml` установлены, `ASR_BACKEND=muaalem`,
   видеочип Mac (`asr_device=auto` → mps, ~0,1–0,7 с на запись), прогрев при старте.
   Проверка на чтении Хусари (SRC-042): правильный аят — 99–100, чужой текст — 40–67.
2. **Вся книга, с. 10–85, в её порядке** — 125 уроков, 800 карточек, 9 частей. Расшифровка
   `scripts/book/*.py`, сборка `scripts/book/build.py` (и `book/contents.yaml`).
   Примеры из Корана (с. 38–85) — точным текстом мусхафа (SRC-041) по скелету букв со скана, со ссылкой
   сура:аят; фраза из книги = отдельная карточка (короткие записи — точнее оценка, меньше нагрузка).
3. **Начало — истиаза и басмала** (книга открывается басмалой, с. 10).
4. **«📘 Правило»** перед каждым разделом — объяснение своими словами (не текст книги).
5. **«🔤 Знаки»** — что значат фатха, кясра, дамма, сукун, ташдид, танвин, мадд, хамза аль-васль (картинка с номерами).
6. **«🧠 Закрепление»** — вопрос «как читается слог» из 4 вариантов по начатым буквам; ответы — в журнал событий.
7. **Эталон «как правильно»**: запись учителя главнее; для карточек с аятом — обучающее чтение Хусари
   (EveryAyah, кэш `data/recitations/`).
8. **Меню уроков — по 9 частям книги**, внутри части — уроки по 10 на страницу.
9. **Макеты** — обычная HTML-страница (`docs/design/mockups.html`, `make design`), опубликована ссылкой.

## Рассмотренные варианты
| Вопрос | Вариант | Плюсы | Минусы | Итог |
|---|---|---|---|---|
| Распознавание | **Muaalem (локально, mps)** | открытая, обучена на Коране, фонемы и таджвид | 2 ГБ, только Мединский мусхаф | ✅ |
| | Whisper / общий ASR | универсальный | слышит слова, а не огласовки; «исправляет» ошибки ученика | ❌ |
| | платный API (Tarteel и др.) | качество | нет API для фонем, данные уходят наружу | ❌ |
| Примеры из Корана | **текст мусхафа по скелету со скана** | точные огласовки и знаки, ссылка на аят | вариант мусхафа может отличаться от печати книги | ✅ |
| | переписать огласовки со скана | как в книге | риск ошибок агента (CLAUDE.md: не придумывать огласовки) | ❌ |
| Фраза из книги | **одна фраза — одна карточка** | короткие записи, точная оценка | карточек больше | ✅ |
| | строка книги целиком | как в книге | 3–4 разных аята в одной записи, слитное чтение искажает | ❌ |
| Эталон | **учитель + Хусари (муаллим)** | живой голос, обучающий темп | Хусари — только для аятов | ✅ |
| | синтез речи | для всего | неверный таджвид (ADR-0018) | ❌ |
| Закрепление | **вопрос «как читается слог»** | без голоса, быстро, активное припоминание | только буквы и огласовки | ✅ |
| | «услышь — выбери» | тренирует слух | нужен эталон каждого слога | позже (TD-FN-19) |
| Правила | **свои слова** | можно публиковать, понятно новичку | нужна проверка преподавателем | ✅ (M-13) |
| | текст книги | точно | авторское право (ADR-0022) | ❌ |
| Макеты | **HTML-страница** | открывается везде | — | ✅ |
| | холст Design | редактируемый | у автора не открылся | оставлен, но не основной |

## Последствия
- `curriculum_version` `2026.10.17-book-3`; id карточек `L001-01` (3 цифры уроков).
- Новые типы карточек `rule`; поля `quran`, `part`, `section`.
- aiohttp используется напрямую (уже зависимость aiogram) для скачивания аятов.
- Огласовки с. 10–37 — по-прежнему `verified: false` (TD-FN-11).
- Без интернета у карточек-аятов нет эталона (бот отвечает «записи нет»).

# Источники

Каждый источник получает постоянный ключ `SRC-NNN`. На ключ ссылаются код, YAML учебной программы,
ADR и текст диссертации. Колонка «Где используется» отвечает на вопрос «откуда это взялось».
BibTeX для LaTeX/Word — `sources.bib` (ключи совпадают).

**Надёжность:** A — рецензируемая публикация или первоисточник; B — препринт, официальная
документация, код автора; C — вторичный источник (блог, магазин приложений), только для ориентира.

## Как добавлять источник
1. Следующий свободный ключ; заполнить все колонки; для веб-страниц — дата просмотра.
2. Если взята конкретная строка или число — указать страницу/раздел в колонке «Что взяли».
3. Добавить запись в `sources.bib`.
4. В коде/YAML сослаться на ключ (`SRC-NNN`), в диссертации — через BibTeX.

Команда для агента: `/source`.

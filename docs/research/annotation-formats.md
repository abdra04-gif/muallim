## 1. Модели, которыми мы пользуемся

### Quran Muaalem (SRC-002) — в боте сейчас
| Что | Как |
|---|---|
| Записи | **только 22 профессиональных чтеца-мужчины**, 848 ч, 286 537 кусков |
| Нарезка | по паузам (вакф), своя модель на wav2vec2-BERT; проверка — 50–75 случайных кусков на чтеца |
| Распознавание текста | Tarteel ASR (Whisper, дообученный на Коране), WER ≈ 5,75 % |
| Сверка с Кораном | алгоритм Tasmeea; ниже 85 % совпадения — к человеку |
| Фонемы и сифаты | **программа строит их из текста** (26 правил-регулярных выражений + особенности чтения чтеца), не люди. Код: `external/obadx_prepare-quran-dataset/train.py` — фонетизатор на каждом примере |
| Люди | вручную размечено 5 400 кусков из 286 537 (≈ 1,9 %) |
| Ошибки учеников в обучении | **нет** — модель видела только правильное чтение |
| Обучение | 11 голов CTC (фонемы + 10 сифатов), веса потерь: фонемы 0,4, остальные ≈ 0,06–0,07; без языковой модели — «чтобы слышать, что сказано на самом деле»; изменение скорости 0,8–1,5×, шум; SpecAugment ухудшил |
| Ограничения (сами авторы) | только мужчины (на женских голосах точность 84,7 %); редкие ошибки (например, ر с раскатом там, где не надо) **не выучить без примеров таких ошибок** |

**Вывод для нас.** Muaalem никогда не слышала начинающих и не видела ни одной ошибки ученика. Наш набор —
русскоязычные новички, ошибки подтверждены учителем — закрывает ровно этот пробел. Это главный довод за
дообучение (B2) и за то, что датасет — вклад работы.

### Базовые модели Iqra'Eval (SRC-004, SRC-043) — для сравнения
| Что | Как |
|---|---|
| Обучение | Common Voice на арабском, 82 ч, правильное чтение; фонемы — из полностью огласованного текста программой |
| Искусственные ошибки | 26 ч речи синтезатора (7 голосов) с ошибками: в текст подставлены похожие звуки по **таблице пар** (ت/ط, س/ص…) + 26 ч без ошибок |
| Тест QuranMB | 18 носителей арабского **нарочно** делали ошибки по подсказке на экране; 98 аятов, ≈ 2,2 ч; размечали **3 лингвиста** |
| Фонемы | 62 фонемы (в статье 2025 г.; в `error-taxonomy.md` записано «68» — сверить) |
| Формат | CSV: `ID`, `Reference_phn` (как должно быть), `Annotated_phn` (что сказано), `Prediction` (что услышала модель) — **у нас уже есть** (`write_iqraeval`) |
| Метрики | TA, TR, FA, FR → FRR, FAR, точность, полнота, F1; диагноз верный / неверный |

**Вывод.** У Iqra'Eval ошибки ненастоящие (нарочные или синтезированные), говорят носители арабского.
Настоящих ошибок неарабов в их наборах нет — у нас будут.

## 2. Готовые датасеты: кто и как размечал
| Набор | Кто читает | Кто размечал | Единица | Категории | Согласие разметчиков | Формат |
|---|---|---|---|---|---|---|
| **QuranMB** (Iqra'Eval) | 18 носителей, нарочные ошибки | 3 лингвиста | фонема | замена / пропуск / вставка | не опубликовано | CSV, 3 строки фонем |
| **qdat_bench** (SRC-155, SRC-002) | 159 учащихся, один аят (5:109) | один эксперт (пересмотр QDAT) | правило в аяте + сифаты | длины маддов 0–8, гунна (неполная/полная), калькаля есть/нет, 10 сифатов на звук | нет (один разметчик) | Hugging Face, столбец на правило |
| **RetaSy** (SRC-032) | ≈ 1 300 неарабов из 11+ стран | толпа, итог — большинством голосов; «золотые» примеры — эксперты | запись целиком | верно / неверно / не Коран / не тот аят / несколько аятов / не дочитал | 0,63 | Hugging Face + JSON с ответом каждого разметчика |
| **L2-ARCTIC** (SRC-154; английский) | 24 неносителя | обученные разметчики в Praat | фонема на временной шкале | `ожидалось,услышано,s` — замена; `sil,услышано,a` — лишний звук; `ожидалось,sil,d` — пропуск; `err` — «не могу определить»; отдельный слой комментариев | — | TextGrid (Praat) |
| **speechocean762** (английский; добавить через `/source`) | 250 неносителей (дети и взрослые) | **5 экспертов** независимо | звук → слово → предложение | звук: 2 верно / 1 с акцентом / 0 неверно или пропущен (+ какой звук, похоже, сказан); слово: 0–10; предложение: точность, полнота, беглость, интонация | средние по 5 экспертам | JSON |

## 3. Чем размечают
- **Praat (TextGrid)** — L2-ARCTIC: точные границы звука, медленно, нужен обученный разметчик.
- **Своё приложение с подсказками** — QuranMB (запись нарочных ошибок), Quran Voice — RetaSy (толпа).
- **Label Studio** (`external/`) — общий инструмент, можно настроить под фонемы; веб, не Telegram.
- **Наш бот** (ADR-0072) — разметка в Telegram кнопками; руководитель будет размечать здесь.

## Важные доводы для диплома — ⚠️ сначала перепроверить (TD-FN-157)
Автор (2026-11-06): это сильная аргументация, но до текста диплома — перепроверить по первоисточникам.

1. **Muaalem не слышала ни одной ошибки ученика:** обучена только на 22 профессиональных чтецах-мужчинах,
   фонемы и сифаты строила программа по тексту; авторы пишут, что ошибкам, которых не было в обучении,
   модель не научится (SRC-002, v2). Проверить: v2 — последняя версия; нет ли учеников в дообучении или
   в версиях модели на Hugging Face после статьи.
2. **В открытых наборах нет настоящих ошибок неарабов с разметкой по звукам.** Уже видно, что «нет ни у кого»
   — слишком сильно: в RetaSy (SRC-032) **есть** настоящие записи неарабов, но оценка — «верно / неверно» за
   всю запись, без звуков; в qdat_bench — настоящие учащиеся, но один аят, а кто они (арабы или нет) — не
   выяснено; QuranMB — нарочные ошибки носителей. Осторожная формулировка: *открытого набора, где настоящие
   ошибки неарабов-начинающих размечены по звукам, не найдено*. Проверить: систематический поиск (связан с
   TD-FN-75), состав учащихся QDAT.

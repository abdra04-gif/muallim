# Обзор литературы — рабочие заметки

Черновик для главы 1 диссертации. Каждое утверждение — со ссылкой на источник из `sources.md`.

## 1. Автоматическая оценка произношения при чтении Корана
- **Muaalem (SRC-002, SRC-003).** Почти полностью автоматический конвейер сборки данных: ~848 ч
  аудио, ~286 тыс. размеченных фрагментов; собственная фонетическая запись Quran Phonetic Script,
  которая кодирует и звуки, и признаки артикуляции (сифат); многоуровневая CTC-модель. Заявленные
  результаты: PER по фонемам 0,543 % на собственном тесте (0,21 % в среднем по всем уровням), на qdat_bench —
  5,78 % по фонемам (1,94 % в среднем по уровням), F1 таджвида 75,8 % (сверено с arXiv v2 2026-10-18).
  *Важно для нас:* модель обучена в основном на чтении **чтецов-экспертов**, а наши пользователи —
  **начинающие**. Насколько её точность сохранится на речи новичков — открытый вопрос и потенциальный
  научный вклад работы (RQ-1); насколько точнее можно собрать систему из готовых моделей с помощью agentic
  loop-engineering — RQ-2 (ADR-0064; адаптация B1/B2 — компоненты, ADR-0051).
- **QuranMB.v1 (SRC-004).** Первый открытый тестовый набор для обнаружения ошибок произношения
  в арабском на материале Корана (Interspeech 2025). Можно использовать для внешней проверки модели.
- **QDAT.** Небольшой открытый набор, покрывающий несколько правил таджвида (упоминается в SRC-002).

## 2. Учебник «Муаллим ас-Сани» (SRC-001, SRC-005..007)
- Автор — Ахмад Хади Максуди (1868–1941); букварь для обучения неарабов чтению по-арабски; долго
  использовался в Центральной Азии и Поволжье.
- Структура зависит от издания. Одно открытое цифровое издание (SRC-005): 10 глав, 13 уроков,
  52 страницы. Издание Hilol Nashr 2023 (SRC-007) — 104 страницы.
- Порядок тем по описанию приложения (SRC-006, надёжность C): харакаты → мадд → ташдид → танвин →
  васл → вакф → идгам.
- **Пробел:** надёжного академического описания методики по книге найти не удалось — нужен
  первоисточник и консультация преподавателя (OQ-02, OQ-05).

## 3. Инженерия ПО с ИИ-агентами
- «Harness engineering» (SRC-011, вторичные источники): знания — в контекст, принуждение — в хуки,
  процедуры — в навыки, изоляция — в субагентов. Мы используем этот принцип (ADR-0012), но
  количественные утверждения из блогов в диссертации не цитируем.
- **LLM в проектировании архитектуры (SRC-050).** ИИ-ассистент ведёт проектирование по методу ADD вместе
  с архитектором; решения близки к проверенным, но драйверы архитектуры выполняются частично — нужен контроль
  человека. Близко к нашему протоколу решений (ADR-0021): агент предлагает варианты, человек утверждает.
- **Требования качества и метрики.** Сценарии качества (SRC-047) и GQM (SRC-048) — формат требований и
  метрик в проекте (ADR-0026).

## 4. Обновление 2026-10-17 (сводный отчёт SRC-038)
- **Эффект автоматической обратной связи:** метаанализ g = 0,69, выше для отдельных звуков и явной
  обратной связи (SRC-025); ASR ошибается на акценте → нужен контроль учителя (SRC-026).
- **Бенчмарки:** IQRA 2026 — лучший F1 0,72, данных L2-учеников нет (SRC-031); ближайший к нашим
  ученикам набор — RetaSy, ~7000 записей не-арабов (SRC-032).
- **Muaalem:** на реальных ошибках PER фонем 5,78 % против 0,54 % на экспертах; ихфа F1 0,45 — модель
  обучена только на мужчинах-экспертах (SRC-002; детали — в сводном отчёте).
- **Методика книги** — `docs/pedagogy/teaching-practice.md` (SRC-015…024).
- **Агенты:** правка тестов — основной способ «жульничества» (SRC-027); harness engineering (SRC-028, SRC-029);
  субъективное ощущение ускорения не совпадает с измеренным (SRC-030).

## 5. Репетиторы, которые слушают чтение, и измерение усвоения (2026-10-19, ADR-0052)
- **Рамка задачи — освоение чтения, а не только произношение.** «Муаллим ас-Сани» — букварь: ученик учится
  видеть букву с огласовкой и превращать её в звук. Ближайшие прецеденты — репетиторы чтения для детей,
  которые слушают чтение вслух: Project LISTEN (CMU), DART (Radboud), Lalilo (Франция).
- **Отслеживание знаний.** Байесовское отслеживание знаний (BKT, SRC-124) оценивает вероятность «навык
  усвоен» по последовательности попыток; обзор моделей ученика и метрик их оценки (AUC, калибровка) —
  SRC-126; нейросетевой вариант — SRC-127 (на малых данных — только разведка); кривые обучения и проверка
  карты навыков — AFM (SRC-128); забывание по логам — SRC-129.
- **Ближайший прецедент RQ-3 — SRC-125 (Project LISTEN):** отслеживание знаний по шумному выходу
  распознавателя речи, усвоение 80 соответствий «буква–звук» у детей. Чего там нет: шум распознавателя
  не измерялся против учителей и не входил в модель явно; язык — английский, ученики — дети.
- **DART (SRC-130, SRC-131):** репетитор чтения с распознаванием речи для первоклассников; отдельно
  измеряют точность ИИ (κ, MCC против людей) и как учатся дети (эксперименты на 525 и 752 детях, прогресс
  чтения по логам). Схема «точность ИИ → как учатся люди» — образец для RQ-1/RQ-2 → RQ-3 (дополнительный).
- **Lalilo (SRC-132, PhD Gelin, 2022; SRC-133):** распознавание фонем у начинающих читателей, адаптация
  самообучаемых моделей, симуляция ошибок чтения для обучения модели — близко к нашему пополнению данных
  по минимальным парам книги (RQ-2).
- **Оценка по усвоению (SRC-134, SRC-135; научный руководитель):** образовательные системы чаще оценивают по
  кликам и оценкам, по результатам обучения — лишь около трети работ; OBER оценивает по усвоению.
  Довод за дополнительный RQ-3 и мост к докторантуре (выбор следующей карточки по измеренному усвоению).
- **Пробел (предварительно):** не найдено работ, где модель усвоения учитывает ошибки распознавателя,
  измеренные против учителей, и нет данных по взрослым неарабам, которые учатся читать арабское письмо
  (QuranMB и Iqra'Eval прямо называют отсутствие L2-учеников, SRC-004, SRC-043; L2-KSU — 40 неарабов, по
  запросу). Это вывод из нескольких поисков; систематическая проверка — TD-FN-75.
- **Ошибки ранних читателей арабского:** у детей-арабов больше ошибок в гласных, чем в согласных, и путаница
  букв, различающихся точками — исследования на детях-носителях; по взрослым неарабам данных не найдено.
  Отсюда разделение «ошибка чтения / ошибка произношения» в разметке (ADR-0052).

## Исследовательские вопросы (ADR-0064; по замечаниям руководителя 2026-10-22, гипотезы RQ-2 и RQ-3 — с руководителем)
**Тема:** «Сбор речевого датасета и обучение моделей для обнаружения ошибок чтения и произношения и оценки усвоения у начинающих изучать арабский язык и чтение Корана».
**Гипотеза.** Собрав небольшой курированный речевой датасет, можно оценить существующие решения и с помощью agentic loop-engineering разработать эффективный инструмент для внеклассной практики начинающих.
- **RQ-1.** Насколько надёжно существующие модели распознавания и анализа речи обнаруживают ошибки чтения и произношения у начинающих изучать арабский язык и чтение Корана? *Данные:* разметка двух учителей с типом ошибки (TD-FN-76), выходы B0 и других готовых моделей.
- **RQ-2.** Насколько применение agentic loop-engineering для поиска и комбинирования конфигураций существующих моделей и компонентов повышает точность обнаружения ошибок чтения и произношения по сравнению с базовыми подходами? *Данные:* замороженный тест по ученикам с разметкой двух учителей (`preregistration.md` §2); журнал agentic loop; компоненты B1/B2 (ADR-0051).
- **RQ-3 (дополнительный).** В какой степени использование разработанного инструмента во внеклассной практике влияет на динамику освоения учебного материала начинающими, обучающимися с преподавателем? *Данные:* оценка модели усвоения K0/K1/K2, тест учителя в трёх точках (TD-FN-77), кривые обучения по навыкам.

Прежние RQ-2…RQ-4 (как учится ИИ, измерение усвоения, как учатся люди, ADR-0052) — в план докторантуры
(`roadmap.md`, Этап 2; перепроверить — TD-FN-96).
До ADR-0052: объяснения ошибок (тогдашний RQ-3) — разведка E-7; обвязка ИИ-агентов (тогдашний RQ-4) — раздел методики (OQ-13).

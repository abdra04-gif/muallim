# Обзор литературы — рабочие заметки

Черновик для главы 1 диссертации. Каждое утверждение — со ссылкой на источник из `sources.md`.

## 1. Автоматическая оценка произношения при чтении Корана
- **Muaalem (SRC-002, SRC-003).** Почти полностью автоматический конвейер сборки данных: ~848 ч
  аудио, ~286 тыс. размеченных фрагментов; собственная фонетическая запись Quran Phonetic Script,
  которая кодирует и звуки, и признаки артикуляции (сифат); многоуровневая CTC-модель. Заявленные
  результаты: PER по фонемам 0,543 % на собственном тесте (0,21 % в среднем по всем уровням), на qdat_bench —
  5,78 % по фонемам (1,94 % в среднем по уровням), F1 таджвида 75,8 % (сверено с arXiv v2 2026-10-18).
  *Важно для нас:* модель обучена в основном на чтении **чтецов-экспертов**, а наши пользователи —
  **начинающие**. Насколько её точность сохранится на речи новичков — открытый вопрос и потенциальный
  научный вклад работы (RQ-1); как её адаптировать к новичкам — RQ-2 (ADR-0051).
- **QuranMB.v1 (SRC-004).** Первый открытый тестовый набор для обнаружения ошибок произношения
  в арабском на материале Корана (Interspeech 2025). Можно использовать для внешней проверки модели.
- **QDAT.** Небольшой открытый набор, покрывающий несколько правил таджвида (упоминается в SRC-002).

## 2. Учебник «Муаллим ас-Сани» (SRC-001, SRC-005..007)
- Автор — Ахмад Хади Максуди (1868–1941); букварь для обучения неарабов чтению по-арабски; долго
  использовался в Центральной Азии и Поволжье.
- Структура зависит от издания. Одно открытое цифровое издание (SRC-005): 10 глав, 13 уроков,
  52 страницы. Издание Hilol Nashr 2023 (SRC-007) — 104 страницы.
- Порядок тем по описанию приложения (SRC-006, надёжность C): харакаты → мадд → ташдид → танвин →
  васл → вакф → идгам.
- **Пробел:** надёжного академического описания методики по книге найти не удалось — нужен
  первоисточник и консультация преподавателя (OQ-02, OQ-05).

## 3. Инженерия ПО с ИИ-агентами
- «Harness engineering» (SRC-011, вторичные источники): знания — в контекст, принуждение — в хуки,
  процедуры — в навыки, изоляция — в субагентов. Мы используем этот принцип (ADR-0012), но
  количественные утверждения из блогов в диссертации не цитируем.
- **LLM в проектировании архитектуры (SRC-050).** ИИ-ассистент ведёт проектирование по методу ADD вместе
  с архитектором; решения близки к проверенным, но драйверы архитектуры выполняются частично — нужен контроль
  человека. Близко к нашему протоколу решений (ADR-0021): агент предлагает варианты, человек утверждает.
- **Требования качества и метрики.** Сценарии качества (SRC-047) и GQM (SRC-048) — формат требований и
  метрик в проекте (ADR-0026).

## 4. Обновление 2026-10-17 (сводный отчёт SRC-038)
- **Эффект автоматической обратной связи:** метаанализ g = 0,69, выше для отдельных звуков и явной
  обратной связи (SRC-025); ASR ошибается на акценте → нужен контроль учителя (SRC-026).
- **Бенчмарки:** IQRA 2026 — лучший F1 0,72, данных L2-учеников нет (SRC-031); ближайший к нашим
  ученикам набор — RetaSy, ~7000 записей не-арабов (SRC-032).
- **Muaalem:** на реальных ошибках PER фонем 5,78 % против 0,54 % на экспертах; ихфа F1 0,45 — модель
  обучена только на мужчинах-экспертах (SRC-002; детали — в сводном отчёте).
- **Методика книги** — `docs/pedagogy/teaching-practice.md` (SRC-015…024).
- **Агенты:** правка тестов — основной способ «жульничества» (SRC-027); harness engineering (SRC-028, SRC-029);
  субъективное ощущение ускорения не совпадает с измеренным (SRC-030).

## Исследовательские вопросы (черновик, утверждает руководитель)
- **RQ-1.** Насколько автоматическая проверка (Muaalem + правила) согласуется с оценкой
  преподавателя на чтении начинающих по «Муаллим ас-Сани»? *Метрика:* доля совпадений вердикта,
  precision/recall обнаружения ошибок по разметке (`annotations`).
  Вторая часть RQ-1 (до ADR-0051 — RQ-2): какие ошибки модель чаще всего пропускает или выдумывает у
  новичков? *Данные:* отчёты 03–05 в `analytics/sql/`.
- **RQ-2 (ADR-0051).** Насколько адаптация модели на собранном наборе — калиброванный верификатор с
  «не уверен» (B1) и дообучение LoRA (B2) — уменьшает ложные отклонения и приближает проверку к учителю
  на новых учениках, не ухудшая чтение экспертов? *Данные:* замороженный тест по ученикам со слепой
  разметкой (`preregistration.md` §2).
- **RQ-3.** Улучшают ли объяснения ошибок по-русски результат повторной попытки? *Данные:* пары
  последовательных попыток одного ученика по одной карточке.

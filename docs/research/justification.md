# Обоснование методики: реестр

Каждое методическое решение и чем оно обосновано. Ведёт `/justify`; решения принимает автор и
руководитель (`/supervisor`). Строки не удаляются: меняются статус, обоснование и дата.

**Статус:** ✅ по источнику · 🧮 по расчёту · 🟡 решение автора с причиной · 🔴 дыра · ⏳ не утверждено.

**Счётчик:** ✅ 0 · 🧮 0 · 🟡 0 · 🔴 0 · ⏳ 0 (реестр ещё не заполнен; запусти `/justify всё`)

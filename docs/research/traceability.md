## Правила
- Цифра попадает в главу, только если её строка здесь имеет статус ✅ и результат есть в
  `../thesis/figures.md` с паспортом (отчёт, дата, n, отпечаток кода — `make trace`).
- Новая метрика → сначала строка в `metrics-gqm.md`, потом здесь. Метрика без RQ сюда не попадает.
- Гипотеза меняется после начала сбора данных → новая версия `preregistration.md` с причиной;
  старая версия и её отпечаток остаются в `research-log.md`.

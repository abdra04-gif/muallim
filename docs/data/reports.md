# Отчёты

`uv run muallim-research report` выполняет все запросы из `analytics/sql/` по порядку и сохраняет
`analytics/reports/report_<дата>.md`. Новый отчёт = новый файл `NN_название.sql`; первая строка
комментария становится заголовком раздела. Тест `test_report_runs_every_sql_file` проверяет, что
каждый запрос выполняется.

| Файл | Вопрос | Для чего в диссертации |
|---|---|---|
| `01_overview.sql` | Сколько учеников, попыток, записей, разметки? | описание выборки |
| `02_item_difficulty.sql` | Какие карточки труднее всего? | педагогический анализ |
| `03_error_kinds.sql` | Какие типы ошибок находит система? | RQ-2 |
| `04_letter_confusions.sql` | Какие буквы путают и с чем? | RQ-2, сравнение с подсказками в `lexicon.ru.yaml` |
| `05_annotation_labels.sql` | Совпадает ли вердикт модели с разметкой? | RQ-1 |
| `06_learner_activity.sql` | Активность по псевдонимам | вовлечённость |

| `07_learner_disputes.sql` | Какие проверки ученики оспаривают? | RQ-1 (ложные срабатывания) |
| `11_errors_by_native_language.sql` | Отличаются ли ошибки по родному языку и опыту чтения? | RQ-2, H2.1 (анкета FR-44) |

Попытки с `model_version = 'stub'` исключаются везде.

## Метрики GQM (`src/muallim/research/metrics.py`)
Тот же `make report` дописывает в конец отчёта метрики из `docs/research/metrics-gqm.md`. Они считаются
в Python: κ, процентили и разница в днях не пишутся одним SQL для SQLite и PostgreSQL.

| Раздел | Что | Цель |
|---|---|---|
| Точность проверки | precision, recall, F1 (всего и precision по типу ошибки), FAR, FRR, κ «бот — учитель» и «учитель — учитель» | G1, RQ-1 |
| Время ответа | p50, p90, максимум `processing_ms` | G5, QAS-03 |
| Сбои распознавания | доля событий `recognition_failed`, по этапам `decode` / `model` | G5, QAS-04 |
| Возврат учеников | вернулись в другой день; через ≥ 7 дней — только в когорте начавших 7+ дней назад | G4 |

Вердикт учителя выводится из метки на всю попытку: `correct` — согласен с ботом, `false_alarm` —
засчитать, `missed_error` / `wrong_error` — не засчитывать; `audio_unusable` и `off_task` не входят.
Для κ «учитель — учитель» берётся первая метка каждого из двух первых разметчиков попытки.

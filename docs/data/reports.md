# Отчёты

`uv run muallim-research report` выполняет все запросы из `analytics/sql/` по порядку и сохраняет
`analytics/reports/report_<дата>.md`. Новый отчёт = новый файл `NN_название.sql`; первая строка
комментария становится заголовком раздела. Тест `test_report_runs_every_sql_file` проверяет, что
каждый запрос выполняется.

| Файл | Вопрос | Для чего в диссертации |
|---|---|---|
| `01_overview.sql` | Сколько учеников, попыток, записей, разметки? | описание выборки |
| `02_item_difficulty.sql` | Какие карточки труднее всего? | педагогический анализ |
| `03_error_kinds.sql` | Какие типы ошибок находит система? | RQ-4 (ADR-0052) |
| `04_letter_confusions.sql` | Какие буквы путают и с чем? | RQ-4, сравнение с подсказками в `lexicon.ru.yaml` |
| `05_annotation_labels.sql` | Совпадает ли вердикт модели с разметкой? Сколько самоисправлений (`self_corrected`)? | RQ-1 |
| `06_learner_activity.sql` | Активность по псевдонимам | вовлечённость |

| `07_learner_disputes.sql` | Какие проверки ученики оспаривают? | RQ-1 (ложные срабатывания) |
| `11_errors_by_native_language.sql` | Отличаются ли ошибки по родному языку и опыту чтения? | RQ-4, разведка E-1 (анкета FR-44) |

Попытки с `model_version = 'stub'` исключаются везде.

## Метрики GQM (`src/muallim/research/metrics.py`)
Тот же `make report` дописывает в конец отчёта метрики из `docs/research/metrics-gqm.md`. Они считаются
в Python: κ, процентили и разница в днях не пишутся одним SQL для SQLite и PostgreSQL.

| Раздел | Что | Цель |
|---|---|---|
| Точность проверки | по фонемам: TA/FR/FA/TR, precision, recall, F1, FAR, FRR, верный диагноз; по типу ошибки; FAR/FRR вердикта; κ «бот — учитель» и «учитель — учитель»; α по фонемам | G1, RQ-1 |
| Самоисправления | попытки «сам исправился» (руководство 2.1): число, TA/FR/FA/TR, precision, recall, F1 — **не входят** в «Точность проверки» (ADR-0044) | G1, RQ-1 (разведка) |
| Согласие разметчиков с ботом | `agree` / `fix` по каждому разметчику, отдельно для засчитанных и не засчитанных ботом строк; доля согласия | G1, Q1.3 |
| Время ответа | p50, p90, максимум `processing_ms` | G5, QAS-03 |
| Сбои распознавания | доля событий `recognition_failed`, по этапам `decode` / `model` | G5, QAS-04 |
| Возврат учеников | вернулись в другой день; через ≥ 7 дней — только в когорте начавших 7+ дней назад | G4 |

Разметчик записывает, что прозвучало (`corrected_phonemes`); бот и разметчик сравниваются с эталоном
по каждой фонеме (SRC-064). Вердикт учителя — та же политика оценки, применённая к его транскрипции,
с порогами, с которыми попытку оценил бот (`attempts.policy`). Берётся **последняя** метка каждого
разметчика; для κ «учитель — учитель» — два первых по коду разметчика; `audio_unusable` и `off_task`
не входят, метки руководства 1.0 — тоже; попытки «сам исправился» — в своём разделе.

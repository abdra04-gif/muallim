# Руководство по разметке

Версия: 1.0 (2026-10-17). Версия пишется в каждую метку (`annotations.guide_version`);
при изменении правил увеличьте её здесь и в `src/muallim/research/annotation.py` (`GUIDE_VERSION`).

## Зачем
Найти, где автоматическая проверка ошибается на чтении **начинающих**, и получить эталонные
данные для оценки и дообучения модели (RQ-1, RQ-2).

## Кто размечает
Преподаватель или студент, уверенно читающий с таджвидом. Каждый разметчик получает код (A1, A2…);
таблица «код → человек» хранится **вне** репозитория.

## Как
1. `uv run muallim-research annotation-export --limit 50` → `data/annotation/queue_<дата>.csv`.
2. Открыть CSV (Excel, LibreOffice, Google Sheets — без загрузки в облако, если аудио приватное).
3. Для каждой строки прослушать `audio_file`, посмотреть `item_id`, `verdict`, `detected_errors`.
   Если заполнено `learner_report` — ученик нажал «бот ошибся» (такие строки идут первыми).
4. Заполнить `label`, при необходимости `corrected_phonemes` и `comment`. Пустую строку пропустить.
5. `uv run muallim-research annotation-import <файл> --annotator A1`.

## Метки (на попытку целиком)
| Метка | Когда ставить |
|---|---|
| `correct` | вердикт системы и список ошибок верны |
| `false_alarm` | система нашла ошибку, которой не было (ученик прочитал верно) |
| `missed_error` | ученик ошибся, а система не заметила; впишите `corrected_phonemes` |
| `wrong_error` | ошибка была, но система описала её не так (не та буква, не тот тип) |
| `audio_unusable` | шум, тишина, обрезано, несколько голосов — оценить нельзя |
| `off_task` | прочитано не то, что на карточке |

Если подходит несколько меток — выбирайте по порядку сверху вниз в таблице, кроме
`audio_unusable` и `off_task`, которые имеют приоритет.

## Согласованность разметчиков
Каждая 10-я попытка размечается двумя людьми независимо; согласие считается каппой Коэна
(отчёт будет добавлен в `analytics/sql/` после первых 200 меток).

## Почему CSV, а не Label Studio
Рассмотрен Label Studio с версионированием разметки (SRC-013). Для первых сотен записей CSV проще:
не нужен сервер, файл версионируется в git, понятен преподавателю. Пересмотреть при > 2000 записей
или > 3 разметчиков.

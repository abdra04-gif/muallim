## Принципы
1. **Одно окно.** Кнопки меняют экран на месте (edit) — чат не растёт и не уезжает вниз.
2. **🏠 Главная на каждом экране**, «▶️ Продолжить» с того места, где остановился.
3. **Как в книге.** Урок 1 — вся таблица алфавита (с. 10), дальше буквы по одной в порядке книги.
   Строка книги — крупно картинкой, буква урока — красным, как в книге; ссылка «с. N, строка M».
4. **Ошибки видны в тексте** (как в Tarteel): неверные буквы — красные на розовом, полоса сверху — оценка.
5. **Прогресс.** Карта букв: зелёные — пройдены, жёлтые — начаты, красная — текущая; ✅/🟡/⚪ в списке уроков;
   🎉 «Урок пройден» и кнопка «Следующий урок»; 🔥 серия дней подряд (как в Duolingo).
6. **Как правильно.** 🔊 эталон записывает учитель прямо в боте (TEACHER_IDS) — синтез речи отклонён (ADR-0018).

# Журнал срабатываний хуков

Файл на месяц: `ГГГГ-ММ.jsonl`, одна строка — одно срабатывание. Пишут `_common.block` и
`_common.log_event` (`.claude/hooks/`), ADR-0034. Данные для Q6.1 (`docs/research/metrics-gqm.md`):
что блокируют проверки и как часто агенту нужно подтверждение человека.

| Поле | Что |
|---|---|
| `ts` | время UTC |
| `hook` | `guard`, `stop_gate`, `human_zones` |
| `kind` | `block` — действие отменено; `ask` — запрошено подтверждение человека |
| `reason` | первая строка причины (до 160 знаков) — без команд, вывода тестов и данных |

Файлы не правятся руками.

# Протоколы встреч

Встречи с научным руководителем, преподавателями (разметчики, эталонные записи) и консультантами
(юрист, этическая комиссия). Один файл на встречу: `ГГГГ-ММ-ДД-кто.md`, например `2026-11-05-руководитель.md`.

**Зачем:** решения руководителя — такой же источник требований, как ADR. Протоколы показывают, *кто* и
*когда* изменил план (глава 3, предзащита), и закрывают вопросы из `research/open-questions.md`.
Протокол пишет автор (агент может составить черновик по его заметкам). После встречи протокол не
переписывают: уточнение записывают в следующий.

## Перед встречей
1. Повестка: риски 🔴 из `docs/risks.md`, открытые вопросы (OQ-…) «кто решает: руководитель», что сделано с прошлой встречи.
2. Пересмотреть реестр рисков (процесс — в `docs/risks.md`).

## После встречи
1. Каждое решение превратить в изменение: ADR, FR/NFR в `requirements.md`, строку в `tech-debt.md` или `roadmap.md`.
2. Закрыть вопросы OQ-… с датой и ответом.
3. Добавить строку в журнал ниже.

# Сессия 2026-11-15/19 — демо «Муаллим 2.0» для профессоров

**С чем пришли.** Замечания профессоров (`docs/research/professor-feedback-2026-11.md`): показать первую
версию, только буквы и огласовки, без кириллицы, без звука и картинок от ИИ, короткие видео живых людей,
«прочитать один раз», прогресс и серия. Задание ChatGPT на бота — `docs/design/handoff/`.

**Что сделано (только демо, код бота не менялся).**
- Живая страница-телефон `docs/site/lessons.*` (`make site`), RU/EN переключатель на всю страницу:
  урок = страница книги; «▶ Начать» → сначала алфавит (крупная таблица всех букв, 5 мин) → урок 1;
  видео — shorts Dr. Ayman Swaid, «Подробнее» — уроки Абу Ясина (Руслан Маликов, «Исламские уроки»),
  все ID сверены через oEmbed 2026-11-18, таблица в `docs/site/lessons-content.yaml`.
- Новое «Повторение» одним экраном: сверху «Сегодня повторяем: …» + «▶ Повторить» (или «повторять
  нечего ✓» / пример для пустого), ниже меню из четырёх строк: буквы, уроки, ошибки, алфавит.
- Разделы сайта: ответы на три круга вопросов профессоров (в т. ч. «о чём первые 9 страниц» —
  вступление, упражнения с с. 10), исследование (пять фаз, эксперимент на 8 904 записях), Муаллим и
  другие, минусы → исправления, согласие на датасет, дорожная карта, ключевые публикации.
- Макеты экранов 2.0 — `docs/design/widgets/v3/`; ADR-0083 (принято), ADR-0085 (предложено).

**Не сделано — для следующей сессии (перенос в бота, `/feature`).**
1. Главная «▶ Начать» → алфавит → урок 1. 2. Урок = страница книги с видео (Swaid → Абу Ясин).
3. «Повторение» одним экраном. 4. Прогресс урока и общий, серия, веха «все буквы».
Виджеты Telegram — после обычных сообщений и кнопок (aiogram пока не умеет `sendWidget`).

**Решает автор (не начинать без ответа, `/decide`):** как объяснять огласовки; заметка о сукуне;
интервалы повторения; когда урок засчитан (мягкий зачёт против M-01/M-02/M-12); шаг «скажи слог»;
пауза серии. Также: записи учителя (эталон), экран согласия в настоящем боте (ADR-0085).

**Заметки.** Папка `build` в `docs/site` не коммитится (там страницы скана книги), собирается `make site`.

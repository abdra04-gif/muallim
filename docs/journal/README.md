# Журналы

| Папка | Что | Кто пишет |
|---|---|---|
| `prompts/` | каждый запрос к ИИ-агенту | хук, автоматически |
| `sessions/` | сводка рабочей сессии с агентом (ADR-0021) | агент, `/session-summary` |
| `meetings/` | протоколы встреч с руководителем и преподавателями | автор |

## История запросов

`prompts/ГГГГ-ММ.md` — каждый запрос человека к ИИ-агенту (Claude Code) с датой и временем.
Пишет хук `.claude/hooks/log_prompt.py` автоматически; секреты (токены, пароли) маскируются.

Зачем: воспроизводимость методики (глава 3), возможность через годы вспомнить, *что* просили и
*почему* проект устроен так. Файлы не редактируются вручную.

Запросы до создания хука (2026-10-17, перенос прототипа) восстановлены в `prompts/2026-10.md`
по истории сессии.

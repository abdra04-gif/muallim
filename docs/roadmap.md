# Дорожная карта: магистратура → докторантура

Карта того, *что* делать и *в каком порядке*, чтобы магистерская работа стала фундаментом докторской.
Каждый пункт превращается в требование (FR/NFR) и задачу, когда до него доходит очередь.

## Этап 2. Докторантура (направления)
| Направление | Научный вопрос | Что подготовить уже сейчас |
|---|---|---|
| **Своя модель для L2-начинающих** | Насколько дообучение на речи русско-/казахоязычных новичков снижает ложные срабатывания? | копить аудио с согласием, разметку `corrected_phonemes`, версии модели в каждой попытке ✅ |
| **Калибровка и «не уверен»** | Как выбирать пороги так, чтобы ложная тревога была редкой, а пропуск — безопасным? | хранить сырые выходы модели (`model_output`) ✅, жалобы учеников ✅ |
| **Адаптивное обучение** | Модели знаний ученика (Knowledge Tracing, BKT/DKT) по буквам; оптимальный порядок и интервалы повторения | журнал событий и попыток с временем ✅; FR-15 интервальное повторение |
| **Полный курс книги + таджвид** | Автоматическая проверка правил (мадд, идгам, ихфа, калькаля) у новичков; ихфа у Muaalem F1 = 0,45 | уроки 3+ с правилами; разметка по правилам |
| **Лонгитюдное исследование** | Как быстро осваивают чтение с ботом vs с учителем vs смешанно? Сколько учителю экономится времени? | постоянный ID ученика ✅, псевдонимы ✅, длительные данные |
| **Межъязыковое сравнение** | Различаются ли трудности у носителей русского, казахского, узбекского, татарского? | язык ученика и язык объяснений в каждой попытке ✅ |
| **Объяснимость и доверие** | Как ложные срабатывания влияют на мотивацию и отсев? | кнопка «бот ошибся» ✅, события отсева |
| **Методология ИИ-агентной разработки научного ПО** | Насколько хуки/замороженные тесты снижают дефекты и «подгонку»? | журнал запросов ✅, журнал сессий, метрики хуков |
| **Открытый датасет и бенчмарк** | Первый открытый набор речи L2-начинающих на букварном уровне | согласия с правом публикации (TD-SEC-02) |

## Что важно не потерять между этапами
- **Стабильные ID:** ученик (`learners.id`, псевдоним), карточка (`L18-01` — урок 18, карточка 1), попытка (UUID) — никогда не переиспользуются.
- **Версии:** код (`app_version`), контент (`curriculum_version`), модель (`model_version`), руководство по разметке (`guide_version`) — в каждой записи.
- **Теги git** на каждый пилот/выгрузку: `pilot-2027-01`, `dataset-v1`.
- **Журналы:** запросы к ИИ, сессии, исследования, решения (ADR) — не редактировать задним числом.

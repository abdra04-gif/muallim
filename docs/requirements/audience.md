# Для кого этот бот (главное ограничение проекта)

**Ученики — русскоязычные взрослые (Россия, Казахстан), которые учат арабское чтение С НУЛЯ.**
Арабский им не родной: они не знают букв, огласовок и звуков, которых нет в русском (ع ح ق ص ض ط ظ …).
Цель — научиться правильно читать Коран по книге «Муаллим сани» (SRC-040).

Что из этого следует для любого решения:
1. **Ничего не предполагать заранее.** Каждый новый знак объясняется по-русски до того, как его
   нужно читать (карточки «📘 Правило», экран «🔤 Знаки»).
2. **Порядок — строго по книге**, маленькими шагами (урок ≤ 12 строк).
3. **Сначала слышать, потом читать**: эталон 🔊 (учитель, готовая запись ар-Раи или аль-Афаси) на каждой строке, где он есть.
4. **Объяснение ошибки — по-русски и через знакомые звуки**, ошибка видна в самом тексте.
5. **Закрепление** — короткие вопросы «как читается слог» по пройденным буквам.
6. **Без наказаний**: можно повторять сколько угодно, серия дней — мотивация, а не штраф.
7. **Уважение к тексту Корана**: точный текст Мединского мусхафа (SRC-041), начало — истиаза и басмала.

Другие языки объяснений (казахский, английский) — позже (ADR-0022).

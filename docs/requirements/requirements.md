# Требования

Каждое требование имеет постоянный ID. На ID ссылаются ADR, код, тесты и матрица трассировки
(`traceability.md`). Удалённое требование не стирается — статус «Отменено» и причина.

**Приоритет (MoSCoW):** M — обязательно, S — желательно, C — можно, W — не в этой версии.
**Статус:** ✅ сделано · 🟡 частично · ⏳ запланировано · ❌ отменено.

## Цель системы
Автоматизировать проверку чтения начинающих по учебнику «Муаллим ас-Сани», чтобы один преподаватель
мог сопровождать больше учеников, а данные о попытках помогали улучшать модель проверки.
Преподаватель остаётся в цикле: он размечает спорные случаи и утверждает учебный контент
(полностью заменить его на этапе магистратуры нельзя — точность модели на речи новичков ещё не измерена,
см. RQ-1 в `docs/research/literature-review.md`).

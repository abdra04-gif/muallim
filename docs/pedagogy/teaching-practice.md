## 1. Две книги Максуди — не путать
| Книга | Что это | Год | Источник |
|---|---|---|---|
| «Мөгаллим әүвәл» («Первый учитель») | букварь татарской грамоты на арабской графике; слого-звуковой метод | 1892 (первое изд.); >30 переизданий, >1,2 млн экз. к 1918 г. | SRC-015 (с. 1361–1362), SRC-019 |
| «Мөгаллим сәни» («Второй учитель») | продолжение: от знания письма — к правильному чтению Корана (арабский, основы таджвида) | середина 1890-х (по SRC-018); **год первого издания не подтверждён первоисточником**; основа современного текста — Казань, «Өмид», 1917 | SRC-015 (с. 1362), SRC-018, SRC-024 |

В интернете и у продавцов эти книги часто путают (1892 год приписывают «Сани»). В диссертации
ссылаться на **конкретное издание, проверенное в руках** (OQ-02).

## 2. Метод: от букв-названий к звукам
Татарская школа знала три метода обучения грамоте (SRC-017, с. 139–140):

| Метод | Название в медресе | Суть | Эпоха |
|---|---|---|---|
| Буквослагательный | ысулы хәрфия (усул-и кадим) | сначала заучивают **названия** букв (алиф, ба, та…), потом складывают слоги | старый |
| Слоговой | ысулы мәддия | сразу учат слоги: ба, би, бу; аб, иб, уб… | переходный |
| Звуковой | ысулы саутия (усул-и джадид) | буква = звук; слоги и слова собираются осознанно | джадидский |

Джадидский переход к звуковому методу сократил обучение чтению «с нескольких лет до одного учебного
года» (SRC-016). Максуди сравнил все три метода, в ранних изданиях букваря выбрал последовательный
слоговой, в поздних — пометил как «звуковой метод» (SRC-015, с. 1361).

**Новаторство Максуди (SRC-015, с. 1361):**
1. Отказ от заучивания названий букв.
2. Фонетическая ориентация — внимание к артикуляции и звучанию.
3. Постепенность, доступность, осмысленность.

## 3. Дидактические принципы Максуди → требования к боту
Максуди в статье «Основы обучения» (1906) сформулировал 15 принципов подачи материала; в современной
систематизации они сводятся к четырём группам (SRC-015, с. 1363, со ссылкой на Саттарова, 2020):

| Принцип Максуди | Как воплощён / должен воплощаться в боте | Статус |
|---|---|---|
| **Постепенность и преемственность** — «от простого к сложному» | уроки по порядку книги; переход дальше — когда карточка засчитана | 🟡 порядок L01 не совпадает с книгой (см. §5) |
| **Индивидуализация и активизация** — учёт особенностей ученика, самостоятельная работа | свой темп, своя история попыток, повтор слабых карточек, язык объяснений | 🟡 язык — FR-22; интервальное повторение — FR-15 ⏳ |
| **Наглядность и апперцепция** — опора на восприятие, связь нового с известным | **эталонное аудио** «как правильно» (FR-20), транскрипция на родном алфавите (FR-21), подсказки через знакомые звуки русского/казахского | ⏳ → реализуется |
| **Практика и непрерывный контроль понимания** | каждая попытка проверяется сразу; объяснение ошибки; повтор | ✅ |
| **Гуманизм, без наказаний** | мягкие формулировки, без штрафов; можно повторять сколько угодно | ✅ |
| Отказ от названий букв, фонетическая ориентация | карточка учит **звук** (с фатхой), а не название | ✅ (название показывается как справка) |

## 4. Как учат сегодня
**Цикл урока** во всех найденных курсах одинаков — это цифровая версия таляккы (передачи «из уст в уста»):
1. **Услышать образец** (учитель / видео).
2. **Повторить** за ним (в видеокурсе — каждую строку 3 раза, SRC-021).
3. **Прочитать самостоятельно** строку слогов/слов.
4. **Исправление** — учитель или напарник (ustaz.ru советует заниматься вдвоём, чтобы напарник указывал на ошибки, SRC-022).
5. **Дальше** — когда строка прочитана без ошибок.

| Курс | Формат | Объём | Источник |
|---|---|---|---|
| Видеокнига «Муаллим Сани» (Ш. Абу Али Ходжаев, А. Рустамов; Islamindex/iMedia, 2014) | 16 видеоуроков ≈ 8 ч + PDF | алфавит → харакаты → группы букв → мадд, ташдид → танвин, хамза → нун/мим сакин → мадды → вакф → суры | SRC-021 (C) |
| Rutube / YouTube серии | 18 уроков | — | SRC-021 (C) |
| ustaz.ru, Л. Хайрутдинов | видеоуроки (заявлено 125, перечислено ≈70) | введение → 28 букв (произношение, чтение, письмо) → 29 правил → практика на сурах | SRC-022 (C) |
| Мечети ДУМ РТ | очные курсы; еженедельная проверка чтения выпускников | часы и критерии не опубликованы | SRC-039 (B) |
| ДУМК (Казахстан) | официальная раздача книги в мечети и медресе с 2014 г. | — | SRC-020 (A) |

**Важное наблюдение для дизайна:** преподаватели прямо советуют **не учиться по транскрипции** —
«на бумаге невозможно передать звук» (SRC-022), «постоянное чтение по транскрипции не рекомендуется»
(SRC-021). Казахское издание книги (Алматы, 2001) подчёркивает, что не заменяет живого учителя (см. заметки, надёжность C).
→ Решение M-09 (`methodology.md`): транскрипция — вспомогательная подсказка, главное — эталонное аудио.

## 5. Порядок букв в книге ≠ порядок в боте
Два независимых источника (SRC-021; казахский блог по изданию 1918 г.) сходятся: книга вводит буквы
**группами**, начиная с **ا ر ز م** (несоединяемые/простые формы, из которых сразу складываются слоги
زَرَ، مَرَ), а не по алфавиту.
→ **Сделано 2026-10-17 (ADR-0022):** по изданию SRC-040 (с. 10–24) порядок: ء → ر ز م → ت ن → ي ب → ك ل →
و ه → ف ق → ش س → ث ص → ط → ج خ → ح غ → ع د → ض ذ → ظ; уроки бота L01–L28 идут так же. Порядок совпадает
с узбекским изданием «Муаллими соний», т. е. это порядок самого Максуди. Буква ا как отдельный звук не
вводится: на с. 10 — хамза (أَ إِ أُ).

## 6. Типичные ошибки русско- и казахоязычных
Рецензируемых исследований именно о русско-/казахоязычных учениках **не найдено** — это пробел.
По методическим источникам (SRC-023, C) и исследованиям других L1 (SRC-034, SRC-035, A):

| Пара / явление | Что делают | Есть в `lexicon.ru.yaml` |
|---|---|---|
| ح → «х», путают с خ, ه | нет фарингального звука в русском | ✅ ح/ه, ح/خ |
| ع → ء или гласный | | ✅ ع/ء |
| ث → с/т, ذ → з/д, ظ → з | нет межзубных | ✅ ث/س, ذ/ز, ظ/ذ, ظ/ز |
| ص ض ط ظ → с д т з | нет эмфатических | ✅ |
| ق → к | слишком «передний» звук | ✅ ق/ك |
| غ / خ | | ✅ |
| долгие гласные укорачиваются | | ✅ (`madd_too_short`) |
| шадда не удваивается | | ✅ (`shadda_missing`) |
| ر смягчается перед и | | ❌ — предложить подсказку (pedagogy-reviewer) |

**Гипотеза для проверки на данных (RQ-4, разведка E-1; до ADR-0052 — RQ-1, до ADR-0051 — RQ-2, H2.1):** казахоязычным ق и غ даются легче, чем русскоязычным
(в казахском есть увулярные [q], [ʁ]); остальные трудности общие. Отчёт `04_letter_confusions.sql`
с разбивкой по языку ученика позволит это проверить.

## 9. Где пробел (научная новизна)
1. Методика «Мөгаллим сәни» как **букваря чтения Корана** почти не изучена (SRC-016 прямо это отмечает).
2. Нет исследований ошибок **русско- и казахоязычных** учеников.
3. Нет **цифровых/ИИ-адаптаций** книги с автоматической проверкой и нет оценок открытых моделей на таких учениках.
4. Нет контролируемых испытаний букварных методик чтения Корана.

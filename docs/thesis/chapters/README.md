# Черновики глав

Один файл на главу: `01-обзор.md`, `02-проектирование.md` и т. д. Пишет `thesis-writer` из
материалов (`../README.md`, `../materials-log.md`), проверяют `citation-verifier` и
`thesis-opponent` (ADR-0033). Текст — черновик: голос и структуру утверждают автор и руководитель.

Пометки в тексте: `[нужен источник]`, `[нет данных]`, `[утвердить]` — до сдачи их не должно остаться.

## 2026-10-18 · правила — в проверки (ADR-0042)

- **Гл. 2 (методика).** Опора для чтения с нуля: длинный аят разбит на слоги, каждый — со звучанием
  (как карточки слогов урока буквы). Правила склейки — эвристики (немые буквы к следующей, ٱ + немая ل —
  с первой звучащей, гунна/мадд лин/идгам танвина, хуруф мукатта'а одной клеткой, «لا» одной клеткой,
  ۥ ۦ — знак); сверка подписей с преподавателем — TD-FN-30, TD-FN-119.
- **Гл. 4 (реализация).** Пример решения «генерируемое заранее + `status` человека» (как ролики ADR-0074):
  бот не зависит от `ml`, человек утверждает разбор глазами. Рисунок для главы: карточка аята по слогам
  (обычный и «Крупный шрифт»), например 106:2 или самый длинный аят; снять через `scripts/render_screens.py`
  (`make design`) после сверки подписей. Отклонённые варианты (поле в `course.ru.yaml`, готовые PNG, разбор
  на лету, слово целиком с подсветкой) — таблица в ADR-0077.
- **Различение данных.** `ayat.yaml` не входит в `curriculum.version` (TD-FN-120): до решения автора граница
  «строка целиком / клетки» в попытках на сурах — по дате (2026-10-31) или `attempts.app_version`.

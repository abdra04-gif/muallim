# Журнал материалов для диссертации

Что произошло и в какую главу это пойдёт. Новые записи — сверху. Ведёт `thesis-scribe` (`/thesis-note`).

## 2026-10-18 · трассировка исследования и предрегистрация
- **Гл. 4 (методика эксперимента).** Предрегистрация (`docs/research/preregistration.md`): 7 подтверждающих
  гипотез, остальное — разведка; исключения и план анализа до данных; заморозка отпечатком SHA-256 (без git).
- **Гл. 2–4.** Две матрицы трассировки: система (требование → код → тест, статус — `make trace`) и исследование
  (RQ → гипотеза → метрика → расчёт → Р-NN/Т-NN). Реестр рисунков `docs/thesis/figures.md` — откуда каждая цифра.
- **Гл. 3.** Отпечаток версии вместо коммита: воспроизводимость без системы контроля версий (ограничение и
  обходной путь, TD-FN-27).

## 2026-10-18 · обзор инструментов для бота
- **Гл. 2.** Сравнение готовых инструментов для Telegram-бота (`docs/research/bot-tooling.md`): что взято, что
  отложено, что отклонено и почему (Sentry — локализация ПДн; локальный Bot API — не та проблема).
- **Гл. 4, находка.** Muaalem отдаёт уверенность по фонемам и 10 признаков сифат (SRC-062); проект хранил их
  строкой и оценивал только фонемы. Уверенность — основа для «не уверен» и ROC (RQ-1), сифат — для ошибок
  русскоговорящих (RQ-2). Пример для «Ограничений»: часть сигнала модели не использовалась до обзора.

## 2026-10-18 · агенты качества и хуки
- **Гл. 3 (методика).** Обвязка: 18 субагентов, 8 хуков (ADR-0034). Отдельные роли «пишет код» и «ищет в нём
  ошибки», «пишет тесты» и «проверяет, что тесты ловят ошибки» (ответ на SRC-027). Зоны человека — запрос
  подтверждения с причиной вместо запрета, чтобы агент не искал обходы.
- **Гл. 3, находка для «Ограничений».** Правила `permissions.ask` закрывали зоны человека только для `Edit`:
  `Write` по тому же файлу проходил без вопроса. Пример того, что правило в настройках ≠ проверенная гарантия.
- **Гл. 3, данные.** С 2026-10-18 каждая блокировка и запрос подтверждения пишутся в `docs/journal/hooks/` —
  источник для Q6.1 вместо ручного подсчёта.

## 2026-10-18 · агенты для исследования и текста
- **Гл. 3 (методика).** Обвязка выросла с 7 до 11 субагентов: под этап исследования добавлены оценка модели,
  автор черновиков, библиограф и оппонент (ADR-0033). Готовые наборы агентов с GitHub отклонены: они общие и
  не знают запретов проекта. Пример для главы: роли «пишет» и «проверяет» разделены правами (у ревьюеров
  нет `Edit`/`Write`).

  (готовый абзац для раздела «Методика оценки»).
- **Гл. 4.** Первые данные о времени ответа: 9 попыток с настоящей моделью, p50 1,7 с, p90 5,0 с — в пределах

- **Гл. 2.** Наблюдаемость: сбой модели записывается с этапом (декодирование или модель) — QAS-04.

# Технический долг

Что сознательно отложено, почему и **когда обязательно закрыть**. Долг не удаляется — закрытый
получает дату и ссылку на коммит/ADR. Решение о закрытой фазе пилота — ADR-0015.

**Триггеры:**
- 🔴 **T1** — до первого ученика **вне круга уведомлённых знакомых**;
- 🟠 **T2** — до сбора данных для статьи/диссертационного эксперимента;
- 🟡 **T3** — при росте (>100 учеников, второй сервер, публичный запуск).

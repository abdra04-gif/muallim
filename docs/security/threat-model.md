# Модель угроз

Метод — STRIDE по компонентам с рисунка контекста (`architecture/diagrams/01-context.svg`).
Пересматривается при каждом новом внешнем интерфейсе (веб-панель, API, второй мессенджер).

## Что защищаем
1. Голосовые записи учеников (персональные, возможно биометрические данные).
2. Связку «Telegram ID ↔ псевдоним».
3. Токен бота и пароль БД.
4. Целостность исследовательских данных (результаты диссертации не должны быть искажены).
5. Учебный контент (ошибка в огласовке = ученики учатся неправильно).

## Угрозы и меры
| STRIDE | Угроза | Мера | Статус |
|---|---|---|---|
| S — подмена | Чужой выдаёт себя за ученика | ученик определяется только по `from_user.id`, который подписан Telegram | ✅ |
| S | Подделка апдейтов | long polling: входящих портов нет (ADR-0008) | ✅ |
| T — изменение | Подмена аудио задним числом | адресация по SHA-256, хеш в БД | ✅ |
| T | Агент или оператор уничтожает БД (`down -v`, откат миграций, DROP) | хук `guard.py`; `make migrate` сначала копирует БД и мигрирует входом `muallim_owner`; `restore` проверяет роли, сверяет SHA-256, спрашивает подтверждение, восстанавливает одной транзакцией и повторяет журнал удалений (ADR-0040, ADR-0054) | ✅ |
| T | Потеря или порча файлов записей | `muallim-research verify`: потерянные, лишние, повреждённые (ADR-0040) | ✅ |
| I — раскрытие | Голоса остаются в пакетах разметки, выгрузках и копиях после отзыва согласия | `verify` находит копии в пакетах и выгрузках; копии 0600; восстановление повторяет журнал удалений (ADR-0054) | 🟡 копии у разметчика удаляет человек |
| E — повышение прав | Ошибка в коде бота или клик в DBeaver удаляет таблицы | роли: бот — `muallim_app` без DDL/TRUNCATE, просмотр — `muallim_reader` только чтение, Telegram ID скрыт (ADR-0054) | ✅ |
| T | Агент «подгоняет» тесты | хук `guard.py` блокирует `tests/` в фазе impl | ✅ |
| T | Агент или человек меняет огласовки по ошибке | правка `curriculum/` только с подтверждения; агент pedagogy-reviewer; ревью diff | ✅ |
| T | Path traversal через имя файла | `FileAudioStore.path_for` принимает только 64 hex-символа | ✅ |
| R — отказ | «Я не давал согласия» | журнал `consents` с версией текста и временем | ✅ |
| I — раскрытие | Токен в git | `.env` в `.gitignore`, gitleaks в pre-commit и CI, хук запрещает агенту читать `.env` | ✅ |
| I | Утечка Telegram ID в датасет | выгрузки только по псевдониму; тест | ✅ |
| I | Утечка аудио с диска | права 0600/0700; `data/` вне git; диск сервера — шифровать (OQ-08) | 🟡 |
| I | Агент читает данные учеников | хук запрещает чтение `data/`, дампов БД, `.env` | ✅ |
| I | Текст сообщений и Telegram ID в логах | в `interaction_events` — только ID и баллы; в логах — запрещённые имена ловит тест, ротация 3 × 10 МБ (ADR-0027) | ✅ |
| I | Токен бота в логах (DEBUG, URL `/bot<токен>/`) | фильтр `RedactSecrets` на обработчике логов (ADR-0027) | ✅ |
| D — отказ в обслуживании | Огромные/длинные файлы | обрезка до 60 с (`ffmpeg -t 60`) | ✅ |
| D | Флуд голосовыми | throttling на ученика | ⏳ |
| E — повышение привилегий | SQL-инъекция | только параметризованные запросы SQLAlchemy | ✅ |
| E | Уязвимости в зависимостях | `pip-audit` в CI, lock-файл `uv.lock` | ✅ |
| E | Выдуманный или похожий по имени пакет (slopsquatting, тайпсквоттинг) | хук `dep_check`: нет на PyPI — блок, есть — карточка человеку (ADR-0046) | ✅ |
| E | Контейнер от root | Dockerfile: непривилегированный пользователь | ✅ |

# Персональные данные и этика исследования

## Какие данные собираются
| Данные | Зачем | Основание | Срок |
|---|---|---|---|
| Telegram ID | связать ученика с прогрессом | работа сервиса | пока ученик не удалит данные |
| Результаты попыток (фонемы, балл, ошибки) | обучение ученика, исследование | работа сервиса; в исследовании — под псевдонимом | до удаления / окончания исследования |
| Голосовые записи | поиск ошибок модели, дообучение | **явное согласие** (кнопка) | до отзыва согласия / удаления / окончания исследования |
| Анкета: 18+, родной язык, опыт чтения по-арабски (кнопки) | проверка 18+ (TD-SEC-05); сравнение ошибок по родному языку (E-1; страта разбиения RQ-2, ADR-0051) | **явное согласие** на исследование — без него не спрашивается | как попытки; удаляется с учеником |
| Настройки и состояние экрана (`learner_settings`, ADR-0061): как показывать подсказки, начало занятия, время напоминания, смещение от UTC в минутах (по ответу «который у тебя час?» — не город и не геопозиция; пока ученик не ответил — умолчание UTC+3, а не его пояс; в датасет и отчёты не выгружается), что открыто на экране | работа бота по выбору ученика; перезапуск не теряет экран | работа сервиса — согласие на исследование не нужно | удаляется с учеником (CASCADE) |
| Ответы «🧠 Закрепления» (`quiz_answers`, ADR-0066): какой вопрос показан, что нажато, верно ли, время ответа, ссылка на попытку чтения ступени ③ — без голоса и текста | обучение ученика (повторение по его ошибкам); модель усвоения (RQ-3) под псевдонимом | работа сервиса | как попытки; удаляется с учеником (CASCADE) |
| Журнал действий | анализ использования | работа сервиса, без текста сообщений | как попытки |
| Открытка «📤 Поделиться» (FR-47): номер и название урока, страница книги, неделя занятий и серия дней — **без имени, псевдонима и Telegram ID**; ученик пересылает её сам | рассказать о боте | действие ученика | бот не хранит; пересланное — вне бота |
| Логи процесса (псевдоним, ID попытки и карточки, вердикт, балл, время обработки, этап сбоя, traceback; без Telegram ID, текста, голоса и фонем). Согласие, /delete и разметка в лог **не пишутся** — только в БД (решение автора 2026-10-18, проверяет `test_research_events_stay_out_of_logs`) | диагностика сбоев | работа сервиса (ADR-0027) | ротация: последние 3 × 10 МБ в Docker (`docker logs`) и в `logs/bot.log` при запуске без Docker (ADR-0048); после /delete строки остаются до ротации |

**Не собираются:** имя, телефон, username, текст сообщений, геолокация.

## Принципы
1. **Минимизация** — храним только то, что нужно для обучения и исследования.
2. **Псевдонимизация** — в отчётах и датасетах только `L-xxxxxxxx`.
3. **Согласие** — отдельное, добровольное, отзываемое; бот работает и без него.
4. **Право на удаление** — одна кнопка в /privacy, удаляется всё. **Отзыв согласия** на запись
   голоса удаляет записи и разметку по ним; попытки (фонемы, баллы) остаются для прогресса
   (ADR-0040). Файлы удаляются после фиксации в БД; запись, которую прислал и другой ученик, остаётся
   у него.
5. **Прозрачность** — текст согласия версионируется; версия хранится с каждым «да/нет».

## Копии голосов вне хранилища
Пакеты разметки (`data/annotation/`), выгрузки датасета (`data/exports/`) и резервные копии
(`data/backups/`) содержат копии записей. После отзыва согласия или удаления копии в пакетах и
выгрузках находит `muallim-research verify` — их удаляет исследователь; разметчик удаляет пакет
после загрузки. Восстановление из старой копии не возвращает учеников, удаливших данные позже:
журнал удалений хранится вне БД и повторяется сразу после восстановления (ADR-0054). В журнале —
только UUID ученика и действие, без Telegram ID; хранится, пока хранятся копии. Ограничение: журнал
на том же диске, что и база, — при потере диска защищают только копии вне компьютера (TD-FN-14).

## Доступ к базе
Три входа (ADR-0054): `muallim_owner` — только миграции; `muallim_app` — бот и инструменты
исследования, без права менять схему; `muallim_reader` — просмотр (DBeaver), только чтение, Telegram
ID скрыт. Суперпользователь — только для копий и восстановления.

## Разметчики в Telegram (FR-17, ADR-0041)
Разметчик слушает записи учеников прямо в боте. Доступ — только из `ANNOTATOR_IDS` или по
одноразовому приглашению (`muallim-research annotator-invite`, сутки, в БД — отпечаток кода);
отзыв (`annotator-revoke`) закрывает его сразу. Права проверяются при каждом нажатии; без доступа
бот ведёт себя как с обычным учеником. Записи отправляются с `protect_content` — Telegram не даёт
их переслать или сохранить (запись экрана и диктофон это не останавливает: остаётся обязательство
разметчика, TD-SEC-21). Кто ученик, разметчик не видит — только строку книги и ответ бота.
Telegram ID разметчика по приглашению хранится в `annotators` только для проверки доступа.

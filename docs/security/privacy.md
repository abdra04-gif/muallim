# Персональные данные и этика исследования

## Какие данные собираются
| Данные | Зачем | Основание | Срок |
|---|---|---|---|
| Telegram ID | связать ученика с прогрессом | работа сервиса | пока ученик не удалит данные |
| Результаты попыток (фонемы, балл, ошибки) | обучение ученика, исследование | работа сервиса; в исследовании — под псевдонимом | до удаления / окончания исследования |
| Голосовые записи | поиск ошибок модели, дообучение | **явное согласие** (кнопка) | до отзыва согласия / удаления / окончания исследования |
| Анкета: 18+, родной язык, опыт чтения по-арабски (кнопки) | проверка 18+ (TD-SEC-05); сравнение ошибок по родному языку (H2.1) | **явное согласие** на исследование — без него не спрашивается | как попытки; удаляется с учеником |
| Журнал действий | анализ использования | работа сервиса, без текста сообщений | как попытки |
| Логи процесса (псевдоним, ID попытки, traceback; без Telegram ID, текста и голоса) | диагностика сбоев | работа сервиса (ADR-0027) | ротация Docker: последние 3 × 10 МБ; после /delete строки остаются до ротации |

**Не собираются:** имя, телефон, username, текст сообщений, геолокация.

## Принципы
1. **Минимизация** — храним только то, что нужно для обучения и исследования.
2. **Псевдонимизация** — в отчётах и датасетах только `L-xxxxxxxx`.
3. **Согласие** — отдельное, добровольное, отзываемое; бот работает и без него.
4. **Право на удаление** — одна кнопка в /privacy, удаляется всё. **Отзыв согласия** на запись
   голоса удаляет записи и разметку по ним; попытки (фонемы, баллы) остаются для прогресса
   (ADR-0040). Файлы удаляются после фиксации в БД; запись, которую прислал и другой ученик, остаётся
   у него.
5. **Прозрачность** — текст согласия версионируется; версия хранится с каждым «да/нет».

## Копии голосов вне хранилища
Пакеты разметки (`data/annotation/`), выгрузки датасета (`data/exports/`) и резервные копии
(`data/backups/`) содержат копии записей. После отзыва согласия или удаления копии в пакетах и
выгрузках находит `muallim-research verify` — их удаляет исследователь; разметчик удаляет пакет
после загрузки. Восстановление из старой копии вернёт данные учеников, удалённых позже, — после
восстановления удалить их снова (TD-DB-05).

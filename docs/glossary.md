# Глоссарий

| Термин | Значение |
|---|---|
| Харакат (огласовка) | значок над/под буквой, задающий короткий гласный: фатха (а), кясра (и), дамма (у) |
| Сукун | знак отсутствия гласного |
| Ташдид | удвоение согласной; в фонетическом письме Muaalem — две одинаковые буквы подряд |
| Мадд | долгий гласный; длительность в харакятах (в боте — 4) |
| Танвин | удвоенная огласовка на конце слова (-ан, -ин, -ун) |
| Калькаля | «отскок» звука у букв ق ط ب ج د при сукуне/остановке |
| Вакф | остановка в чтении; конечная огласовка не произносится |
| Васл | слитное чтение без остановки |
| Махрадж | место образования звука |
| Сифат | признаки звука (твёрдость, звонкость и т. п.) |
| Риваят Хафс | передача чтения, самая распространённая; параметр модели |
| Таджвид | правила чтения Корана |
| Фонема | минимальная звуковая единица; модель выдаёт строку фонем |
| Quran Phonetic Script | фонетическая запись проекта Muaalem (SRC-002) |
| PER | Phoneme Error Rate — доля ошибочных фонем |
| Попытка | одно голосовое ученика по одной карточке — строка `attempts` |
| Карточка | одна печатная строка книги (или заголовок буквы) в уроке, `L18-01`; у каждой — страница и строка книги |
| Шаг (урока) | одна карточка урока в порядке книги — правило, таблица или строка для чтения; на экране «шаг N из M», в прогрессе «повторить шаги: …» (ADR-0058) |
| Псевдоним | `L-xxxxxxxx` — идентификатор ученика в исследовательских данных |
| ADR | Architecture Decision Record — запись архитектурного решения |
| Порт / адаптер | протокол в `application/ports` / его реализация в `infrastructure` |
| Хук | скрипт, который среда агента выполняет на событие; агент не может его пропустить |
| TDD | разработка через тесты: красный → зелёный → рефакторинг |
| Смысловая область (bounded context) | часть системы со своим языком и границей: Обучение, Эталоны, Оценка чтения, Ученик и согласие, Исследование (`architecture/overview.md`, §2.1) |
| Итерация проектирования (ADD) | шаг проектирования: одна цель, драйверы (QAS, NFR), решения (ADR), проверка тестом (`architecture/design-iterations.md`) |
| Риск | событие, которое может случиться и помешать целям работы; балл = вероятность × влияние (`risks.md`) |
| Пользовательская история | требование глазами человека: «Как ‹роль›, я хочу ‹…›, чтобы ‹…›» + критерии приёмки (`requirements/user-stories.md`) |

# Текст диссертации (LaTeX)

Магистерская диссертация, Университет Иннополис, программная инженерия, сдача ≈ июнь 2027.
Сборка: `make thesis` → `thesis/build/main.pdf`; проверка вёрстки — `make thesis-check`.
Нужны xelatex, biber, latexmk (TeX Live 2025); шрифты — Times New Roman (macOS) и Scheherazade New
из `src/muallim/presentation/telegram/assets/fonts/` (тот же, что на карточках бота).

## Что где
| Файл | Что |
|---|---|
| `main.tex` | порядок глав; **язык текста** — `\mainlang` (english / russian) |
| `meta.tex` | тема, автор, руководитель, код направления — для титула |
| `titlepage.tex` | двуязычный титул (ru/en) |
| `preamble.tex` | шрифты, поля, библиография (`../docs/research/sources.bib`, ключи SRC-NNN) |
| `chapters/` | главы; в комментарии каждой — откуда брать материал в `docs/` |
| `check.tex` | проверка: арабский с огласовками, кириллица, ссылка, рисунок |

Рисунки берутся прямо из `docs/architecture/diagrams/` и `docs/design/screens/`; подпись и метка —
по ID из `docs/thesis/figures.md` (`\label{fig:R-02}`). Арабская строка — `\ar{…}` и рядом источник.

## Не подтверждено — узнать в учебном офисе / у руководителя
| Вопрос | Сейчас в каркасе |
|---|---|
| Официальный шаблон и требования к оформлению ВКР Иннополиса | свой каркас по образцу публичного двуязычного титула |
| Язык основного текста (английский? русский допускается?) | `english`, переключается одной строкой |
| Код и название направления, профиль | 09.04.01 «Информатика и вычислительная техника» — **[утвердить]** |
| Стиль библиографии (IEEE, APA, ГОСТ) | IEEE для английского, ГОСТ (`gost-numeric`) для русского |
| Поля, кегль, интервал, объём | 12 pt, 1,5 интервала, поля 3/1,5/2/2 см — **[утвердить]** |
| Аннотация на двух языках, обязательные разделы | одна аннотация |
| Сроки: предзащита, проверка на заимствования, сдача текста | неизвестны — для плана работ |

## Правила
- Цифра из данных — только со статусом ✅ в `docs/research/traceability.md` и паспортом в
  `docs/thesis/figures.md` (отпечаток `make trace`).
- Источник — только ключ из `sources.bib`; нового нет — сначала `/source`.
- Разведочные результаты так и называются (`docs/research/preregistration.md`).
- Использование ИИ-агентов в работе раскрывается в тексте (глава 3 и раздел о методике) по правилам
  вуза; доказательная база — `docs/journal/prompts/`, `docs/journal/sessions/`.

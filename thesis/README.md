# Тексты диссертации (LaTeX)

Магистерская диссертация, Университет Иннополис, программная инженерия, сдача ≈ июнь 2027.
Все тексты — на двух языках, из одной преамбулы и одних рисунков. Сборка: `make papers` (всё сразу).

| Документ | Файлы | Сборка → PDF |
|---|---|---|
| Диссертация, английская версия | `main.tex`, `chapters/en/` | `make thesis` → `build/main.pdf` |
| Диссертация, русская версия | `main-ru.tex`, `chapters/ru/` | `make thesis-ru` → `build/main-ru.pdf` |
| Аннотация к ВКР (рус., 4–5 с., обязательна) | `annotation-ru.tex` | `make annotation` → `build/annotation-ru.pdf` |
| Предложение темы (proposal) | `proposal-en.tex`, `proposal-ru.tex` | `make proposal` → `build/proposal-*.pdf` |
| Исследовательский обзор (research) | `research-en.tex`, `research-ru.tex` | `make research` → `build/research-*.pdf` |
| Проверка вёрстки | `check.tex` | `make thesis-check` |

Нужны xelatex, biber, latexmk (TeX Live 2025, пакет extsizes для 14 pt); шрифты — Times New Roman (диссертация, аннотация), PT Serif / PT Sans /
PT Mono (предложение, обзор, заголовки; есть в macOS) и Scheherazade New из
`src/muallim/presentation/telegram/assets/fonts/` (тот же, что на карточках бота).

## Что где
| Файл | Что |
|---|---|
| `preamble.tex` | общая для всех: язык (`\mainlang`), стиль (`\docstyle` = thesis / article), шрифты, цвета карточек бота, рамки RQ, библиография (`../docs/research/sources.bib`, ключи SRC-NNN) |
| `meta.tex` | тема, автор, руководитель, код направления — для титулов |
| `titlepage.tex` | двуязычный титул ВКР по Приложению 8 к Положению о ГИА |
| `chapters/en/`, `chapters/ru/` | главы; одинаковые метки `\label`, поэтому перекрёстные ссылки совпадают |
| `figures/fig-*.tex` | рисунки TikZ; подписи на двух языках через `\LANG{english}{русский}` |
| `figures/screen-*.png` | снимки экранов бота на 2026-10-18 (из `docs/design/screens/`), чтобы рисунок не менялся сам |

Рисунки: `fig-context` (Р-01), `fig-layers` (Р-02), `fig-pipeline` (ср. Р-03), `fig-harness` (ср. Р-06),
`fig-research-design`, `fig-gantt` — паспорта в `docs/thesis/figures.md`.

## Правила
- Цифра из данных — только со статусом ✅ в `docs/research/traceability.md` и паспортом в
  `docs/thesis/figures.md` (отпечаток `make trace`). Пока данных нет — видимая красная пометка
  `\pending{…}` («ожидает данных»): перед сдачей их не должно остаться (`grep -rn pending chapters`).
- Источник — только ключ из `sources.bib`; нового нет — сначала `/source`. Выходные данные сверять с
  Crossref/arXiv.
- Арабский — `\ar{…}`; список букв — через запятую (`\ar{ص}, \ar{س}`): через пробел порядок переворачивается.
- Правка смысла — в обеих версиях сразу (en и ru), иначе они разойдутся.
- Разведочные результаты так и называются (`docs/research/preregistration.md`).
- Использование ИИ раскрыто в «Statement on the use of AI tools» / «Заявлении об использовании ИИ»
  (`chapters/*/00-abstract.tex`); доказательная база — `docs/journal/prompts/`, `docs/journal/sessions/`.

## Требования вуза
Источник — Положение о порядке проведения ГИА Университета Иннополис (приказ ОД/УД-02/2026/01/26 от
26.01.2026), п. 6.8–6.16 и приложения 8, 11. Что из него уже выполнено в вёрстке:

| Требование | Где |
|---|---|
| A4, Times New Roman 14 pt, чёрный текст, интервал 1,5, по ширине, абзацный отступ | `main*.tex` (extreport 14pt), `preamble.tex` (`\docstyle`=thesis: заголовки, подписи, ссылки чёрные, Times) |
| Поля: левое 25 мм, остальные 20 мм | `preamble.tex` |
| Глава, введение, заключение, приложение — с новой страницы | класс extreport |
| Нумерация сквозная, на титуле номера нет | `main*.tex`: `\setcounter{page}{2}` после титула |
| Введение: актуальность, цель, задачи, объект исследования, новизна | `chapters/*/01-introduction.tex`, раздел `sec:novelty` |
| Не менее 40 страниц без приложений | сейчас ≈ 91 (en) / 95 (ru) страниц всего |
| Аннотация на русском 4–5 страниц со своим титулом (Прил. 11) | `annotation-ru.tex`: титул + 5 страниц |

Сроки программы (лекция «Thesis Project», 25.09.2026): руководитель и тема — 19.10.2026 (тема у автора есть,
руководитель её ещё не утвердил); главы 1–2 — в Moodle до 10.12.2026.

Сроки по Положению: тему можно уточнить не позже чем за месяц до ГИА (заявление, Прил. 4); ВКР и аннотация —
на корпоративную почту за 10 календарных дней до защиты; отзыв руководителя и рецензия с подписями — за 5 дней;
рецензент — не сотрудник Иннополиса (п. 6.12); текст проверяется на заимствования и размещается в ЭБС (п. 6.16).

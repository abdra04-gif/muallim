## [Не выпущено]
### Исправлено (ADR-0040, аудит БД)
- **Главная метрика не считалась**: precision/recall/F1 брали метки «на ошибку», которые импорт никогда не ставил.
  Теперь — по каждой фонеме эталона: TA/FR/FA/TR, precision, recall, F1, FAR, FRR, верный диагноз (как Iqra'Eval,
  L2-ARCTIC); α Криппендорфа между разметчиками; κ (NFR-ACC-01, QAS-01).

  после commit и не удаляются, если та же запись есть у другого ученика (в том числе при «Удалить мои данные»).
- **`make backup` больше не выдаёт сбой за успех**: проверка архива, SHA256SUMS, папка `-FAILED` при ошибке;
  `make restore` — сверка SHA-256, подтверждение «да», копия перед восстановлением, одна транзакция.

### Добавлено (FR-43, ADR-0029)
- **«🔤 Как читается» на карточке — под спойлером**: сначала ученик читает буквы сам, транскрипция по касанию;
  полное чтение со всеми огласовками от фонетизатора (те же параметры, что у проверки).
- Подсказка к значкам транскрипции называет только буквы из этой строки: в «’ал-х̣ам-ду…» — «х̣ — из горла…»,
  без лишних с̣ т̣ д̣ з̣.
- Одинаковые объяснения ошибок не повторяются: недотянутый долгий мадд («лаа» — две «ا») давал два одинаковых пункта.
- Подсветка ошибок на картинке результата сопоставляет буквы текста с фонемами по буквам, а не по номеру
  согласной: шадда и немая «ٱ» сдвигали подсветку к началу строки, и непрочитанный конец строки не был красным (ADR-0024).
- **Разбор ошибок, который хочется читать** (FR-43, ADR-0030): не дочитал — один пункт «на каком слоге остановился,
  что осталось»; один пункт на слог; «✅ Прочитано верно — N из M»; картинка в три цвета (верно / ошибка / не прочитано);
  со второй попытки — «📈 Было → стало» и «✨ Исправлено: «…»».
- Пропущенный слог объясняется как пропуск этого слога, а не «гласный в соседнем + буква» (ADR-0030).
- **Разбор ошибок коротко** (FR-43, ADR-0031): пункт — ««как надо» → у тебя «как прозвучало»» слогами и полфразы
  подсказки, без названий букв и «+»; до трёх мест, сначала явные ошибки (буква, огласовка), потом мадд;
  «👄 Как сказать» свёрнуто под «Подробнее»; план — одна строка.
- В БД снова текст к каждой ошибке (после схлопывания повторов их стало меньше, чем ошибок — сохранение упало бы на PostgreSQL).
- **Разбор ошибок для новичка**: «Нужно / У тебя» по слогам, слог с ошибкой подчёркнут; каждая ошибка —
  в каком слоге (не «во 2-м слоге») и «👄 Как сказать» для всех 10 типов, для гласных — как держать рот;
  план «что сделать»: 🔊 послушай → скажи слоги 3 раза медленно → прочитай строку.
- Результат с ошибками — двумя сообщениями (фото + разбор с кнопками): подпись к фото ≤ 1024 символов.

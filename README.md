# Muallim — ИИ-тренажёр чтения по «Аль-Муаллим ас-Сани»

Магистерская диссертация (Исмаилов, Университет Иннополис, 2027): *«Сбор речевого датасета и обучение моделей
для обнаружения ошибок чтения и произношения и оценки усвоения у начинающих изучать арабский язык и чтение Корана»*
(ADR-0064). Бот — инструмент сбора датасета и полигон, где модель проверяется.

Telegram-бот, который учит читать по-арабски по учебнику Ахмада Хади Максуди «Муаллим ас-Сани»
(«Второй учитель»). Ученик читает вслух букву или слово, бот распознаёт произношение моделью
Quran Muaalem, находит ошибки и объясняет их по-русски. Каждая попытка сохраняется (аудио — только
с согласия), чтобы изучать ошибки учеников и модели, размечать данные и улучшать проверку.

## Быстрый старт
```bash
make setup                         # зависимости + pre-commit
cp .env.example .env               # вписать BOT_TOKEN и пароль БД
make db-up && make migrate && make db-roles   # PostgreSQL + схема + три входа (ADR-0054)
make run-stub                      # бот без модели; отставшую схему БД обновит сам (с копией)
make try a='"/start" "✅ Да, разрешаю"'  # проверка бота в терминале: без Telegram, .env и базы учеников
uv sync --extra ml && make run     # бот с моделью (~2 ГБ, нужен ffmpeg)
```

## Для исследователя
```bash
make report                                              # отчёт → analytics/reports/
uv run muallim-research annotation-export --annotator A1 --limit 50   # пакет разметчика → data/annotation/A1_<дата>/
uv run muallim-research annotation-import FILE --annotator A1
uv run muallim-research dataset-export                   # датасет → data/exports/<дата>/
uv run muallim-research verify                           # сверка БД и файлов записей
```

`make check` — ruff, mypy --strict, import-linter (архитектура), pytest (покрытие ≥ 80 %).
То же в CI, плюс gitleaks, pip-audit, `make hygiene` (deptry, zizmor) и сборка Docker-образа.

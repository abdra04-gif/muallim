Изменение: $ARGUMENTS

Цель — в репозиторий уходит только проверенное, согласованное и понятное. Правила коммитов —
`docs/process/git.md`. Порядок:

1. **Что меняется.** `git status`, `git diff HEAD --stat`. Если в дереве несколько несвязанных
   изменений — делай несколько коммитов (по одному смыслу), добавляя файлы явно: `git add <пути>`.
   Никогда `git add -f`; `git add -A` — только если всё дерево — одно изменение.
2. **Проверки.** `make check` — зелёный. Красный — остановись и покажи человеку; коммитить
   красное можно только по его явному слову, с пометкой `Known failing:` в теле коммита.
3. **Согласованность.** Субагент `consistency-auditor` на этот diff — **только** для изменений
   уровня L (ADR-0071) или если в diff есть `docs/requirements/`, `docs/data/`, `docs/adr/`,
   `CLAUDE.md`, `tables.py`, миграции. Для S и M хватает хука doc_sync — субагента не запускай.
   Расхождения в документации исправь (документация — зона агента); в зоне человека (тексты ученику,
   программа, схема, методика) покажи человеку и жди.
4. **Трассировка.** `make trace` — обнови `docs/requirements/verification-status.md`; только если
   в diff есть `tests/` или `docs/requirements/`.
5. **Секреты.** `git add` отдельной командой, затем `git diff --cached --name-only` — проверь
   глазами; хук `git_guard` перед коммитом проверит пути и запустит gitleaks.
6. **Коммит** — отдельной командой, сообщение через `git commit -F -` (heredoc):
   ```
   <тип>(<область>): <что изменилось — словами ученика или исследователя>

   <зачем и что важно знать, 1–6 строк>

   Refs: FR-44, ADR-0038, TD-SEC-19
   Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>
   ```
   Типы: `feat` (ученик видит новое), `fix`, `research` (метрики, отчёты, разметка), `docs`,
   `thesis` (текст диссертации), `test`, `refactor`, `harness` (агенты, хуки, команды), `data`
   (схема, миграции), `chore`. Область — `bot`, `assessment`, `db`, `research`, `curriculum`,
   `thesis`, `harness`, `docs`.
7. **Push.** `git push` (хук `git_guard` ещё раз прогонит архитектуру, типы и тесты).
8. **Итог человеку:** `git log --oneline -5`, ссылка на коммит
   `https://github.com/abdra04-gif/muallim/commit/<hash>`, что проверено, что осталось.

Коммит и push подтверждает человек (запрос разрешения) — не обходи его.

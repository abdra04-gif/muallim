# Telegram-бот Muallim: что нужно знать до правки

## Ограничения Bot API (проверено по core.telegram.org/bots/faq, 2026-10-18)
| Что | Предел | Что делать в проекте |
|---|---|---|
| Сообщений в один чат | ~1 в секунду (короткие всплески можно) | разбор ошибки — одно сообщение + картинка, не серия |
| Разным пользователям | ~30 в секунду | рассылка напоминаний (TD-FN-18) — с паузами |
| В группе | 20 в минуту | бот только в личке |
| Скачать файл (`getFile`) | 20 МБ | голосовое минуты — с запасом; ограничение длительности — наше (`Settings`) |
| Отправить файл | 50 МБ | эталоны и картинки маленькие |
| Ошибка 429 | `retry_after` в ответе | aiogram бросает `TelegramRetryAfter` — ждать указанное, не повторять сразу |

Пределы aiogram и Telegram, которые легко забыть: `callback_data` ≤ 64 байт (UTF-8: арабская буква —
2 байта), текст сообщения ≤ 4096 символов, подпись к фото/аудио ≤ 1024, `parse_mode=HTML` —
экранировать `<`, `>`, `&` в тексте ученика и арабских строках.

## Тестовая среда Telegram (для стенда перед пилотом)
Отдельные аккаунты и боты, данные учеников туда не попадают.
- Вход: iOS — 10 раз нажать «Настройки» → Аккаунты → Войти в другой → Test; macOS — 10 раз по
  «Настройки» → ⌘ + клик «Добавить аккаунт»; Desktop — Shift + Alt + правый клик «Добавить аккаунт».
- Бот создаётся у @BotFather **внутри тестовой среды**; запросы идут на
  `https://api.telegram.org/bot<token>/test/METHOD`.
- В aiogram 3 это уже есть: `from aiogram.client.telegram import TEST`,
  `AiohttpSession(api=TEST)`. Подключение — настройкой, через `/feature` (TD-FN-38).

## Голосовые
- Telegram присылает OGG/Opus; ffmpeg → 16 кГц моно для модели (`infrastructure/audio`).
- В России голосовые замедляются (TD-FN-04): не путать медленную доставку со сбоем модели.
- Тишина, шум, обрезка → `audio_unusable` у разметчика; фильтр до модели — TD-FN-37 (VAD).

## Что Muaalem отдаёт сверх строки фонем
`quran_muaalem.Muaalem(...)` возвращает `MuaalemOutput`: `phonemes` (`text`, `probs` — уверенность
по каждой фонеме, `ids`) и `sifat` — по каждой группе фонем признаки с вероятностью:
`hams_or_jahr`, `shidda_or_rakhawa`, `tafkheem_or_taqeeq`, `itbaq`, `safeer`, `qalqla`, `tikraar`,
`tafashie`, `istitala`, `ghonna`. Сейчас `_raw_output` (`infrastructure/asr/muaalem.py`)
сохраняет их строкой `repr` с тензорами, а оценка их не использует — TD-FN-35, TD-FN-36.

## Правила проекта для этого кода
- Тексты ученику — только в `texts.py` и `feedback.*.yaml` (зона человека).
- Обработчик не ждёт модель в цикле событий: распознавание — в отдельном потоке/исполнителе.
- Никаких Telegram ID и текстов сообщений в логах (ADR-0027).
- Хендлеры проверяются `tests/integration/test_bot_flow.py` (подача update в Dispatcher, без сети).
- Документация aiogram с актуальной версией — MCP `context7` (`.mcp.json`): «aiogram 3 …».

# Цикл чтения: автор не обязан помнить команды

Описание цикла: `docs/research/reading/README.md`. Шаги выполняй **строго по файлам команд**, здесь
только правила, когда какой шаг запускать.

| Автор пишет | Шаг | Делай по |
|---|---|---|
| мнение о статье: ссылка / PDF / SRC + «прикольно», «не то», «слабо», «полезно» | карточка | `.claude/commands/read-note.md` |
| «что почитать», «нужны источники для …», в главе `[нужен источник]` | подбор | `.claude/commands/read-next.md` |
| «напиши обзор / текст для главы / раздел про …» с источниками | черновик | `.claude/commands/read-draft.md` |
| «вставь», «короче», «больше критики» после черновика | правка черновика | `.claude/commands/read-draft.md`, шаг 6 |

Правила:
- Перед стартом скажи одной строкой: «Записываю как карточку статьи (цикл чтения)». Если автор просто
  болтает о статье и не хотел записи, он остановит.
- Мнение не дописывай за автора. Если в сообщении нет оценки («прочитал X» и всё), спроси одним
  вопросом: «Что понравилось, а что нет?»
- После карточки, если по той же главе набралось ≥ 3 карточек 👍/🤔 без ✍️, предложи одной строкой:
  «По гл. N уже K карточек — написать черновик?»
- Хук начала сессии показал «📥 ждут чтения» или «карточек без черновика» → в первом ответе сессии
  напомни об этом одной строкой, если автор пришёл не с другой срочной задачей.

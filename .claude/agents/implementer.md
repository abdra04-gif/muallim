Ты реализуешь код под уже принятые тесты (зелёная фаза TDD, ADR-0011) в проекте Muallim.

Перед началом прочитай `CLAUDE.md`, `docs/architecture/overview.md` и ADR-0002.

Правила:
- Фаза должна быть `impl`. Тесты менять нельзя (хук заблокирует). Если тест кажется неверным —
  **остановись и объясни человеку**, не обходи.
- Соблюдай слои: domain — только stdlib; application — только domain и порты; SQL — только в
  infrastructure; Telegram — только в presentation; связывание — только в `bootstrap/di.py`.
- Новый сценарий регистрируй в `bootstrap/di.py`.
- Изменение таблиц → `infrastructure/db/tables.py` + миграция (`make migration m="..."` с
  подтверждения человека) + `docs/data/data-dictionary.md`.
- Минимальный код для зелёного, потом рефакторинг при зелёных тестах.
- Учебный контент (`curriculum/`), тексты ученику (`texts.py`), пороги (`policy.py`) не меняешь без
  явного разрешения человека.

Готово, когда `make check` зелёный. Итог одной таблицей: файл → что изменено → зачем.

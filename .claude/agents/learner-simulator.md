Ты играешь ученика проекта Muallim: взрослый, говорит по-русски, арабских букв не знает, таджвид
слышит впервые, занимается с телефона урывками. Портрет — `docs/requirements/audience.md`.

Что читать: тексты `src/muallim/presentation/telegram/texts.py`, экраны `screens.py`, `views.py`,
клавиатуры `keyboards.py`, объяснения `curriculum/feedback.ru.yaml`, `curriculum/lexicon.ru.yaml`,
программу `curriculum/course.ru.yaml`, макеты `docs/design/screens/`.

Пройди по шагам: первый запуск и согласие → первый урок → первая попытка (верно / с ошибкой /
не дочитал / тишина) → разбор ошибки → повтор → следующий урок → /progress → возврат через неделю
→ удаление данных. На каждом шаге спроси себя:
- Понятно ли без знания арабского, **что делать дальше**? Есть ли кнопка для этого?
- Есть ли термин без объяснения (огласовка, фатха, мадд, сукун, таджвид, «фонема»)?
- Сколько нового сразу? Больше трёх — перегрузка (ADR-0031).
- Разбор ошибки говорит, **как сказать правильно**, а не только что неверно (SRC-053, SRC-056)?
- Не стыдно ли и не обидно ли ошибаться; хочется ли продолжить (ADR-0030)?
- Что, если ученик нажал не то, прислал текст вместо голоса, вернулся через месяц?

Правила: тексты ученику и учебный контент меняет только человек — ты предлагаешь формулировку,
не правишь. Арабский текст и таджвид не придумываешь.

Ответ: путь ученика по шагам; на каждом — «что увидел · что понял · где застрял · предложение».
В конце — 3 самых сильных места и 3 самых болезненных.

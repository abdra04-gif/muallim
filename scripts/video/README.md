# Генератор роликов «🎬 Как произносить» (ADR-0074, FR-56)

Ролик = рисунок разреза головы (`assets/`, SRC-148) + деформация (челюсть, губы, кончик и спинка
языка) + поток частиц воздуха + звук ар-Раи (SRC-144). Результат — `curriculum/video/*.mp4`
(720p) и строка в `curriculum/video/videos.yaml`; `status` ставит человек после просмотра.

Код генератора переносится сюда на этапе реализации FR-56 (зависимости — группа `video`, numpy).
Место звука и подсказки — из `scripts/book/theory.py` (аль-Джазари, SRC-059); утверждает человек.

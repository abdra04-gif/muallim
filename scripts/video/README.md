# Генератор роликов «🎬 Как произносить» (ADR-0074, FR-56)

```bash
make videos a="ر ز"   # ролики букв; без a — все буквы из LETTERS в build.py
uv run --group video python scripts/video/build.py ز --out /tmp/try   # проба во временную папку
```

Нужно: ffmpeg и ffprobe (`brew install ffmpeg`), группа зависимостей `video` (numpy; Pillow и
PyYAML уже есть в проекте), шрифты macOS Avenir Next и Geeza Pro (на другой системе поменять пути
`FONT_TEXT`, `FONT_ARABIC` в `render.py`). Сеть и модель не нужны. Буква — около 5 минут.

## Как получается ролик
1. **Звук** (`build.py`). Берётся запись-тройка ар-Раи из `curriculum/audio/library/sounds.yaml`
   (например «رَ رِ رُ», SRC-144). По громкости находятся три гласных ядра; каждый слог вырезается
   от начала его согласного до конца гласного, промежутки выброшены (исключение из ADR-0068,
   утвердил автор на слух).
2. **Рисунок** (`articulate.py`). Медицинская иллюстрация разреза головы (`assets/`, SRC-148,
   P. J. Lynch, CC BY 2.5) не перерисовывается, а деформируется: каждый пиксель кадра берётся из
   исходника со сдвигом. Челюсть поворачивается вокруг сустава и тянет нижнюю губу и язык; верхняя
   губа приподнимается; щель между губами заливается цветом рта; кончик и спинка языка сдвигаются
   плавными «пятнами» (кончик — к бугорку за зубами у ر, к нижним зубам у ز; спинка вверх — твёрдые).
3. **Движение по звуку** (`render.py`). Перед каждым слогом — подготовка согласного (удар кончиком,
   щель, смыкание губ или связок), в момент слога — поза гласного: «а» — рот открыт, «и» — губы
   растянуты, «у» — губы кружком вперёд (тексты `scripts/book/theory.py`).
4. **Воздух.** 280 частиц идут по пути трахея → глотка → над языком → губы; до звука копятся у места
   смыкания, на звуке вылетают облачком; у ز — свистящие штрихи у зубов; от губ — звуковые волны.
5. **Панель.** Буква, название, место звука (аль-Джазари, SRC-059), шаги; у тройки — три плашки,
   звучащая красная; внизу — пять областей, нужная горит.
6. **Сборка.** Кадры 1920×1080 (рисуются вдвое крупнее для сглаживания) → ffmpeg: H.264 720p + AAC,
   `+faststart`. Имя файла — хеш содержимого; строка в `curriculum/video/videos.yaml` получает
   `status: unchecked`. Человек смотрит ролик и ставит `ok` или `bad`.

Вертикальные ролики 720×1280 (басмала, буквы ب ت ث ج) — [`vertical/`](vertical/README.md).

Случайность частиц — с фиксированным зерном: тот же код и та же запись дают тот же ролик.

## Как добавить букву
1. Тип артикуляции — `KINDS` в `render.py` (`glottal`, `tap`, `sib`, `lips`). Для новых мест
   (спинка к мягкому нёбу у ق ك, кончик между зубами у ث ذ ظ, горло у ع ح) нужна новая поза языка
   в `articulate.py` и проверка кадров человеком.
2. Строка в `LETTERS` (`build.py`): тип, название, три слога, твёрдость. Место звука и подсказки —
   из `scripts/book/theory.py`; **утверждает человек**.
3. В библиотеке звуков должна быть запись-тройка этой буквы.
4. `make videos a="<буква>"`, посмотреть ролики, поставить `status: ok`.

# Аяты по слогам (ADR-0077, FR-61)

```bash
make syllables   # = uv run --extra ml python scripts/syllables/build.py
```

Нужно: extra `ml` (`quran_transcript` — фонетизатор Хафса, ADR-0006). Модель распознавания, сеть
и база не нужны. Все аяты программы — несколько секунд.

## Что делает
1. Берёт из `curriculum/course.ru.yaml` все пункты с `quran` в уроках `section: sura` — по одному
   на уникальный текст (басмала — одна строка на все суры).
2. Фонетизатор (`quran_phonetizer`, параметры — `MOSHAF_PARAMS` бота) даёт фонемы и для каждой
   буквы текста — её звуки. Слоги фонем (`domain.phonetics.syllables`) режут слово на клетки;
   подпись — простой кириллицей (`application.transcription.plain`, FR-54).
3. Правила склейки (эвристики — результат проверяет человек):
   - немая буква (ٱ, «ль» перед солнечной) — в клетке со следующей звучащей, в конце слова — с
     предыдущей;
   - ٱ в начале аята звучит, но отдельной клеткой не стоит — вместе со следующей («аррах»);
   - гунна, мадд лин, идгам танвина в و/ي — повторы сжаты («мм», не «ммм»);
   - хуруф мукатта'а (الٓمٓ) — всё слово одна клетка;
   - ل и алиф после неё — всегда в одной клетке (лигатура «لا», как в мусхафе), подпись такой
     клетки через дефис («ли-ии»); татвиль перед алифом — не лигатура;
   - маленькие ۥ ۦ — знак после буквы, а не буква: соединение клеток не меняют (106:2).
4. Пишет `curriculum/syllables/ayat.yaml`: `moshaf` — параметры разбора, `ayat` — `text`, `status`,
   `words` (слово — список `[кусочек, подпись]`). Падает, если хоть один пункт не разобран или
   кусочки не складываются ровно в текст пункта.

## Статус — решает человек
Пересборка сохраняет `status` строки, если её `words` не изменились (`merge.py`), иначе ставит
`unchecked`. Человек смотрит карточку в боте и ставит `ok` или `bad`; `bad` бот не показывает —
рисует прежнюю карточку (строка аята целиком). Номер аята в файле не хранится: его даёт правило
`domain.syllables.ayah_number`.

Файл генерируется — руками не править (кроме `status`). Изменили пункт программы или
`MOSHAF_PARAMS` — тест `tests/integration/test_syllable_library.py` красный, пока не выполнен
`make syllables`.
